# sshc v0.16.4

保存済みのアカウントパスワードと鍵パスフレーズを、割り当てを保ったまま編集できるようにした更新です。

## 変更

- 名前付きアカウントパスワードの名前と値を編集できるようにしました。
- 名前付き鍵パスフレーズにも同じ編集操作を追加しました。
- 編集画面には保存済みの値を読み込み、すぐに確認・修正できる状態で表示します。
- 資格情報の名前を変更しても、現在のホストまたは鍵への割り当てを維持します。
- 同名の資格情報がある場合は上書きせず、別の名前を指定するよう案内します。
- 通常の一覧、更新応答、ログには秘密値を含めず、編集時だけ一度限りの確認トークンを使う専用APIから1件を取得します。
- 編集用の応答をキャッシュせず、名前・値・割り当ての更新を1回のvault transactionとして保存します。
- デスクトップとモバイルの編集画面、漏えい防止、同時実行安全性を自動検査するようにしました。

**変更履歴**: [v0.16.3...v0.16.4](https://github.com/aida0710/sshc/compare/v0.16.3...v0.16.4)
