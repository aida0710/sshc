# sshc v0.25.0

v0.25.0では、SFTPを日常的なファイルマネージャーとして使いやすくし、Terminalを中心にした画面構成へ整理しました。

あわせて、Terminalのコピー、Quick Connect直後の表示、対話型CLIとの互換性、接続先補完の安全性を修正しています。

## SFTP

- 接続直後はサーバーが返すホームディレクトリを表示し、一覧先頭の`..`、Back、Forward、Home、Root、パス直接入力で移動できるようにしました。
- 現在のディレクトリを名前で絞り込めます。名前、種類、更新日時、サイズの並べ替えと組み合わせて使用できます。
- ファイルとフォルダーの行をコンパクトにし、行クリックとチェックボックスで選択できるようにしました。Shiftによる範囲選択、Ctrl／Cmdによる追加選択、全選択、選択反転にも対応しています。
- 複数選択した項目をまとめてダウンロードまたは削除できます。選択した名前やフルパスは改行区切りでクリップボードへコピーできます。
- テキストファイルの編集は画面幅を変えないモーダルで開きます。UTF-8かつ2 MiB以下という既存の安全上の制限は維持しています。
- 転送キューをファイル一覧の下部へ移し、空の場合は表示しないようにしました。折りたたみ、全件一時停止、再開、キャンセルにも対応しています。
- 転送の有無は左メニューの独立項目ではなく、SFTP項目の状態点で示します。
- ホスト選択をモーダルへ変更し、検索、最近接続した順、グループ別の表示に対応しました。
- WinSCP 6.5.6の機能を項目単位で比較した差分台帳を追加しました。未対応機能を含め、今後の実装範囲と優先順位を追跡できます。

## 画面構成

- デスクトップの上部ヘッダーをなくし、Terminal、Connections、SFTP、Menuを左側のナビゲーションへ集約しました。TerminalとWorkspaceが使える表示領域を広げています。
- テーマと言語はMenu内のPreferencesから変更できます。
- モバイルのスワイプによるメニュー表示を削除しました。メニューやPreferencesは外側をクリックまたはタップしたときにも閉じます。

## TerminalとSSH

- Terminalで選択した文字を通常のコピー操作で取得できない問題を修正しました。リモートアプリケーションからローカルのクリップボードへ書き込むOSC 52とは分離して動作します。
- Quick Connectで接続した直後に、新しいセッションがTerminalへ表示されない問題を修正しました。
- SSHのリモートPTYへ固定のbaud rateを送信しないようにしました。端末速度を厳密に扱う対話型CLIでも、一般的なTerminalと同じ条件で起動します。

## CLI

- 接続先のシェル補完で、OpenSSHのaliasをシェルコードとして評価しないようにしました。空白や引用符などを含むaliasも、補完候補として安全に受け渡します。

## 検証

- Goの全パッケージテスト、Webの1,117テスト、TypeScript、ESLint、WebとPagesのproduction buildを実行しました。
- SFTPのホーム表示、移動、複数選択、転送キュー、ホスト選択を実Chromiumで確認しました。
