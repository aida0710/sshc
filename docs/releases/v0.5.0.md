# sshc v0.5.0

`ProxyCommand` を使用する接続と、再接続回数の設定に対応しました。

## 新機能

- `ProxyCommand` を経由する SSH 接続に対応しました。
- 実行する `ProxyCommand` を接続前にコンソールへ表示します。
- `ProxyJump` と `ProxyCommand` が同時に有効な場合は、どちらを使用するか曖昧にしないため接続を拒否します。
- 予期せず切断された場合の再接続回数を 0、1、2、3、5 回から選択できます。
- `sshc status` の既定出力を、対話利用向けの表形式に変更しました。機械処理には `--json` を使用できます。
- Android の通知からエンジンを停止できるようにし、通知へバージョンを表示します。

## 修正

- ProxyJump の経路解析、到達性検査、公開鍵登録の確認画面で、Match ブロックが反映されない問題を修正しました。
- Android AAR 内のエンジンが常に `dev` と表示される問題を修正しました。
- リリース対象のバイナリを各 OS のジョブで実行し、バージョン、エンジン起動、埋め込み UI を確認してから公開するようにしました。
- 3 OS すべてで到達不能な Go 関数を検出する CI 検査を追加しました。

## インストール

```sh
brew install aida0710/tap/sshc
```

または:

```sh
curl -fsSL https://raw.githubusercontent.com/aida0710/sshc/main/install.sh | sh
```
