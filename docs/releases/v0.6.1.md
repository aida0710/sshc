# sshc v0.6.1

Workspaceを複数hostの作業単位として扱い、接続後のpane配置も直接変更できるようにしたリリースです。

## Workspace Command Center

- Workspace内の接続先へ、直接入力したcommandまたは保存済みSnippetを一括実行できます。
- 既定では同じaliasをhostごとに1回へまとめ、必要な場合はpaneごとに個別実行できます。
- 実行前に対象hostと展開後commandをpreviewし、実行後はtargetごとのstdout、stderr、終了状態を表示します。
- ad-hoc commandは`{{...}}`を文字列として扱い、Snippetを選んだ場合だけ型付き変数を展開します。
- 実行はlive terminalへの入力ではなく専用SSH sessionを使うため、terminalのcwd、環境変数、shell stateは継承しません。

## Pane配置

- 各paneのhandleを別paneへDrag & Dropすると、接続状態を維持したまま配置を交換できます。
- Drag中の移動元とdrop先を表示し、terminalの選択、copy、resize操作を妨げないようterminal本体はdraggableにしていません。
- handleを2つ順に選ぶkeyboard／touch操作でも同じ交換を実行でき、Escapeで選択を解除できます。
- split方向、比率、pane数、focusを維持し、Workspaceを保存すると交換後の配置を再オープンできます。

## 検証

- Goの通常テストとrace detector、Android／Windows build、dead code検査を実行しました。
- Webのユニットテスト811件、TypeScript型検査、ESLintを実行しました。
- Playwright E2E 107件を実行し、pane交換後のWorkspace保存payloadも確認しました。
- 固定digestのOpenSSHコンテナでSFTP、SeaweedFSで暗号化S3同期、OpenSSH serverで接続互換性を確認しました。
