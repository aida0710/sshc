# sshc v0.44.1

v0.44.1では、[公開デモ](https://sshc-demo.aida0710.work/index.html)の画面を改善しました。起動時のダウンロードの進捗を起動画面の中に表示し、ヘッダを細くしてWeb UIとCLIを広く使えるようにしています。

sshc本体（CLI、engine、Web UI、Androidアプリ）の動作に変更はありません。

## ブラウザデモ

- これまでは、GitHubの最新リリースからデモ一式をダウンロードするあいだ、進捗バーが起動画面の外に表示され、画面内の項目はすべて「待機中」のままでしたが、**デモ一式のダウンロードを起動画面の1行として表示する**ように変更しました。ダウンロード・展開・保存のどの段階かと、その割合を確認できます。
- 最新リリースを取得できず配信済みの版で起動する場合は、その旨を同じ行に表示します。
- これまでは、ヘッダの下に状態表示の行とWeb UI・CLIのタブの行が並んでいましたが、**ヘッダ・状態表示・タブを1段にまとめました**。Web UIとCLIの表示領域が縦に広くなります。スマホ幅では、ヘッダを2段に折り返して表示します。
- デモの外枠の配色をWeb UIのダークテーマに合わせました。CLIのターミナルが枠の下端からはみ出して表示される問題も修正しました。
