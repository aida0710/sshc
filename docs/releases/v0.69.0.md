# sshc v0.69.0

v0.69.0では、リモートセッションを選んでいる間、ターミナルだけでなく、Home、Connections、SFTP、Vaultなどの画面も、接続先のsshcエンジンのマシンのものになるように改善しました。画面全体を枠で囲んで接続名を表示するので、操作の相手がこのマシンではないことがどの画面でも分かります。

あわせて、セッションが無いときに表示するHome、ターミナルの文字の大きさの既定と大きさを変えたときの表示、日本語を読みやすく表示するフォントを改善しています。sshcエンジンを切り替えて戻ったときに、画面の分割やターミナルの状態が元に戻らないようにも修正しました。

## 更新後に必要な操作

- **リモートセッションを使っている場合は、接続先のsshcもv0.69.0へ更新してください。** 接続先で`sshc update`を実行します。リモートセッションのやり取りの互換の番号を上げたので、このマシンと接続先の片方だけがv0.69.0だと、その組み合わせはリモートセッションとして使えません。
- Androidアプリからリモートセッションを使う場合は、アプリもv0.69.0へ更新してください。接続先をv0.69.0にすると、v0.68.3以前のアプリからはその接続先をリモートセッションとして使えません。
- 接続先がv0.68.3以前のままのときは、リモートセッションのターミナルの領域に両方のバージョンが表示されます。その場の更新のボタンで接続先を更新することもできます。更新すると、接続先で動いているセッションはすべて終了します。

## リモートセッション

- これまでは、リモートセッションを選んでも、接続先のsshcエンジンで動くのはターミナルのセッションだけで、HomeやConnections、SFTPなどの画面はこのマシンのものでした。**リモートセッションを選んでいる間は、次の画面を接続先のsshcエンジンのマシンのものに変更しました。**
  - Home、Connections、SSH Config、History
  - SSH Keys、Known Hosts、Remote Keys
  - Vault（パスワード、鍵のパスフレーズ、OTP）
  - VPN、Diagnostics、SFTP
- 接続先を追加、編集、削除すると、接続先のマシンの`~/.ssh/config`が変わります。サイドバーの［新しいセッション］に並ぶ接続名も、接続先のsshcエンジンのものです。検索欄に入力した`user@host`を［接続先として保存して接続する］で保存する先も、接続先のsshcエンジンです。
- SFTPの「ローカル」には、接続先のマシンのファイルが並びます。アップロードとダウンロードは、このマシンのsshcエンジンを通って接続先へ届きます。大きいファイルを送っている間も、セッションの一覧などの読み込みは待たされません。別のsshcエンジンへ切り替えても、このブラウザで始めた転送は続きます。
- Snippets、Settings、言語、テーマ、Sync、sshcの更新は、これまでどおりこのマシンのものです。
- 接続先のVaultのマスターパスワードの変更と、壊れたVaultの復旧・作り直しは、リモートセッションからはできません。接続先のsshcの画面を別に開いて行います。
- リモートセッションを選んでいる間は、画面全体をオレンジの枠で囲み、上の端に「リモートセッション: 接続名」を表示します。localhostに戻すと消えます。
- Homeの接続先のカードは、これまではリモートセッションを選んでいてもこのマシンでセッションを開き、［リモートセッション］をlocalhostに戻していました。**選んでいるsshcエンジンでセッションを開くように変更しました。** 選択はそのままです。
- リモートセッションで開いたシェルは、セッション名の下にこれまで「localhost」と表示していました。接続先の接続名を表示するように修正しました。ターミナルの［…］の「現在のフォルダをSFTPで開く」も、リモートセッションで開いたSSHのセッションで使えるようになりました。
- 未保存の変更がある画面では、sshcエンジンを切り替える前に、変更を破棄するかを確かめます。

## sshcエンジンの切り替え

- これまでは、画面を分割したまま別のsshcエンジンへ切り替えて戻ると、分割が解除されていました。**分割をsshcエンジンごとに覚え、戻ると元の分割を表示するように修正しました。** ページを読み込み直すと分割が解除されるのは、これまでどおりです。
- これまでは、切り替えて戻るとターミナルが作り直され、拡大・縮小した文字の大きさ、スマホの入力欄に書きかけた文、sshcエンジンが保存している範囲より前のスクロールバックが消えていました。**切り替える前のターミナルを裏に残し、戻るとそのままの状態で表示するように修正しました。** 裏に残すのは、表示していたターミナルと、設定の「裏に残すターミナル」の数までです。
- 接続先ごとにフォントなどの見た目を決めている場合に、切り替えたときにターミナルが既定の見た目に戻ることがありました。接続先の設定を読み終えるまでは前の見た目のまま描くように修正しました。

## Home

- **セッションが無いときは、これまでのTerminalの専用の画面の代わりにHomeを表示するように変更しました。** 最後のセッションを閉じたとき、スマホの下のバーでTerminalを選んだとき、リモートセッションをセッションの無いsshcエンジンへ切り替えたときです。
- Homeの後ろに、プリセットで選んだ絵（ネットワーク、等高線、地球儀、水槽）を表示します。一番下には、新しいセッションが開くマシンの状態とアクティビティを表示します。
- これまでの空の画面にあった「最近の接続」の一覧と、［セッションを開く］［接続先を追加］［同期で受け取る］のボタンは無くなりました。Homeの接続先の一覧と、サイドバーの［新しいセッション］を使います。
- 設定の「セッションが無いときの背景」の名前を「Homeの背景」に変更しました。選んでいた絵はそのまま引き継がれます。
- セッションを開けなかった理由は、これまでサイドバーにだけ表示していたので、サイドバーが隠れているスマホでは気づけませんでした。画面の下の短い知らせにも表示するように変更しました。

## ターミナルの文字

- プリセットのフォントサイズが空欄のときの文字の大きさは、これまでスマホで15px、それ以外で13pxでした。**どの画面でも13pxに変更しました。** スマホだけ大きくするときは、スマホ用のプリセットにフォントサイズを入力します。
- つまむ操作、Ctrlとホイール、ショートカット、コマンド検索で文字の大きさを変えると、ターミナルの右上に今の大きさと［リセット］を3秒表示します。［リセット］を押すと、設定の大きさに戻ります。
- これまでは、トラックパッドのスクロールの勢いが残っている間にCtrlを押すと、文字の大きさが端まで変わることがありました。Ctrlを押す前から続いているスクロールは、大きさの変更に使わないように修正しました。
- ターミナルのフォントの選択肢に「JetBrains Mono + BIZ UDGothic」を追加しました。英数字と記号をJetBrains Monoで、日本語をBIZ UDGothic（BIZ UDゴシック）で表示します。フォントのファイルは合わせて4.4MBで、このフォントを選んだときだけ読み込みます。既定のフォントは変わりません。
