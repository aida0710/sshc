# sshc v0.24.0

v0.24.0では、SFTPやWorkspaceで画面を切り替えたときに、前の状態が新しい画面へ混ざらないよう処理を見直しました。

あわせて、CLIのヘルプと補完、Web UIとengine間のデータ検証、ブラウザー登録、キーボード操作を改善しています。

## SFTPとWorkspace

- SFTPで接続先を切り替えると、前の接続先の一覧と開いていたファイルをすぐに閉じるようにしました。切り替え前の通信が遅れて完了しても、新しい接続先の画面へ内容やエラーを表示しません。
- 転送ジョブで実行できる一時停止、再開、再試行、キャンセルをengineが返すようにしました。画面を再読み込みした場合も、表示中の状態から操作可否を推測せず、engineが管理している状態に従います。
- モバイルでは、ワークスペース名と現在のペインを残し、名前変更とその他の管理メニューだけを狭い画面で非表示にしました。分割したTerminalは、これまでどおり1ペインずつ切り替えられます。

## CLIとAPI

- CLIのコマンド解釈、個別ヘルプ、bash／zsh／fishの補完を、同じコマンド定義から作るようにしました。新しいコマンドや選択肢を追加した場合に、ヘルプと補完だけが古いまま残ることを防ぎます。
- Web UIとengineの間で送受信するJSONを、OpenAPIに記載した形式と照合するようにしました。不正な値や不足した項目を画面の状態へ反映する前に検出します。
- Keys、Remote Keys、Snippets、Workspace、SFTPなどの画面で、個別に重複していたAPIの型と検証処理を共通の定義へ揃えました。

## ブラウザー登録と画面操作

- 保存していたローカルポートを使用できずengineのURLが変わった場合は、以前のブラウザー登録を失効するようにしました。新しいURLでは`sshc`を一度実行して、現在のengineへブラウザーを登録してください。同じポートで再起動した場合は、これまでどおり登録を引き継ぎます。
- SyncのForce送信と受信確認で、最初に操作ボタンへフォーカスし、Tabキーをモーダル内に留めるようにしました。EscapeキーとAndroidの戻る操作で閉じた後は、元のボタンへフォーカスが戻ります。
- Connectionsの設定タブは、左右の矢印キーとHome／Endキーで移動できます。オフライン画面の再読み込みボタンがContent Security Policyによって動かない問題も修正しました。

## 検証

- Goの全パッケージテスト、変更箇所のrace test、`go vet`、Webの1,099テスト、TypeScript、ESLint、production buildを実行しました。
- 360px幅のブラウザーで、モバイルのWorkspace表示と管理ボタンの非表示を確認しました。CLIとOpenAPIの生成物は、再生成しても差分が出ないことを検査しています。
