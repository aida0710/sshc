# sshc v0.37.2

v0.37.2では、`sshc sync pull`と`sshc sync push`が、転送量の要約だけでなく、追加・変更・削除したファイルを1行ずつ表示するようになりました。同期のたびに何が書き換わったかを、その場で確認できます。

あわせて、Vaultのワンタイムパスワード（TOTP）の画面で、6桁のコードをクリックしてコピーできるようにしています。

## Syncのコマンド

- **これまで`sshc sync pull`と`sshc sync push`は、書き込んだ件数と削除した件数だけを表示していましたが、どのファイルが変わったかを1行ずつ表示するようになりました。** 各行は`added`、`modified`、`removed`の区分と、`~/.ssh`からの相対パスを示します。要約の件数も`written`をやめ、`added`と`modified`に分けています。
- **競合または削除があって通常の`pull`が止まったときに、適用しなかった内容を表示するようになりました。** これまでは「プレビューを確認してください」と伝えるだけで、CLIにはそれを見る手段がありませんでした。止まったときは、適用されなかった追加・変更・削除と競合を同じ形で標準エラー出力へ表示してから、`sshc sync pull --force`を案内します。通常の`pull`は削除を適用しないため、削除されるファイルはこの表示で確認してください。
- `--json`にも同じ内容が入ります。pullの応答には`written`に加えて`added`が入ります。`added`は`written`のうち、この端末にまだ存在しないファイルで、残りは既存のファイルを置き換えます。pushの結果には`added`、`modified`、`removed`がパスの配列として入ります。

## ワンタイムパスワード（TOTP）

- **6桁のコードをクリックすると、そのコードをコピーするようになりました。** これまでは表示を選択して手で写す必要がありました。読みやすさのために挟んでいる空白は含めず、6桁の数字だけをコピーします。
- **「ひとつ前」「ひとつ後」のコードも、同じようにクリックしてコピーできます。** コードが次の値へ切り替わると、コピー済みの印は消えます。
- クリップボードへの書き込みをブラウザーが拒否した場合は、コピーできたように見せず、その場で拒否を示します。

## Windows

- **Windowsのssh-agentとの通信を閉じるとき、待っている読み取りがあると、閉じる側と待っている側が同じhandleを同時に扱っていました。** 取り下げた入出力がカーネルから戻るのを待ってからhandleを閉じるようにしました。これまでは、閉じた直後の読み取りが無関係なエラーを返したり、無効になったhandleを触ったりする可能性がありました。

## 更新後に必要な操作

更新後はengineを再起動して新しい版を利用してください。Syncの一覧はengineが作るため、CLIだけを更新した場合は表示されません。

v0.36.0以降から更新する場合、ブラウザーの再登録は不要です。v0.35.0以前から更新する場合は、[v0.36.0のリリースノート](v0.36.0.md)にあるブラウザーの再登録とengineの再起動が必要です。
