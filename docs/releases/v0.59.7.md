# sshc v0.59.7

v0.59.7では、Androidのアプリとスマホの画面を使いやすくしました。Androidの「戻る」をほかのアプリと同じ動きにし、キーバーに^Cを足しました。ターミナルの指のスクロールが速すぎた不具合も直しています。

あわせて、再接続中や接続が切れたこと、初めての接続先のホスト鍵の確認を、ターミナルの下に大きな枠で出すようにしました。ホスト鍵は、枠のボタンで受け入れられます。スマホでは、こうしたお知らせを上のバーの警告アイコンにまとめます。

## ターミナルのお知らせ

- **再接続中や接続が切れたことを、ターミナルの下に大きな枠でも出すようにしました。** これまでは、ターミナルの上の1行の帯に、小さな字とボタンで出していました。枠に出すのは、自動で再接続しているとき、接続が切れたかプログラムが失敗で終わったとき、画面とsshcエンジンとの接続の再試行を止めたときです。帯は今までどおり出ます。スマホでの出し方は、下の「Androidのアプリとスマホの画面」に書いています。
- 枠には、帯と同じ［再接続を停止］［再接続］［今すぐ接続］を出します。終わったセッションの枠には、そのセッションを閉じる［閉じる］も出します。`exit`で正常に終わったときは、帯だけに出します。
- 枠は右上の×で消せます。ログを読むときに邪魔にならないようにするためです。消したあとは、上の帯から操作します。ほかの画面へ行って戻っても消えたままで、同じセッションでまた接続が切れたときには、もう一度出ます。
- 枠が出ると、フォーカスが枠に移ります。Tabで枠のボタンへ進み、Escで枠を消せます。打っていたEnterでボタンが押されないよう、フォーカスはボタンではなく枠に移します。

## 初めての接続先のホスト鍵

- **known_hostsに無いホスト鍵を、枠のボタンで受け入れられるようにしました。** これまでは、ターミナルに出る英語の問いに`yes`と打つ必要がありました。枠には、接続先、鍵の種類、SHA256のフィンガープリントと［やめる］［接続する］を出します。上の帯にも同じボタンを出します。ターミナルで`yes`や`no`と打って答えることもできます。
- ボタンの答えは、その鍵についての問いがまだ開いているときだけ渡します。ターミナルで先に答えたあとや、ProxyJumpの次の段が別の鍵を尋ねているときに押しても、何も起きません。遅れた答えが、パスワードの問いや、つながったあとのシェルに入ることはありません。
- ［やめる］や`no`で答えたときは、「ホスト鍵を受け入れなかったため、接続しませんでした。」と出すようにしました。これまでは、問いに答えられない接続に向けた「…対話モードで接続してください」という文が出ていました。
- StrictHostKeyChecking yesで、問いを出さずに断ったときの文を、「このホスト鍵はknown_hostsにありません。フィンガープリントを確認してknown_hostsに登録してから、接続し直してください。」にしました。
- **スマホで、ホスト鍵の問いの最後の行が途中で切れていた不具合を直しました。** これまでは「…continue connecting (yes/no)? 」が「…continue connec」で切れ、打った答えが最後の文字に重なっていました。接続を待っているあいだに画面の幅が変わったときは、その行を新しい幅で書き直します。問いが出ている最中に画面を回したときも同じです。
- 鍵が変わった接続先と、失効させた鍵は、今までどおり尋ねずに接続を止めます。
- v0.59.6以前の実行先のsshcエンジンでは、ホスト鍵の枠は出ません。これまでどおりターミナルで答えてください。

## Androidのアプリとスマホの画面

- **スマホでは、お知らせを上のバーの警告アイコンにまとめるようにしました。** 上の帯も下の枠も最初は出さず、「…」の左に警告アイコンを1つ出します。何かが終わったり失敗したりしたときは赤、それ以外は黄色です。アイコンを押すと、帯をターミナルの上に重ね、枠を下に出します。重ねて出すので、ターミナルの行数は変わりません。新しいお知らせやホスト鍵の問いが来ても、自分からは開きません。もう一度押す、外を押す、Androidの「戻る」、枠の×のどれでも閉じます。
- **Androidの「戻る」を、ほかのアプリと同じ動きにしました。** これまでは、下のバーで切り替えた画面を、切り替えた順に全部さかのぼっていました。これからは、Home以外の画面で戻るとHomeへ、Homeで戻るとアプリを閉じます。開いた接続先や、Menuから開いた設定などのページでは、1つ前の画面へ戻ります。開いているダイアログやメニューを先に閉じる動きは変えていません。
- **キーバーに^Cを足しました。** 1回のタップでCtrl+Cを送ります。これまでは、日本語のキーボードではCtrlのあとに打ったcが変換の確定を待つので、Ctrl+Cを送るのに3回の操作が要りました。ほかの組み合わせは、今までどおりCtrlを押してから英字を打ちます。
- ターミナルの上のバーの左のボタンを、‹からメニューのアイコンにしました。押すとサイドバーが開く動きは変えていません。‹は「戻る」に見えるためです。
- アプリの起動の間を黒にしました。これまでは、明るい起動画面のあとに白い画面が一瞬出てから、暗い画面になっていました。
- 入力欄を使ったあと、ほかのアプリから戻るとキーボードが勝手に開いていた不具合を直しました。
- ホスト名・ユーザー・パス・コマンドなどの欄で、キーボードに文の先頭の大文字化と自動修正をさせないようにしました。ホスト名などの欄は、タップすると英字の配列で開きます。これまでは、`ls`が`Ls`になることがありました。
- 強制終了したときや、スマホのシステムがアプリを閉じたときも、次に開いたときに「前回のセッションを開き直しますか」を出すようにしました。これまでは、sshcエンジンが正しく止まったときにしか出ませんでした。sshcエンジンが動いているあいだは、開いているセッションが変わってから5秒以内に、開き直しの記録を書きます。
- スマホのサイドバーで、ワークスペースとセッションの行を36pxに詰めました。これまでは、セッションの行が58px、ワークスペースの行が44pxでした。一度に多くのセッションが見えます。
- 接続先の編集で、5桁のポート番号（22298など）が「戻す」ボタンの下に隠れていた不具合を直しました。

## ターミナル

- **指のスクロールで、マウスを読むプログラム（vim、Claude Codeなど）が指の約3倍の速さで動いていた不具合を直しました。** 指が3行分動くごとに、ホイールを1回送るようにしました。
- キーボードを開いて全画面のプログラムを始め、キーボードを閉じると、画面がずれて描かれていた不具合を直しました。xterm.jsの不具合で、sshcの側で補っています。
- Terminalに戻るたびに、文字の描画（WebGL）を作り直して画面が一瞬止まり、文字の折り返しが変わって文字が動いていた不具合を直しました。
- 日本語の文のすぐあとにファイル名があるとき、文まで下線を引いていた不具合を直しました。
- ほかのブラウザや、このsshcエンジンを実行先として使うマシンで開いたセッションと、変えたワークスペースを、ページを読み込み直さずに出すようにしました。これまでは、開いているセッションが0個のあいだやワークスペースを変えたあとに、読み込み直すまで出ないことがありました。
- 長押しで文字を選ぶとき、選ばれる位置が画面の文字とずれることがあった不具合を直しました。フォントを読み込んだあとに文字の幅が変わると起きていました。

## SFTPとSSH Config

- SFTPで別の画面へ行って戻ると、接続していたタブが「未接続」になっていた不具合を直しました。同じ起動のあいだに接続していたタブは、戻ったときにつなぎ直します。
- `~/.ssh/config`がまだ無いとき、HomeとSSH Configに「問題があります」と出ていた不具合を直しました。
