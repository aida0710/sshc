# sshc v0.12.1

自動同期が変更のないスナップショットを繰り返し送信し、日付付き履歴を増やす問題を修正しました。

## 変更内容

- 1分ごとの自動同期は最初にライブオブジェクトのETagだけを確認し、ローカルとリモートのどちらにも変更がなければ転送しないようにしました。
- 送信専用設定でもリモート世代を確認し、別端末による更新を検知した場合は履歴候補を作る前に自動同期を停止します。
- ローカル差分がない通常の手動pushを拒否し、同じ内容の履歴が増えないようにしました。
- 日付付き候補の作成後にライブオブジェクトの条件付き更新が競合した場合、その試行が作成した候補だけを削除します。
- 同期先をendpoint、bucket、region、object keyの組で識別し、別バケットへ切り替えたときに以前のETagを流用しないようにしました。
- 同期画面に「送信するローカル変更はありません」と表示し、差分がないときは送信ボタンを無効にしました。

既存の履歴オブジェクトは自動削除しません。保持期間を制限する場合は、確認のうえバケット側のlifecycle ruleを設定してください。
