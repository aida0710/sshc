# sshc v0.33.7

v0.33.7では、接続経路を変更した後の保存済み認証情報をWebから安全に再確認できるようにしました。

## Connections

- HostName、User、Port、ProxyJumpなどが変わった場合、以前の経路に紐付いた保存済みパスワードとTOTPを自動では使用しません。
- 使用を止めた保存済みパスワードは、Connectionsの概要に短い「停止中」として表示します。
- 基本設定を保存すると確認モーダルが開き、既存のパスワードまたはTOTPを現在の認証経路へ再確認できます。
- Advanced、同期、ほかのエディタで接続経路が変わった場合も、基本設定の保存から復旧できます。
- 再確認では秘密値をWebへ返さず、SSH設定とVaultの割り当てを同じトランザクションで更新します。

## 更新後

Webではバイナリ更新後に稼働中のengineを再起動してください。Androidでは正式版APKを更新してください。
