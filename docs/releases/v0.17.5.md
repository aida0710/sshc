# sshc v0.17.5

接続先ごとの文字コード設定、Remote Keysの複数接続先登録、接続管理とターミナル操作の改善をまとめた更新です。

## 文字コード

- SSH、Serial、TelnetでUTF-8、Shift_JIS、EUC-JP、ISO-2022-JPの双方向変換に対応しました。
- SSHの文字コードは接続先ごとに保存され、Webターミナル、`sshc <alias>`、`sshc ssh <alias>`、非対話コマンドで同じ設定を使用します。
- SerialとTelnetではCLIの`--encoding`から文字コードを指定できます。

## 接続管理

- 接続詳細に`sshc`タブを追加し、配色、フォント、背景、文字コード、タグ、表示順を他のSSH設定と同じ画面で編集できるようにしました。
- Ctrl+Kのホスト検索結果から三点ボタンで接続設定へ直接移動できます。Connectionsの既定順を名前順へ変更しました。
- 作成、名前変更、複製、保存先移動で同名のHost aliasが存在する場合、曖昧な設定を作らず操作を拒否します。
- 接続編集タブとグループの未保存操作欄が内容へ追従し続けないようにしました。

## Remote Keys

- 保存済み接続先を検索して複数選択し、同じ公開鍵を最大4台ずつ並列登録できるようにしました。事前確認と結果は接続先ごとに表示します。
- 別のHostだけに設定された`ProxyCommand`などが鍵登録時の警告へ混入する問題を修正しました。条件付き`Include`も接続先の条件を保ったまま評価します。

## ターミナルと表示

- Shiftを押している間は接続カードを薄い赤色で示し、そのまま閉じるボタンを押すと確認なしで接続を終了します。通常操作では従来どおり確認を表示します。
- GitHubへの更新確認が失敗またはタイムアウトしても、左下の現在のバージョン表示が消えないようにしました。
- 接続メタデータを保存した直後に詳細を再読込し、文字コードなどの表示が保存前の値へ戻る問題を修正しました。
