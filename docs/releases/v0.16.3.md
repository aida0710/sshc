# sshc v0.16.3

モバイルの接続一覧とConfig Explorerを整え、スクロール中も現在の画面を見失わないようにした更新です。

## 変更

- 接続一覧の「グループ／ファイル」切替に、他のcontrolと揃えた8pxの丸角を追加しました。
- Config Explorerのfile iconを、ファイル名と状態からなる2行labelの中央へ揃えました。
- 「読み込みファイル」「編集可能」「診断」を狭幅でも3列に保ち、列間の区切り線が消えないようにしました。
- 最上部のapp headerをscroll中も固定し、navigationと現在の画面名へ常にアクセスできるようにしました。
- ページの長い説明文は固定せず、モバイルの表示領域を圧迫しないようにしました。
- 日本語の360px表示で、丸角、列境界、icon位置、scroll後のheader位置を自動検査するようにしました。

**変更履歴**: [v0.16.2...v0.16.3](https://github.com/aida0710/sshc/compare/v0.16.2...v0.16.3)
