# sshc v0.27.1

v0.27.1では、SFTP転送マネージャーの操作とスマートフォンでのサイズ変更を改善しました。完了・キャンセル・失敗した転送を一覧から除去でき、キャンセルと完了が重なった場合にも不要なエラーを表示しません。

あわせて、macOSで背景画像を設定したローカルシェルを編集すると、消した文字が画面に残る問題を修正しました。また、SSH通信に使用する依存ライブラリを、既知のサービス拒否問題が修正された版へ更新しました。

## SFTP転送マネージャー

- 完了、キャンセル、失敗した転送を、行ごとの［一覧から削除］で1件ずつ除去できるようにしました。［失敗項目を消去］では、成功した履歴を残したまま失敗項目だけをまとめて除去できます。
- 右端のメニューは、実行できる一括操作がある場合だけ表示します。操作項目がない空のメニューが開かない問題を解消しました。
- キャンセル要求と転送完了が同時に起きた場合は、完了状態を維持したまま正常終了として扱います。操作時に状態が変化した場合は最新状態を取得し、理由のないエラー表示を避けます。
- 失敗したアップロードを一覧から除去するときは、sshcが作成した未公開の一時ファイルも削除します。接続障害などで削除できない場合は項目を残して理由を表示し、接続回復後に再試行できます。
- 転送マネージャー上端のグリップをスマートフォンでも操作しやすくしました。スマートフォンでは画面高に応じた3段階、デスクトップでは連続した高さに変更でき、それぞれの高さを個別に保存します。上下矢印、Home、Endキーでも変更できます。

## Terminalの背景画像

- macOSのChromium系ブラウザーで、背景画像を設定したTerminalの行をBackspaceなどで編集すると、削除済みの文字が残像として残る問題を修正しました。シェルへ送られる入力自体は失われていませんでした。
- 背景画像を使用するTerminalでは、透明セルを確実に再描画できるDOM rendererへ自動で切り替えます。背景画像を使用しないTerminalは、これまでどおりWebGL rendererを使用します。
- 実際のローカルPTYを使い、入力した文字列をBackspaceで書き換えて実行するブラウザーテストを追加しました。

## SFTP CLIの進捗表示

- 対話ターミナルで`sshc sftp get`を実行すると、リモートファイルの準備状況をSFTP接続ごとの進捗バーで表示します。4接続で分割している場合は4行、分割しない場合は1行になります。
- 各行には接続番号、進捗率、転送済みサイズ、担当サイズ、ファイル名を表示します。表示値はエンジンが実際に各接続から読み取ったバイト数です。
- `--json`と非対話環境では進捗表示を無効にし、JSONやリダイレクト先へ制御文字を混在させません。

## セキュリティ

- SSH通信に使用する`golang.org/x/crypto`を`v0.56.0`へ更新し、SSH channelの処理が停止する可能性がある既知のサービス拒否問題2件を修正しました。

## ドキュメント

- 日本語・英語のSFTPガイドに、転送履歴の除去、キャンセル時の扱い、スマートフォンの高さ調整を追記しました。
- 日本語・英語のTerminalと設定ガイドに、背景画像使用時の描画方式を追記しました。
- 日本語・英語のCLIリファレンスに、SFTPダウンロードの接続別進捗表示を追記しました。
