# sshc v0.7.2

SFTPの狭い画面で発生する表の折り返しと、履歴画面が読み込み表示から進まない問題を修正したリリースです。

## 修正

- SFTPの「種別」列と「フォルダ」「ファイル」の値を1行で表示するようにしました。
- SFTPの表に必要な最小幅を設け、狭い画面では画面全体ではなく表の中だけを横スクロールするようにしました。
- 履歴と設定概要の取得を独立して処理し、片方が失敗しても「履歴を読み込んでいます…」から抜けるようにしました。
- APIの片方だけが成功した場合は、取得できた履歴または未完了transactionを保持しながら、失敗した要求のerror codeを表示します。

## 検証

- Webのユニットテスト830件、TypeScript型検査、ESLint、production buildを実行しました。
- 履歴API失敗時のloading解除、片方だけ成功した場合の表示、SFTP種別列の折り返し防止を回帰テストで確認しました。
- Playwright E2E 12件を実行し、履歴の実操作、session lifecycle、360pxで全画面がviewport内に収まることを確認しました。

## インストール

```sh
brew install aida0710/tap/sshc
```

```sh

```
