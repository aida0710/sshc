# sshc v0.17.0

Serial／Telnet接続と、大量のSSH接続先を扱いやすくするホーム・Connections再設計をまとめた更新です。

## 変更

- `sshc serial`でSerial deviceの列挙と対話接続、`sshc telnet`で一回限りのTelnet接続を利用できます。
- `sshc run serial|telnet`へJSON automation、expect、timeout、機密値のmask、安定した終了codeを追加しました。
- Linux PTYとlocalhost TCP serverを使い、実binaryからSerial／Telnet transportまで通す仮想E2Eを追加しました。
- ホームのQuick Connectを最近使用順の接続ランチャーへ再構成し、panel／list表示、group filter、接続先addressとuser表示を追加しました。
- マウスではsingle clickで選択、double clickで接続し、touch／keyboardでは1回で接続します。
- Connectionsを分類、検索結果、詳細の3領域へ再構成し、group／file／接続先／userによる絞り込みと並び替えを追加しました。
- 360px画面では接続一覧から詳細へ遷移し、右inspector表示時も編集操作が隠れないようにしました。
- お気に入り機能をmetadata、API、CLI、Web UIから撤去し、接続順と検索・group分類へ一本化しました。

**変更履歴**: [v0.16.5...v0.17.0](https://github.com/aida0710/sshc/compare/v0.16.5...v0.17.0)
