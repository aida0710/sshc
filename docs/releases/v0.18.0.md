# sshc v0.18.0

SSH、Serial、Telnetのコマンド体系を明確にし、コンソール自動操作、接続進捗、SFTPとSSH Keysの画面を改善した更新です。

## CLIコマンド体系の変更

このリリースではCLIの呼び出し方が変わります。SSH aliasは`sshc ssh`の内側だけで解釈され、transportを省略した`sshc <alias>`と旧`sshc run ...`は受け付けません。

- 対話SSH接続は`sshc ssh <alias>`、接続先の選択は`sshc ssh`、一覧表示は`sshc ssh --list`を使用します。
- 非対話SSHコマンドは`sshc ssh <alias> --non-interactive -- <command>`を使用します。
- SerialとTelnetの非対話操作は、それぞれ`sshc serial ... --non-interactive`と`sshc telnet ... --non-interactive`へ統一しました。
- `serial`、`telnet`、`status`などのコマンド名と同じSSH aliasも、`sshc ssh <alias>`として曖昧なく指定できます。

## SerialとTelnetの自動操作

- `sshc serial`でdevice path、USB VID／PID、製品名、serial numberを表示し、`--json`では自動処理向けの安定した形式を返します。
- `--require-output`を追加しました。`--read-for`の時間内に1 byteも受信しなかった場合を成功扱いにせず、終了codeとJSONから判定できます。
- scriptに`onFailure`を追加し、main stepが失敗した場合だけCtrl+Cなど明示した復旧入力を送れるようにしました。復旧処理の結果は元の失敗理由を上書きせず、JSONの`failureCleanup`へ記録します。
- 引数解析、仮想Serial、Telnet、timeout、出力制限、cleanupの回帰テストを拡充しました。

## SSH接続の進捗

- ターミナルとセッション一覧に、通信開始、ホスト鍵確認、認証、セッション開始の現在段階を表示します。
- ProxyJumpを使用する場合は現在の接続先とhop位置も表示し、接続済み状態を明示します。

## SFTPとSSH Keys

- SFTP接続に失敗した場合、全画面の診断エラーへ切り替えず「接続できませんでした」とページ内で案内するようにしました。
- SSH Keysの通常行は「詳細を開く」だけに整理し、操作と公開鍵／秘密鍵の内容を全列幅の詳細行へまとめました。
- 秘密鍵表示の警告、ssh-agent操作、パスフレーズ管理、名前変更、ゴミ箱操作を同じ鍵の詳細領域内に配置しました。
