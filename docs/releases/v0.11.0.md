# sshc v0.11.0

暗号化同期の世代履歴にコミットメッセージを追加しました。

## 変更内容

- 自動同期では、前回確認済みのsnapshotとローカル内容を比較し、追加・変更・削除されたパスからコミットメッセージを自動生成します。
- 手動送信では、同じ自動生成メッセージを初期値として表示し、送信前に編集できます。
- コミットメッセージは暗号化されたmanifest内だけに保存し、S3 object metadataには平文で書きません。
- メッセージをrevision IDの計算対象に含め、改変をsnapshot検証で検出します。
- 暗号化された世代履歴に各コミットメッセージを表示します。v0.10以前の世代は「メッセージなし」と表示します。
- 本文なしで送信する旧クライアントとの互換性を維持し、その場合はサーバー側でメッセージを自動生成します。

## 互換性

manifest schemaはv4です。v0.11.0は既存のv1〜v3 snapshotを読み取れます。v0.10以前のsshcはv4 snapshotを新しい形式として安全に拒否するため、同じバケットを使う端末はv0.11.0へ更新してください。

**変更履歴**: [v0.10.0...v0.11.0](https://github.com/aida0710/sshc/compare/v0.10.0...v0.11.0)
