# sshc v0.26.1

v0.26.1では、SFTPに2ペインでのファイル管理、リモート接続間の転送、ディレクトリ比較を追加しました。

あわせて、CLIからのSFTP転送、macOSでのengine常駐、Syncの再設定、WindowsでのProxyCommand接続を改善しています。

## SFTP

- デスクトップでは、**2つのリモート接続先またはディレクトリを並べて開ける2ペイン表示**を利用できます。各ペインで選んだ接続先と開いていた場所は端末に保存されます。スマートフォンは従来どおり1ペインで表示します。
- ファイルやフォルダーを一方のペインからもう一方へドラッグすると、コピーまたは移動を選べます。異なる接続先の間では2本のSFTP接続で直接データを転送し、ローカル端末に平文の一時ファイルを作りません。同じ接続先内の移動では、可能な場合にサーバー上のrenameを使います。
- 2つのディレクトリを再帰的に比較し、左だけ、右だけ、差分あり、種類不一致を確認できるようになりました。選んだ項目だけを左右どちらかへコピーでき、相手側だけにあるファイルを自動的に削除することはありません。
- 転送キューをengine側で保存するようにしました。待機中、一時停止中、再開可能な転送はengineを再起動した後も復元されます。リモート接続間の転送はブラウザーを閉じても継続します。
- SFTPで開いている場所から同じ接続先のTerminalを開始できます。反対に、接続先がOSC 7で通知した現在のディレクトリをTerminalからSFTPで開けます。
- ファイル一覧、breadcrumb、選択操作、転送ドックの情報密度を調整しました。通常の操作領域を抑え、ファイル名と選択状態を中心に確認できます。

## SFTP CLI

- `sshc sftp get`と`sshc sftp put`を追加しました。通常ファイルに加えて、`--recursive`を付けたフォルダー転送に対応しています。
- 既存ファイルは暗黙に上書きしません。`--overwrite`では実行前に確認し、`--yes`を併用した場合だけ確認を省略します。`--skip-existing`、`--dry-run`、`--json`も利用できます。
- CLIの転送にはWeb UIと同じengine、Vault、OpenSSH設定、Host Key検証、転送キューを使います。`Ctrl+C`でアップロードを中断した場合は、リモート側の一時ファイルも取り消します。

## engineの常駐と更新

- `sshc service install`、`sshc service status`、`sshc service disable`をmacOSのlaunchdユーザーエージェントでも利用できるようになりました。Linuxでは引き続きsystemdユーザーサービスを使用します。
- `sshc service install`、`sshc service disable`、`sshc update`は、変更内容を表示してから確認を求めます。確認を省略する自動処理では、内容を確認したうえで`--yes`を指定できます。
- sshcが作成していないsystemd unitやlaunchd plistは上書きも削除もしません。管理中のサービスが動作している場合は、`sshc update`の完了後に新しいbinaryで再起動します。

## Sync

- `sshc sync pull`が、変更のない空の一覧をengineから受け取った場合に、正常な応答をバージョン不一致として拒否する問題を修正しました。新旧のengineが返す空一覧の表現をCLI側でも安全に扱います。
- `sshc sync setup`では、設定済みのEndpoint、Bucket、Path、Region、Directionを既定値として表示します。Directionは`both`、`push`、`pull`から選べます。
- Access Key IDは末尾5文字だけを伏せ字付きで表示します。Secret Access Keyと同期鍵は値を表示せず、設定済みかどうかだけを示します。再設定時は秘密値を空のままEnterすると、engine内の既存値を維持します。

## SSHと検証

- WindowsでProxyCommandを使用した接続を閉じる際、匿名パイプの読み取り待ちによって終了処理が止まる問題を修正しました。
- SFTP CLIは固定digestのOpenSSHコンテナを使い、1 MiBを超えるファイル、通常ファイル、空ファイル、フォルダーを実際に送受信して内容が一致することを確認しています。
- 日英ドキュメントへ2ペイン表示、ディレクトリ比較、転送キュー、SFTP CLI、macOS常駐、Sync再設定の操作方法と製品画面を追加しました。
