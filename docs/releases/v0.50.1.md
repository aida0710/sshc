# sshc v0.50.1

v0.50.1では、古いsshcが入ったWindowsで、PowerShellのインストーラー（`install.ps1`）が実行ファイルを置き換える前に止まる問題を修正しました。

あわせて、Connectionsを読み込むあいだの表示と、SFTPの画面の余白を改善し、VPNのコンテナイメージに入れるパッケージを更新しています。Includeの並び順によって、グループの共通設定がaliasの重複として警告される問題も修正しました。

## Windowsのインストーラー

- これまでは、v0.48.0より前のsshcが入ったWindowsで`install.ps1`を実行すると、「プロパティ 'failure' が見つかりません」と表示されて止まり、sshcは古いバージョンのままでした。古いsshcは、sshcエンジンに接続できないときに状態を返さないためです。**インストーラーは、入っている`sshc.exe`から動いているプロセスを確かめるように修正しました。** 動いていなければ、そのまま新しいバージョンに置き換えます。
- 入っている`sshc.exe`から動いているプロセスがあれば、`sshc stop`で止めてから置き換えます。止められなかったときは何も置き換えずに止まり、そのプロセスのPIDを表示します。
- v0.48.0より前のsshcがあるアカウントでは、サービスの状態を確かめずに進むようにしました。これまでは、古いsshcが答えられないサービスの状態を確かめようとして、「could not inspect the sshc service」で止まっていました。
- v0.48.0より前のsshcには`sshc stop`がありません。このバージョンのsshcエンジンが動いている場合は、インストーラーが表示したPIDのプロセスを終了してから（`Stop-Process -Id <PID>`）、もう一度実行してください。

## ConnectionsとSFTP

- これまでは、Connectionsを開いてから一覧を読み込むまで「読み込んでいます」だけを表示し、画面の上の帯が消えていました。**読み込むあいだも、帯と一覧・右側の枠を表示するように変更しました。**
- これまでは、SFTPの画面だけ帯の下に余白があり、ファイルの一覧を角の丸い枠の中に表示していました。HomeやConnectionsと同じく画面の幅いっぱいに表示し、ファイルの一覧と転送マネージャーの境目は線だけにしました。ファイルをドラッグしてきたときの強調は、一覧の内側の線で表示します。

## グループの共通設定

- v0.50.0の修正のあとも、`~/.ssh/config`で、グループの共通設定のファイルを読み込むIncludeの行が、接続先のファイルを読み込む行より前にあると、接続先の詳細にaliasの重複の警告を表示していました。**Includeの並び順に関わらず、グループの共通設定の行をaliasの宣言として数えないように修正しました。**

## VPN

- VPNのコンテナイメージに入れるUbuntuのパッケージを、2026年10月20日時点のものに更新しました。これまでは2026年9月20日時点のものでした。VPN機能を使用している場合、次にVPNに接続するときに、コンテナイメージがマシン上で1度だけ作り直されます。作成にはネットワークが必要です。
