# sshc v0.44.5

v0.44.5では、VPN proxyのテストが長時間止まる場合に、5秒で失敗箇所を知らせるようにしました。通信データの転送と、入力終了後も応答を受け取れることを別々に検証します。

あわせて、統合テストの終了時に、ビルドしたsshcと一時ディレクトリを削除するようにしました。いずれも開発・配布前の検証を改善する変更です。

## VPN proxyの検証

- これまではWindowsでまれにテストが20分の上限まで止まることがありましたが、**5秒で失敗を報告するように変更しました。** データの転送と入力終了の通知を別のテストで確認し、どちらで止まったかを分かるようにしています。
- 入力を送り終えた後も、中継からの応答を受け取れることを確認します。Windowsでまれに起きる入力終了の通知の問題は、引き続きテストで検出します。

## 統合テストの後片付け

- これまではテスト用にビルドしたsshcが一時ディレクトリに残っていましたが、正常終了時とビルド失敗時に削除するようにしました。
- ビルドに失敗した場合は、コマンドの出力に加えてエラーの内容も表示します。Goが見つからない場合なども、原因を確認できます。

## Windowsのビルド検証

- 通常テストと並行処理の検査を合わせて30分を超える場合に検証が打ち切られていたため、Windowsの検証ジョブの上限を45分に変更しました。
