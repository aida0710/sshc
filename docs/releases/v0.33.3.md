# sshc v0.33.3

v0.33.3では、スマホでの画面移動、ターミナル入力、SFTPの操作を改善しました。キーボードや転送管理を開いたときも、入力欄やファイル一覧を使いやすい配置にしています。

あわせて、PCを含むHomeとConnectionsの表示を整理し、背景をグレー基調にして選択中の項目を見分けやすくしました。

## スマホでの画面移動と入力

- 下部に **Home／Connections／SFTP／Terminal／Menu** のナビゲーションを追加しました。キーボード表示中はヘッダーと下部ナビゲーションを隠し、入力領域を広く使います。
- ボタンのタップ領域を広げ、ダイアログや操作メニューを画面内に収めました。長い内容は内部をスクロールできます。
- Connectionsはスマホの横向きでも一覧と編集画面を切り替えて使えます。Config Explorerの階層一覧やSnippetsの選択欄も、狭い画面で編集領域を確保する配置に変更しました。

## SFTP

- これまでは転送管理を展開するとファイル一覧が押し縮められていましたが、スマホでは**進捗を示す1行から別のシートを開く方式**に変更しました。転送設定はシート内で展開できます。
- スマホでは名前を1回タップしてフォルダを開くか、ファイルをプレビューします。チェックボックスまたは長押しで選択を始めると、名前のタップは選択の追加・解除になります。
- フォルダ移動や検索中は処理中の表示を出し、古い一覧への操作を一時的に止めます。
- 通常の操作欄を1行にまとめ、追加操作をメニューへ移しました。プレビューの属性情報は必要なときだけ展開できます。

## ターミナル

- 指を離した後も減速しながらスクロールするようになりました。再タッチ、選択開始、画面移動で停止し、OSの「動きを減らす」設定にも従います。
- Ctrl、Esc、Tab、矢印の補助キーを1行にまとめ、横向きでも使えるようにしました。Altや記号は「…」から選べます。
- Androidでキーボードを開いたまま回転したときの入力位置と、タッチ・文字選択の領域を修正しました。

## HomeとConnectionsの表示

- Homeは検索、グループ、接続先を中心に並べ、重複する見出しや空の説明を減らしました。スマホは1タップ、PCは1クリックで選択・ダブルクリックで接続する操作を維持します。接続開始中は進行表示を出し、重複した接続操作を防ぎます。
- Connectionsの接続ボタンを詳細の上部へ置き、フォームの枠や補助情報の重複を減らしました。
- ライト・ダークとも背景、文字、境界線をグレー基調にし、選択と主要操作に控えめな青を使います。OSアイコンは小さな単色表示を維持します。
- Sessionsの見出しと、セッションがない場合の表示の左端を揃えました。

## 更新後

CLIやWebを使う場合は、バイナリ更新後に稼働中のengineも再起動してください。Androidの正式版APKにも今回の画面改善を含みます。

開発版の「sshc Dev」は正式版とは別のアプリです。正式版APKを入れてもDevのデータは自動では移りません。同期する端末は、引き続きすべてv0.33.1以降を使用してください。
