# sshc v0.59.1

v0.59.1では、設定の保存場所を作り直しました。これまでブラウザごとに保存していたテーマ、使うショートカットのプリセット、列の幅なども含め、すべての設定を`~/.ssh/sshc`に保存してSyncで同期します。設定は「全体の設定」「プリセット」「マシンごとの設定」の3つに分かれ、マシンごとにどのプリセットを使うかを選べます。スマホとPCで文字の大きさを変えるといった使い分けが、同期したまま行えます。

あわせて、ターミナルの画面や行が欠ける不具合を直し、プログラムの状態の表示（OSC 7501）、ワークスペースの並べ替え、ファイルのプレビューの拡大とスワイプ、スマホの入力とキーボードの扱い、PCの画面のサイドバーの見た目を改善しています。FreeBSDとOpenBSD向けのCLIも配布を始めました。設定の形を変えたので、更新の前に「更新後に必要な操作」を確認してください。

## 更新後に必要な操作

- **Syncでつないでいるすべてのマシンを、v0.59.1へ更新してください。** v0.59.1はmetadata.jsonを新しい形（schema 10）で書きます。v0.58.1以前のsshcはこの形を読めないため、同期で届いた設定を使えません。v0.58.1が書いたmetadata.jsonは、v0.59.1のsshcエンジンが起動したとき、または同期で届いたときに、自動で新しい形へ移します。
- **ブラウザにだけ保存していた設定は引き継がれません。** 使っていたショートカットのプリセット、通知音、左のナビと接続先の一覧の幅、SFTPのタブと分割、転送マネージャーとHomeの表示形式、ターミナルの実行先、ワークスペースの折りたたみ、［画面を常にオン］、タッチ操作の扱い、更新のお知らせの折りたたみは、既定の値から始まります。テーマと表示言語は、ブラウザに残っている値をそのまま使います。Settingsで選び直すと、その値が同期されます。
- **Vaultの自動ロックの時間は、既定の12時間に戻ります。** 変えていた場合は、Settings → Vaultで設定し直してください。自動ロックは、このマシンだけの設定からプリセットの設定に変わりました。
- **OSC 52（プログラムによるクリップボードへの書き込み）の許可は、Settings → Generalに移しました。** v0.58.1ではSettings → Terminalにありました。許可していた値はそのまま引き継がれます。ターミナルの「…」でも切り替えられます。
- sshcエンジンのポートは、Settings → Machinesでマシンごとに設定するようになりました。v0.58.1で設定していたポートは、そのマシンの設定へ自動で移します。
- 転送マネージャーで「新しい転送の開始を停止」していた場合、更新後は止めていない状態から始まります。止めているかどうかを、どのマシンのものとして移すかが分からないためです。
- FreeBSDとOpenBSDのCLIの名前を確かめる処理がこの2つのOSを知らず、リリースの組み立てが止まったため、v0.59.0は公開していません。

## 設定

- **設定を「全体の設定」「プリセット」「マシンごとの設定」の3つに分け、設定の画面の左の一覧もこの3つに分けて並べました。**
  - 全体の設定（General）: 表示言語、再接続、接続のログ、OSC 52、完了した転送を消すまでの時間、通信が切れた転送の自動再開と回数、背景画像のライブラリの容量です。どのマシンでも同じ値です。
  - プリセット: Appearance、Terminal、SFTP、Keyboard shortcuts、Notifications、Vaultの自動ロックと、画面を常にオン、タッチ操作の扱い、列の幅、Homeの表示形式です。一覧の上の［編集するプリセット］で選んだプリセットを編集します。スマホでは、各ページの上で選びます。
  - マシンごとの設定（Machines）: Syncでつながっているマシンごとに、名前、使うプリセット、sshcエンジンのポートを選びます。
- これまでのEngineのページはMachinesに、Master passwordのページはVault（自動ロックとマスターパスワード）になりました。
- プリセットは［標準］を含めて16個まで作れます。プリセットの値を変えると、そのプリセットを使うマシンに同期で届いたときに効きます。プリセットを削除すると、それを使っていたマシンは［標準］に戻ります。
- ターミナルの実行先、SFTPのタブと分割、ワークスペースの折りたたみ、転送の処理を止めているかどうかは、マシンごとのファイル（`~/.ssh/sshc/machines/`）に保存して同期します。マシンごとにファイルを分けたので、2台が同時に変えても同期で衝突しません。
- SFTPの設定のページで、前の保存の「保存しました」が出ている間に選択肢を変えると、選んだ値が保存されなかった不具合を直しました。

## ターミナル

- **裏に残す数を超えて戻ったターミナルで、一度描いた画面が欠けていた不具合を直しました。** Claude Codeのように画面の変わった所だけを書き直すプログラムでは、描いた部分が再生バッファ（既定256 KiB）から押し出されると、戻ったときに消えていました。これからはtmuxと同じく、sshcエンジンがセッションごとに画面を覚え、作り直すターミナルにその画面を先に送ります。流し直しの先頭に`026h`のような文字の切れ端が出ることもなくなりました。
- **幅の違うブラウザで同じセッションを開くと、長いコマンドの行の途中が消えていた不具合を直しました。** 出力を書いたときの大きさで流し直してから、今の幅に合わせて折り返します。
- **プログラムの状態の知らせ（OSC 7501）に対応しました。** 対応したプログラムが知らせる作業中・入力待ち・完了・失敗を、サイドバーのセッションの行の印と2行目の文に出します。作業中と入力待ちは続いている間ずっと、完了と失敗はそのセッションを表示するまで出ます。
- ターミナルの上の2本の指のピンチと、Ctrlを押しながらのホイール（トラックパッドのピンチを含む）で、文字の大きさを8〜32pxの間で変えられるようにしました。変えた大きさはそのターミナルの表示だけに効き、保存しません。
- ワークスペースを、ドラッグと「…」の［上へ移動］［下へ移動］で並べ替えられるようにしました。並びはsshcエンジンに保存されます。
- 実行先を切り替えたとき、その実行先で最後に開いていたセッションを開くようにしました。閉じていれば、サイドバーの一番上のセッションを開きます。これまでは一覧の先頭のセッションが選ばれていました。
- 接続が切れたあとの知らせを1本にしました。これまでは理由の帯と終わりの帯が重なり、見出しでも同じ状態を別の言葉で繰り返していました。終了コードが分からないときに「終了コード-1」と出していたのも、「終了コードは分かりませんでした」にしました。
- 新しいセッションを開いたとき、ターミナルの大きさを2回送り、シェルや全画面のプログラムが2回描き直していたのを、1回にしました。

## スマホとタッチ

- **スマホでセッションを開いたとき・表示中のセッションを閉じたときに、キーボードを自動で開かないようにしました。** ［新しいセッション］と実行先の切り替えを開いたときも、検索欄からキーボードを開きません。
- **スマホでターミナルをタップすると、下の入力欄にフォーカスするようにしました。** 日本語を入力欄で変換してから送れます。入力欄で打っている途中にキーバーのCtrl・Altを押すと、次のキーはターミナルへ送ります。
- ターミナルの上から始めた横のスワイプでも、サイドバーを開くようにしました。長押しのあとの指の移動と、選んだ文字の上から始めたスワイプは、これまでどおり文字の選択になります。
- スマホのサイドバーからConnections・SFTP・Menuを外し、Homeだけを置きました。どれも下のバーから開けます。見えるセッションの行が増えます。
- Menuから開いたページでは、下のバーのMenuを選んだ表示にしました。スマホのMenuの上には検索の入口を置きました。
- スマホのHomeで、検索欄を行いっぱいにし、［パネル｜リスト］を件数の行の右に小さく置きました。
- タッチ画面付きのPCで、マウスを乗せてもサイドバーの行の「…」と「×」が出なかった不具合を直しました。

## 画面の見た目

- **PCの大きさの画面で、左のサイドバーを本文と同じ角丸・枠・影の板にし、窓の端から少し離して浮かせました。** これまでは、サイドバーが窓の端に付いた角のある板で、本文だけが角丸でした。スマホで引き出すサイドバーは、これまでどおり画面の端まで届きます。
- Homeのカードで、最終接続を名前の横の札（今日・昨日・3日前など）にし、カードの高さをそろえました。日時の全部はツールチップで見られます。グループに入っていない接続先に「グループなし」の札を出さないようにしました。
- Homeのカードを右クリック（スマホでは長押し）すると、「…」と同じメニューを開くようにしました。
- Homeの「確認が必要」は、直す必要のある注意だけを数えるようにしました。SSH Configの設定ファイルの問題、接続先の注意、途中で止まった変更の3つを種類ごとに書き、SSH Config・Connections・Historyへのボタンを文の下に置きます。
- ロック解除と作成の画面のサインアウトを、小さいリンクにしました。何が起きるかは、押したあとの確認で説明します。Syncの未設定の画面の長い説明は、1行の要約と［詳しく］にしました。

## SFTPとファイルのプレビュー

- **プレビューで画像と動画を拡大できるようにしました。** ホイール、ダブルクリック、拡大中のドラッグ、2本の指のピンチで操作し、最大8倍です。見出しの［前へ］［次へ］［ダウンロード］［閉じる］はアイコンにし、名前はツールチップで見られます。
- 拡大していない画像と動画を指で左右にスワイプすると前後のファイルへ移り、下へスワイプすると閉じるようにしました。SFTPの詳細のプレビューにも［前へ］［次へ］を付けました。
- SFTPの空のペインに、このマシンと最近の接続先を最大4件並べ、1回で開けるようにしました。ペインが1つの間は、タブの帯の右に［左右に並べる］を置きました。接続先を選ぶ前のペインには、パスの帯を出さないようにしました。
- 動画と音声のファイルが見つからないとき、「再生できない形式」ではなく「ファイルが見つかりません。」と出すようにしました。

## そのほか

- 検索（Ctrl+K）で、同じ種類の中を名前の一致の度合い（同じ → 始まる → 単語の頭 → 途中）で並べるようにしました。
- Known Hostsで、ハッシュ化したエントリに、その鍵を持つ保存した接続先の名前を「bastion（ハッシュ済み）」のように出すようにしました。
- Diagnosticsの設定ファイルの一覧を、`~/.ssh`からのパスで出すようにしました。
- ssh-agentに届かないときの案内を、sshcエンジンのOSに合わせた手順だけにしました。接続先の編集のタブ、SSH ConfigのIncludeの木、開けなかったセッションの行の文も短くしました。
- 実行先のsshcエンジンを起動し直したとき、まれにこのマシンの中継のポートが変わっていた不具合を直しました。
- sshcの更新を止めたとき、まれに「中断」ではなく「更新できません」と表示されていた不具合を直しました。

## FreeBSD・OpenBSD

- **FreeBSDとOpenBSD（amd64・arm64）向けのCLIを配布するようにしました。** インストールスクリプトは、curlもwgetも無ければFreeBSDの`fetch`、OpenBSDの`ftp`で取得し、`sha256 -q`でSHA-256を確かめます。手順は[インストールガイド](https://aida0710.github.io/sshc/guide/install#freebsd--openbsd)にあります。
- `sshc service install`には対応していません。sshcエンジンを常に動かすときは、tmuxやscreenの中で起動してください。
