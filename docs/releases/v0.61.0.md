# sshc v0.61.0

v0.61.0では、接続先をまとめて開く操作、出力を待ってから送る接続時の自動実行、ターミナルの出力をファイルに残すセッションのログを追加しました。SSH Configのファイルや接続先のHostブロックなどの文字の欄も、SFTPの編集と同じエディタで編集できるようになりました。

あわせて、接続先とリモートセッションの点検で見つかった不具合、ターミナルのペイン名と進み具合の表示、ドキュメントを改善しています。

## 接続先をまとめて開く

- Connectionsで2件以上選んだときの帯と、グループの「…」に［すべて接続］を追加しました。一覧に並んでいる順に1つずつセッションを開き、最初に開いたセッションを表示します。グループの［すべて接続］は、中のグループの接続先も開きます。
- 開く先は［接続］と同じで、選んでいるsshcエンジンの［メイン］のワークスペースです。同じ接続名の接続先は1つだけ開きます。
- 開く数が、あと開けるセッションの数を超えるときは押せません。開けなかった接続先は、理由ごとにまとめてサイドバーに出します。Vaultがロックされたリモートセッションでは、解除したあとにまとめて開きます。

## 出力を待ってから送る接続時の自動実行

- スニペットの［種類］で［手順］を選べるようにしました。［手順］では「待つ文字列・送る文字列・Enterを押す・省略可」の行を並べます。**接続時の自動実行で、待つ文字列がシェルの出力に出てから、送る文字列を打ち込みます。** sudoのパスワードや、ネットワーク機器のenableのように、問いが出てから次を送る接続先で使えます。
- 待つのは認証が済んだあとのシェルの出力だけです。sshcが出す認証の問いや`[sshc]`の行には答えません。色などの制御の文字を外した出力に待つ文字列が含まれたら送り、正規表現は使いません。
- ［待つ時間の上限］（既定10秒、最大300秒）のうちに待つ文字列が出なければ、そこで止めて、ターミナルに`[sshc]`の1行で知らせます。［省略可］の手順は飛ばして次へ進みます。自動再接続のたびに、はじめからやり直します。
- 手順のスニペットは、接続時の自動実行でだけ使えます。複数の接続先での実行と、ターミナルへの送信には出ません。

## セッションのログ

- ［Settings］→［General］に［セッションのログをファイルに保存する］（既定はオフ）を追加しました。**オンにすると、セッションごとに1つのファイルへ、ターミナルに出た行を文字で書き続けます。**
- 書くのは、画面の上へ流れた行と、消す前の画面の行、セッションの終わりに画面に残っていた行です。Claude Codeのように同じ所を描き直す画面は、描き直したあとの形だけが残ります。vimやtmuxのような全画面のプログラムの中身は書きません。
- SSHのセッションでは、認証が済んだあとのシェルの出力だけを書きます。パスワードの問いと、そこへ打った値は書きません。スニペットのシークレット変数の値は`[secret]`に置き換えます。接続・切断・再接続・セッションの終わりは、日時付きの`[sshc]`の行で書きます。
- ［保存しない接続先］に、ログを書かない接続名のパターンを.gitignoreと同じ形で書けます（`!`で始めた行は書く側へ戻し、あとの行が勝ちます）。ローカルシェルは`@local`です。
- 置く場所は、Linux・BSDは`~/.local/state/sshc/session-logs`、macOSは`~/Library/Logs/sshc/sessions`、Windowsは`%LOCALAPPDATA%\sshc\session-logs`です。［Machines］のマシンの「…」の［ログの保存先を変更…］で、マシンごとに変えられます。ログはほかのマシンへ同期しません。リモートセッションのログは、そのセッションが動いているマシンに書きます。Androidではログを保存しません。

## 文字の欄のエディタ

- これまでは、SSH Configのファイル、接続先の［テキストで編集］、VPNの設定ファイル、同期除外ルール、転送の除外パターン、スニペットのコマンドは、ただの文字の欄でした。**SFTPの編集と同じエディタ（Monaco）に変更しました。**
- ssh_configの欄では、ディレクティブ、値、コメントを色分けし、行の先頭で`Ctrl+Space`を押すとディレクティブの名前の候補を出します。SSH Configのファイルでは、OpenSSHが知らないディレクティブなど、設定を読んだときに見つかった問題の行に印を付けます。
- ssh_configの欄では`Tab`で字下げします。ほかの欄では`Tab`で次の欄へ移り、長い行は折り返します。

## 接続先とリモートセッション

- これまでは、接続先の名前を変えたり消したりしても、それを踏み台（ProxyJump）にしているほかの接続先は古い名前のままでした。**名前を変えると、ほかの接続先の踏み台の名前も同じ保存で書き換える**ように変更しました。削除の確認には、消す接続先を踏み台にしている接続先を出します。踏み台の欄に、保存した接続先に無い名前を書くと注意を出します。
- 踏み台で接続が止まったときは、「踏み台のjump（1/2）に接続できませんでした。」のように、どの踏み台かを理由の前に出すようにしました。
- 打ったパスワードが拒否されたときは、OpenSSHと同じ「Permission denied, please try again.」を出してから尋ね直すようにしました。
- 再接続の途中でパスワードなどの入力を待っているときは、見出しと帯に「入力待ち」と出すようにしました。
- リモートセッションの先のホスト鍵が変わった・失効したときは、その理由と直し方を出すようにしました。
- ロック中や接続できないリモートセッションを選んでいるときにその行を押すと、ロックの解除のダイアログか、ターミナルの領域の断りのパネルへ移るようにしました。Vaultのロックで開けなかったセッションは、解除したあとに開きます。
- リモートセッションを切り替えたときは、［リモートセッション］とターミナルの領域に、接続の段階と経過秒数を出すようにしました。応答しないsshcエンジンを待つあいだも、このマシンの画面は待たせません。
- リモートのsshcエンジンに届かないことの知らせが、つながったあとまでサイドバーに残る不具合を修正しました。

## ターミナル

- ローカルシェルで1秒以上動いているコマンドの名前を、ペイン名の前に出すようにしました（例: 「sleep · aida@r540: ~」）。LinuxとmacOSだけです。［Settings］→［Terminal］の［操作］の［ペイン名に実行中のコマンドを出す］で切り替えられます。
- 新しいセッションの一覧のローカルシェルを1つにしました。開くシェルは［既定のローカルシェル］で選んだもので、選んでいなければシステムのログインシェルです。
- OSC 9;4の進み具合は、見出しでは地の線付きの線で、セッションの一覧では接続の点の代わりの輪で出すように変更しました。
- プログラムが右端で改行して折り返した長いURLを、1つのURLとして開くようにしました。
- セッションの一覧の接続の点を、Claude Codeなどの状態の印と同じ大きさにしました。ダークのテーマでスクロールバーの横に白い縦線が出る不具合を修正しました。

## そのほか

- 空のグループ名で作ろうとしたときは「名前を入力してください。」と出すようにしました。セッションの行の「接続先が切りました」を「接続先が切断しました」に直しました。
- ドキュメントで「実行先」を「リモートセッション」に改名し、ホームの先頭に載せました。Terminal、SFTP、VPN、ポート転送、踏み台、同期のページに図を足し、長い段落を表や箇条書きに分けました。

## 更新後に必要な操作

- スニペットを保存するファイルの形式のバージョンを上げました。同期しているマシンを全部v0.61.0に更新するまで、古いsshcは同期したスニペットを読めません。
- セッションのログの設定と保存先は、v0.61.0より前のsshcでは読めないか、そのsshcが設定を書き直すと消えます。同期しているマシンを全部更新してから設定してください。
