# sshc v0.20.1

非対話のProxyJump認証を修正し、画面と接続ログの日本語を全面的に整えたパッチリリースです。

## 非対話SSH認証

- `sshc ssh <alias> --non-interactive -- <command>`で、保存済みパスワードを現在のProxyJump経路に正しく適用するよう修正しました。
- 非対話接続でホスト鍵確認を安全側へ強制しても、保存時に確認した認証経路との照合結果が変わらないようにしました。
- 対話・非対話接続の警告と復旧案内を統一し、認証に失敗したaliasを判別しやすくしました。
- 接続進捗の不要な空行を削除しました。

## 日本語表示

- Terminal、Connections、Groups、SSH Keys、Known Hosts、Remote Keys、Sync、Diagnostics、Vaultの説明と操作名を見直し、直訳調や意味の曖昧な表現を整理しました。
- SSH ConfigのInclude対象外となったファイルについて、OpenSSHに読み込まれない理由と必要な操作を明記しました。
- 「握手が通りませんでした」などの接続表示を、SSHハンドシェイク、接続、再接続の意味が明確に伝わる表現へ変更しました。
- 接続タイムアウトとキャンセルは、`context deadline exceeded`などの内部表現ではなく日本語で表示します。
- 数量表記、空白、助数詞、句読点を画面全体で統一しました。
