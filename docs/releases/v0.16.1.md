# sshc v0.16.1

Workspaceと設定画面の操作性を整え、狭い画面でも主要操作が見えるようにした更新です。

## 変更

- ローカルシェルを最大4 paneのWorkspaceへDrag & Dropし、比率・Focus Mode・名前付きlayoutを保存、復元できるようにしました。
- console一覧は状態と接続先を含む主領域全体をクリックして選択できます。
- 同期設定をchevron付きの親ブロックへまとめ、BucketとSnapshotの階層を明確にしました。
- vault作成・解錠前にも外観と言語を変更できるようにし、ライトテーマの境界を明瞭にしました。
- 360pxの同期サマリーを縦並びにして、長い状態名の重なりを解消しました。
- SFTPのモバイル一覧をカード表示へ変更し、download、権限変更、rename、deleteを横スクロールせず操作できるようにしました。
- consoleの行メニューを、利用可能な空間に応じて上または下へ開くようにしました。
- 保存済みlayoutの入口へchevronを追加しました。
- 小さい補助文字と操作境界のコントラストを改善し、ライト・ダークの双方を自動検査するようにしました。
- 操作できない領域に付いていたhover表現を除き、クリック範囲との食い違いを減らしました。

Broadcast Commandは従来どおり、接続中のSSH terminalだけを対象にします。ローカルシェルへcommandは送信しません。
