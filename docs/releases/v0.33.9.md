# sshc v0.33.9

v0.33.9では、SFTPのディレクトリ削除とファイルのダウンロード開始を改善しました。

## SFTP

- 中身のあるディレクトリを削除できるようにしました。削除は転送マネージャーのキューで処理し、確認後に進行状況を表示します。
- 削除完了後に現在のディレクトリ一覧を更新します。手動の「ディレクトリを更新」ボタンも追加しました。
- 約10MBなど分割転送の対象外のファイルでも、SFTPの並列読み取りを使います。通信の往復が遅い接続で、ダウンロード開始までの待ち時間を短縮します。

## 更新後

Webではバイナリ更新後に稼働中のengineを再起動してください。Androidでは正式版APKを更新してください。
