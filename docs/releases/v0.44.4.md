# sshc v0.44.4

v0.44.4では、Homebrew版もWeb画面から更新できるようになりました。これまではターミナルでの更新を案内していましたが、画面で確認してからHomebrew経由で更新できます。

あわせて、実際にインストールされたバージョンを記録し、再起動後の更新結果をそのバージョンで確認するようにしました。

## Homebrew版のWeb更新

- macOS・LinuxのHomebrew版で、新しい安定バージョンがあると「sshcを更新」ボタンが表示されます。確認後に`brew upgrade`を実行し、sshcを再起動します。
- Homebrewは更新時の定義に従うため、確認画面より新しいバージョンが入る場合があります。**更新結果には、実際に入ったバージョンを表示します。**
- 新しいバージョンが入らなかった場合は、更新を成功扱いにせず、`brew update`を実行してから再確認するよう案内します。
