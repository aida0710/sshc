# sshc v0.5.2

Web UI の構成と操作性を見直したリリースです。

## 改善

- Home、Connections、Config、Keys、Groups、Known Hosts、Install Key、Ad hoc checks、Secrets、Sync、History、Settings、Terminal の情報配置と操作階層を整理し、画面間の表現を統一しました。
- Home は接続先を最初に選べる構成とし、Connections、Config、Keys などの管理画面は対象と操作の関係を追いやすいワークスペース形式へ変更しました。
- デスクトップのサイドバーを表示・非表示にできるようにし、横幅も調整できるようにしました。表示状態と横幅はブラウザに保存され、次回の起動時に復元されます。
- モバイルでは専用のナビゲーションを維持し、全画面を 360px 幅で検証して横方向のはみ出しや主要操作の欠落がないことを確認しました。
- Terminal に未接続時の案内と、接続中のセッション情報を表示する領域を追加しました。

## インストール

```sh
brew install aida0710/tap/sshc
```

または:

```sh
curl -fsSL https://raw.githubusercontent.com/aida0710/sshc/main/install.sh | sh
```
