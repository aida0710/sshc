# sshc v0.45.0

v0.45.0では、SFTPのタブ、検索、転送一覧を整理し、ファイル一覧を広く使えるようにしました。スマートフォンでも操作しやすい大きさを保ち、縦向きと横向きの両方でファイルを選べます。

あわせて、フォルダ転送の除外指定、テキストの行差分、ローカルファイルの編集・画像プレビュー、RemoteForwardを追加しています。

## SFTPの一覧とタブ

- これまではタブの下にも接続先を表示していましたが、**フォルダ名と接続先をタブへまとめました。** タブ内から接続先を変更でき、タッチ操作でタブの文字が欠ける問題も修正しました。
- ローカルとリモートで操作欄と一覧の開始位置を揃えました。リモートの検索対象は必要なときに開いて設定でき、狭いPCの一覧では主要な列を表示します。権限や所有者・グループは詳細から確認できます。
- ローカルのフォルダにも［ここでターミナルを開く］を追加しました。表示中のフォルダを開始位置として、engineが動くマシンのシェルを開きます。
- スマートフォンでは左右の区分を使わず、すべてのファイルタブを一列に表示します。接続先・フォルダ・選択状態を保持し、PCへ戻ると元の左右配置を復元します。比較する2つのタブも選べます。
- スマートフォンの選択操作と検索は、同じ操作欄を切り替えて表示します。タブの操作領域は44px以上、ファイル行は56px以上とし、横向きでも一覧の高さを確保しました。

## 転送の表示と除外指定

- これまでは転送1件ごとに縦長の表示を使っていましたが、名前・転送経路、容量・速度・残り時間・状態、操作を横にまとめ、下に進捗バーを表示するようにしました。フルパスとエラーは、各行の詳細から確認できます。
- 転送設定を別のダイアログへ移し、速度と復旧、同時実行と完了項目、分割転送、除外ルールに分けました。キューが空、または折りたたまれているときも開けます。
- **フォルダ転送に除外パターンを指定できるようになりました。** 例えば `.git`、`node_modules`、`*.log` を指定すると、一致した項目を転送しません。初期設定では何も除外しません。
- 除外指定はWebのフォルダアップロード・コピー、engine側のローカルディスクとのフォルダ転送、ZIPダウンロード、CLIの再帰的な `get`／`put` で共通して使います。キュー登録時の指定を保持するため、あとから設定を変えても登録済みの転送には影響しません。
- ワイルドカードは `*` と `?` に対応し、64件まで保存できます。明示的に選択した単一ファイル、移動、削除には適用しません。詳しい指定方法は[転送マネージャー](https://aida0710.github.io/sshc/sftp/transfers)で確認できます。

## ファイルの編集と行差分

- ローカルの2 MiB以下のUTF-8テキストを編集し、詳細から画像をプレビューできるようになりました。エディタでは `Ctrl/Cmd+S` で保存できます。
- ローカル保存では、外部で変更・差し替えられたファイルや、転送中のファイルを上書きしません。所有者・グループ・アクセス権・拡張属性を保持し、取得や保持ができない場合は保存を拒否します。Windowsの通常の監査設定（SACL）は保持の対象外です。
- 比較結果の［行ごとの差分］から、左右のUTF-8テキストを読み取り専用で確認できます。各ファイルは2 MiBまでで、片側にないファイルは空として表示します。狭い画面では差分を縦に表示します。

## RemoteForward

- SSH接続先のポートから、engineが動くマシン経由で指定した宛先へ通信を転送できます。接続設定の `RemoteForward`、CLI、実行中のSSHターミナルに対応しました。
- 待ち受けはSSH接続先の `127.0.0.1` に限定します。サーバー側の転送許可が必要で、待ち受けを拒否された場合は転送の失敗を表示し、ターミナル接続は続けます。
