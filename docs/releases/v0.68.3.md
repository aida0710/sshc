# sshc v0.68.3

v0.68.3では、スマホやタブレットのターミナルで、プログラムがリンクとして出力した文字をタップしたときに、プログラムの指定した行き先を開けるように改善しました。

## ターミナルのリンク

- Claude Codeのように、出力するURLに行き先の情報（OSC 8のリンク）を付けるプログラムがあります。これまでは、スマホやタブレットでタップしたときにこの情報を使わず、画面に見えている文字だけからURLを読み取っていました。**タップした文字にOSC 8のリンクが付いていれば、プログラムの指定した行き先を開くように変更しました。** PCでのクリックは、これまでもこの行き先を開いています。
- この変更で、何行にも分かれたURLも、どの行をタップしても全体が開きます。v0.68.2までは、URLが画面の右端で折り返し、続きの行に`/`や`=`などの記号が1つも無いときに、1行目の終わりまでしか開けませんでした。
- 表示の文字がURLではないリンク（文字と行き先が別のもの）も、スマホやタブレットでタップして開けるようになりました。
- OSC 8のリンクを付けないプログラムが出力したURLは、これまでどおり画面の文字から読み取ります。続きの行に記号が無い形で折り返したURLは、1行目の終わりまでです。
- ブラウザで使う場合は手元のsshcを、Androidアプリではアプリをv0.68.3に更新すると、この変更が入ります。リモートセッションの接続先のsshcを更新する必要はありません。
