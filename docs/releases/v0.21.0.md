# sshc v0.21.0

Terminalを日常の作業場所として使い続けるための操作、復元、通知、ポート転送をまとめて追加し、Snippetと同期の保護を強化した更新です。

## TerminalとWorkspace

- split構成、比率、選択pane、SSH接続とローカルシェルをWorkspaceとして保存し、Homeから新しいセッションとして再オープンできます。一部の接続に失敗しても、開けたpaneは維持します。
- URLとリモートpathをTerminalから操作し、リンクを開くほか、対象pathをSFTPで表示できます。
- Quick CommandsでSnippetを現在のpaneへ挿入、実行、コピーできます。実行前のpreviewとprocess世代を照合し、別セッションへ誤送信しません。
- 検索barをTerminalへ重ねて表示し、大文字小文字、正規表現、全一致highlightに対応しました。検索の開閉でTerminalの高さを変えません。
- OSC 52によるクリップボードコピー、kitty keyboard protocol、JIS配列の円記号入力、WebGL描画と安全なfallbackに対応しました。
- エージェントの完了と確認待ちを未読表示し、対象paneへ移動できます。ブラウザ通知と通知音は状態別に選択できます。
- ローカルシェルのprofileを選択でき、Terminalの操作を自動化する`sshc terminal list/show/read/send/wait/create/rename/close`を追加しました。

## ポート転送

- ConnectionsにLocalForwardとDynamicForward（SOCKS5）の設定画面を追加しました。
- 接続中のSSH transportを再利用して、一時的なLocal／SOCKS転送をTerminalから開始、停止、保存できます。
- listenerはloopbackへ限定し、SOCKS交渉期限と同時接続数の上限を設けています。同じマシン上の別利用者を隔離する境界ではないことも画面に明記しました。

## Snippet、Vault、同期の保護

- Snippet libraryとstartup bindingを既存のmaster keyで暗号化し、旧版の平文データをunlock後に原子的に移行します。
- master password変更、Vault復元、remote syncで暗号化鍵の世代を揃え、別端末では受信側のmaster keyで再暗号化します。
- 同期履歴のreplay、暗号文によるKDF負荷、異なる鍵世代からの復元、過大なVault／Snippet文書に対する上限を強化しました。
- Vault lockを同一originの画面間で通知し、復帰時は再確認が完了するまでsecret操作を閉じます。

## 画面の仕上げ

- Menuを専用ページへ整理し、Connections概要、Config Editorのモバイル保存操作、wide desktopのカテゴリ配置を調整しました。
- Terminalを含むスクロールバーを細い角丸表示にし、スマートフォンと強制カラー環境ではOS標準の表示を維持します。
- 存在しない色utilityをsemantic tokenへ置き換え、テーマによって文字や境界線が欠ける箇所を修正しました。
