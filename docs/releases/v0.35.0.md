# sshc v0.35.0

v0.35.0では、Terminalがシェルやコーディングエージェントの送る標準のエスケープシーケンスでペイン名の更新と通知を行うようになり、専用のplugin連携を廃止しました。自動再接続を途中で止める操作、セッション一覧の接続先ピッカー、Connectionsの列幅変更を追加し、SFTPのローカルとリモートを同じ一覧に統一しています。

## Terminalのタイトルと通知

- シェルやプログラムがOSC 0／1／2で設定したタイトルを、ペインの見出し、セッション一覧、コマンドパレットの表示名に反映します。利用者が固定した名前があればそちらを優先し、空のタイトルで接続名へ戻ります。再接続後は新しいシェルのタイトルを待ちます。
- OSC 9（iTerm2形式）、OSC 99（kitty形式）、OSC 777（rxvt／tmux形式）の通知を「端末からの通知」として扱います。別のペインを見ている間やタブがバックグラウンドの間に届くと未読の印を付け、許可していればブラウザー通知と通知音を出します。BELだけの出力は通知にしません。
- Claude CodeやCodexは、それぞれの標準設定（iTerm2形式／OSC 9）で通知を送れます。設定手順は「タイトルと通知」ページにまとめました。
- **廃止**: sshc-agent-bridge向けの独自OSC 6973連携（エージェント状態の表示、会話名、再開API、`sshc terminal wait --for agent-*`）を削除しました。通知音の設定は1種類に統合し、保存キーが`sshc.terminal-notification-sound.v1`に変わります。以前の通知音の設定は引き継がれないため、［Settings］→［Notifications］で選び直してください。

## Terminalとセッション一覧

- 自動再接続の待機中に、ペイン上部の**「再接続を止める」**で打ち切れるようにしました。止めたセッションは終了状態で一覧に残り、手動の「再接続」か閉じる操作だけができます。
- セッション一覧の「Local shell」ボタンとプロファイルの選択を**「新しいセッション」**に置き換えました。SFTPの接続先選択と同じダイアログから、Local shell、検出したシェルプロファイル、SSHホスト（検索・最近の接続・グループ付き）を選べます。
- コマンドパレットで「ホストへ接続」を「開いているセッション」より先に並べます。
- Menuの「キーコンフィグ」を他の項目と同じ「Keyboard shortcuts」表記に揃えました。

## Connections

- グループ／一覧／詳細の境界2本をドラッグと矢印キー（Shiftで大きく、Home／Endで最小・最大）で変えられるようにしました。幅はブラウザーごとに保存します。

## SFTP

- ローカル（sshcエンジン側）とリモートのファイル一覧を同じ実装に統一しました。ローカルでも絞り込み、右クリック／長押しメニュー、行のドラッグ（リモートへ落とすとアップロード、リモートの行をローカルへ落とすとダウンロード）が使えます。更新ボタンの位置が左右で違っていた問題も解消しています。
- **ブックマークと最近開いたパス**（★「場所」メニュー）を削除しました。戻る・進むの履歴と、パスバーからの直接入力で移動してください。
- 絞り込み欄の横にあったドロップの案内文を削除しました。

## 修正

- 既定のキーボードショートカットを選んだままでも、ブラウザーの保存領域に選択を書き込んでいた問題を直しました。利用者が明示的にプリセットを選んだときだけ保存します。

## 内部の変更

- Web（`App`、Keys、Terminal、SFTPの転送キュー、Sync、Workspace）とエンジン（`internal/sftp`、`internal/httpserver`、`internal/remotesync`、`internal/secret`、CLI）の大きなファイルを責務ごとに分割しました。動作は変えていません。

## 更新後

Webではバイナリ更新後に稼働中のengineを再起動してください。Androidでは正式版APKを更新してください。
