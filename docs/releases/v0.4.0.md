# sshc v0.4.0

デスクトップアプリを廃止し、CLI とフォアグラウンドで動作するエンジンへ構成を統一したメジャーアップデートです。

## 重要な変更

- `sshc headless` を `sshc engine` に変更しました。
- macOS の app bundle、DMG、Linux AppImage、Windows インストーラの配布を終了しました。
- Homebrew cask を廃止しました。CLI の formula は引き続き利用できます。
- デスクトップアプリに依存していた Touch ID による vault のロック解除を削除しました。
- vault は 12 時間操作がない場合に自動的にロックされます。

エンジンはフォアグラウンドで起動します。常駐させる場合は tmux、systemd、launchd などを使用してください。

```sh
sshc engine
sshc
```

## 新機能

- ターミナルのカラーパレットを 6 種類から選択できます。
- JetBrains Mono を同梱し、ターミナルのフォントを選択できます。
- 全体または接続ごとに背景画像とオーバーレイ濃度を設定できます。
- エンジンの待受ポートを CLI または設定画面から指定できます。
- `sshc engine --replace` で実行中のエンジンを置き換えられます。
- SSH 接続が予期せず切断された場合に自動再接続します。
