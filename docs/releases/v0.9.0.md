# sshc v0.9.0

SFTPのupload／downloadを一つのTransfer Managerへ統合し、大量転送を操作・監視しやすくしたリリースです。

## SFTP Transfer Manager

- file／folder、upload／downloadを共通queueで管理し、network転送を同時2件までに制限します。
- fileごとに転送bytes、速度、残り時間、status、試行回数、失敗理由を表示します。
- pause、resume、retry、cancelを共通化し、folder batchでは成功済みfileを保ったまま失敗fileだけ再実行できます。
- SFTP画面から移動しても転送を継続し、完了・失敗をApp内通知で知らせます。

## 安全な再開

- uploadは対象と同じremote directoryの一時fileへ送り、remote側の転送済みsizeから再開します。
- 完了時にrevisionを再検証し、atomic renameでだけ本来のfile名へ公開します。cancel時は一時fileを削除します。
- file downloadは通信断後にHTTP Rangeで受信済みoffsetから自動再開します。
- folder ZIP downloadは共通queueで操作できますが、resume時はarchiveを先頭から作り直します。

## 検証

- Go unit／race、Android向けbuild、deadcode、Web unit、TypeScript型検査、ESLint、production buildを実行しました。
- Playwright E2Eを実バイナリと隔離HOMEで実行し、共通queue、別画面でのbackground転送と通知を確認しました。
- 固定digestのOpenSSH containerと64 MiB超のfixtureを使い、remote offset resume、atomic complete、Range download、SHA-256一致、cancel cleanupを確認しました。
- UIをdesktopと360px幅で撮影し、Transfer Managerの情報と操作が横移動なしで判読できることを確認しました。
