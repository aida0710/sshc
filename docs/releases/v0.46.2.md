# sshc v0.46.2

v0.46.2では、ターミナルに貼り付けたときの確認が、開いた直後に消えてしまう問題を修正しました。

あわせて、確認を取り消す場面を、再接続で新しいシェルに替わったときなどに絞っています。

## ターミナルの貼り付け

- これまでは、改行や制御文字を含む貼り付けの確認を開いているあいだにターミナルへ出力が届くと、確認を取り消していました。Claude Codeのように、フォーカスが外れたときや処理中に画面を描き直すプログラムでは、**確認が一瞬表示されてすぐに消えていました。** 確認中に画面の表示が変わっても、確認を開いたままにするように修正しました。
- 確認を取り消すのは、セッションが終了したとき、ブラウザとengineの接続が切れたとき、再接続で新しいシェルに替わったときです。替わる前のシェルへ送るつもりで確認していた内容を、新しいシェルへ送らないためです。
