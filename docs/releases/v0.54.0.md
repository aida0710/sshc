# sshc v0.54.0

v0.54.0では、ターミナルを並べて使う「分割表示」を作り直しました。最大4ペインの分割を複数持ち、サイドバーから切り替えます。

実行先のsshcエンジンに接続できないときは、ターミナルの領域に理由と次の操作を表示するようにしました。Vaultのパスワードの入力や接続先の更新も、その場でできます。更新の出力は、接続先の更新でもこのPC自身の更新でも、動いている間から画面に流れます。

ほかに、ターミナルに出たパスを押して画像を開くときに拾えるパスの書き方を広げ、サイドバーとキー操作も直しています。

> **実行先を使っている場合:** このリリースから、実行先との組み合わせをsshcのバージョンではなく互換の番号で確かめます。実行先として使う接続先も、一度だけv0.54.0以降に更新してください。更新は、ターミナルの領域に出る更新のボタンからできます。

## 分割表示

- **SSHとローカルシェルのセッションを、最大4ペインに並べられるようにしました。** サイドバーのセッションを、表示中のターミナルの上下左右へドラッグして並べます。ターミナルの見出しやセッションの［…］の［右に分割して表示］［下に分割して表示］からも並べられます。
- 分割はサイドバーの SPLIT VIEWS に「分割 1」「分割 2」…として並び、選ぶと切り替わります。最大8グループまで作れます。同じ実行先のセッションなら、別のワークスペースのものも並べられます。
- 仕切りのドラッグで大きさを変え、見出しのボタンでペインの入れ替え、1つを大きく表示、ペインを閉じる操作ができます。ペインを閉じてもセッションは終了しません。
- 分割は保存しません。ページを開き直すと、分割していない状態に戻ります。

## ターミナルのパス

- **`~/shots/a.png`のような`~/`で始まるパスを、そのセッションのホームフォルダから開くようにしました。** これまでは作業フォルダの後ろにつないで、`/home/…/~/shots/a.png`のような無いパスを開こうとしていました。ホームフォルダは、ローカルシェルならsshcエンジンのマシン（実行先で開いたシェルならその実行先）、SSHのセッションなら接続先から調べます。`$HOME/…`と`${HOME}/…`も同じように開きます。
- **日本語などの名前を含むパスを、全体で拾うようにしました。** これまでは`/home/aida/スクショ/画面.png`の`/home/aida`だけを拾っていました。`artifacts/画面.png`のような画像の相対パスも押せます。
- 空白を含むパスは、`'…'`や`"…"`で囲んだものと、`\ `で空白を書いたものを1つのパスとして拾います。囲んでいない空白入りのパスは、どこまでがパスか分からないので拾いません。これまでのように一部だけを拾うことはありません。
- 引用符やバッククォートの中のパス、`Saved to:/tmp/x.png`や`保存しました：/tmp/x.png`のように`:`・`：`・`→`の直後にあるパス、`file:///…`も拾うようにしました。
- **プログラムが右端で自分で改行して続きを字下げした長いパスを、1つのパスとして拾うようにしました。** Claude Codeは幅を超える行をこの形で折り返します。これまでは`e.png`のような断片を別のパスとして拾っていました。どの行を押しても完全なパスを開きます。右端まで埋まっていない行や、`●`・`❯`で始まる行はつなぎません。
- このPCがWindowsのときは、ローカルシェルに出た`C:\…`の形のパスも拾います。

## 実行先のsshcエンジン

- **接続できないとき、サイドバーではなくターミナルの領域に、何が起きたかと次の操作を表示するようにしました。** ダイアログではないので、サイドバー、［実行先］、ほかの画面はそのまま使えます。最後に試した時刻を表示し、数秒ごとに自動で読み直します。
  - 届かないとき: ［今すぐ再接続］か［localhost に戻す］を選べます。SSHの接続に失敗したときは、見出しでそう書きます。
  - Vaultがロックされているとき: その場でパスワードを入力して解除します。これまでのように、ダイアログが自動で開くことはありません。
  - 組み合わせて使えないバージョンのとき: 両方のバージョンを並べて表示し、その場で接続先を更新できます。
  - ［詳しく］で、sshcエンジンが返したエラーの種類と内容を確かめられます。
- **実行先との組み合わせを、sshcのバージョンではなく互換の番号で確かめるようにしました。** やり取りの形が同じなら、バージョンが違う実行先もそのまま使えます。
- **接続先の更新・再起動・停止で、接続先の`sshc`の出力を、動いている間から表示するようにしました。** 操作はこのPCのsshcエンジンの中で最後まで走るので、途中で画面を離れても止まりません。
- バージョンが違うsshcエンジンも、実行先に追加できるようにしました。

## このPCの更新

- **About sshcからこのPCのsshcを更新するとき、インストーラーの出力を「更新の出力」に表示するようにしました。** sshcエンジンが再起動したあとも、続きから読めます。出力は状態フォルダの`web-update.log`に、1回の更新につき256 KiBまで書きます。
- **About sshcを開いたら、その場で更新を確認するようにしました。** これまでは前回の確認の結果だけで「最新です」と表示していました。このページで確認できたときだけ、新しいバージョンの有無を表示します。新しいものが無いときは「新しいバージョンはありません」と表示します。

## サイドバー

- ワークスペースの行のセッションの数を、行にポインタを乗せたときかフォーカスしたときだけ表示するようにしました。行のボタンと同じ表示です。タッチ操作の画面では、これまでどおり常に表示します。
- セッションの行の文字を一段小さくしました。行の上下の余白は保っています。スマホの画面では、押せる大きさを変えていません。
- 見出し「Workspaces」の横に［＋］を置き、ワークスペースをすぐ作れるようにしました。［…］には非表示の切り替えだけが残ります。

## キー操作

- **ターミナルでShift+Tabを押したとき、フォーカスがターミナルの外のボタンへ移らないようにしました。** Claude Codeなど、Kitty keyboard protocolを使うプログラムで起きていました。キーはプログラムに届いていましたが、同時にフォーカスが右上の［…］へ移り、続けて打った文字がターミナルに入りませんでした。
- **日本語の変換を確定するEnterで、セッション名の変更が確定しないようにしました。** 変換中のEscで欄が閉じることもありません。ターミナルの検索、コマンドパレット、SFTPの検索とパスの入力、転送の設定の数値、ショートカットの設定も同じです。

## 更新後に必要な操作

- 実行先として使う接続先も、v0.54.0以降に更新してください。v0.53.1以前の接続先は、このリリースのsshcと組み合わせて使えません。ターミナルの領域に出る更新のボタンから、その場で更新できます。
