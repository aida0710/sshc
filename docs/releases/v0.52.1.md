# sshc v0.52.1

v0.52.1では、Windowsで`~/.ssh/config`の`Include`に`~\`で始まるパスを書いたとき、sshcがそのファイルを読まなかった問題を修正しました。

## Windowsの`Include`

- これまでは、Windowsで`Include ~\.ssh\conf.d\*.conf`のように`~\`で始まるパスを書くと、sshcは「対応していないInclude」と警告してそのファイルを読みませんでした。WindowsのOpenSSH（OpenSSH for Windows 9.5で確認）は、`~\`も`~/`と同じくホームディレクトリから読みます。そのため、`ssh`では使える接続先が、sshcの接続先の一覧に表示されませんでした。**Windowsでは、`~\`で始まる`Include`もホームディレクトリから読むように修正しました。** `IdentityFile`などの値は、これまでも`~\`をホームディレクトリとして読んでいます。
- Windows以外では`\`はファイル名の一部なので、これまでどおり`~\`で始まる`Include`は読みません。
