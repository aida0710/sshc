# sshc v0.23.0

v0.23.0では、Syncの対象から不要なファイルを除外できるようにしました。端末ごとの一時ファイルを同期せず、受信先に残したいファイルも保護できます。

あわせて、リモートまたはローカルの状態を明示的に採用する操作、受信時の検証、Androidでの画面復帰を改善しています。

## 同期するファイル

- Sync画面の「同期するファイル」から、同期対象を検索して確認できます。ファイルごとの選択に加え、`.sshcignore`へgitignore形式のパターンを記述できます。正規表現ではありません。
- `.sshcignore`を作成していない場合は、`.DS_Store`、`Thumbs.db`、`desktop.ini`、`*.bak`、`*.tmp`、`*.lock`を既定で除外します。保存した`.sshcignore`はワークスペースに含まれ、同じバケットを使う端末へ同期されます。
- 除外したローカルファイルはPushに含まれず、通常のPullやForce Pullでも上書き・削除されません。`.sshcignore`自体と、VaultおよびSnippetsの同期データは除外できません。

## Force送受信

- Sync画面に「Force受信」と「Force送信」を追加しました。履歴が分岐して通常の同期を続けられない場合に、リモートまたはローカルのどちらを採用するか明示できます。
- Force受信では、作成日時、作成元、変更されるファイルを確認してから適用します。確認後にリモートが更新されていた場合は適用せず、もう一度確認を求めます。
- Force送信では、コミットメッセージを入力し、リモート履歴を置き換えることを確認してから送信します。受信のみの端末からは送信できず、送信のみの端末では受信できません。
- CLIでは`sshc sync pull --force`を追加しました。受信のみと送受信の端末で使用でき、画面と同じ確認・検証を行います。

## 受信とエラー表示

- これまでは受信した`.ssh`内のすべてのファイルをSSH設定として解析する場合があり、任意の補助ファイルが原因でPullできないことがありました。現在はスナップショットの構造、パス、権限、暗号化データを検証したうえで、任意のファイルを内容を変えずに復元します。
- 接続、認証、暗号化キー、スナップショット検証の失敗を分けて表示するようにしました。Syncに失敗した場合は、原因と次に確認する項目を画面とengineログで追えます。
- 同期設定の入力中にAndroidで別のアプリへ移動して戻った場合も、入力内容を保つよう修正しました。一時保存用のAPIは追加せず、表示中の画面を維持します。

## Androidとドキュメント

- Androidでランチャーや通知からアプリへ戻った際、同じengineのWebViewを読み直さないようにしました。左端スワイプは中央の限られた範囲でメニューを開き、それ以外の場所ではAndroidの戻る操作を使えます。
- 日本語・英語のPagesに、同期対象の選び方、`.sshcignore`の例、Force送受信、エラー時の確認手順を追加しました。デスクトップとスマートフォンの実画面も更新しています。

## 検証

- S3互換ストレージを使い、`.sshcignore`の共有、除外ファイルを送信しないこと、受信先の除外ファイルを保持することを確認しました。
- Goの全テストとrace test、Webの1,055テスト、SyncのE2E、Pages build、Android向けGo build、Android JVMテストを実行しています。
