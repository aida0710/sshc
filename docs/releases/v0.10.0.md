# sshc v0.10.0

S3上の暗号化スナップショットを、Git風のrevision履歴として確認・比較・復元できるようにしたリリースです。

## 暗号化revision履歴

- 各スナップショットへ内容から検証できるrevision IDと親revision IDを記録し、HEAD、ancestor、branchを判別できるようにしました。
- 同期画面にrevision timelineを追加しました。作成日時、ファイル数、匿名化された端末ID、親revisionを表示します。
- v1/v2スナップショットはlegacy revisionとして読み取れます。既存のS3オブジェクトを移行や再暗号化のために書き換えません。

## 差分と安全な復元

- 選択したrevisionと現在のHEADを比較し、追加・変更・削除されたパスを表示します。ファイル内容はAPIレスポンスへ含めません。
- 過去revisionは通常のpullと同じく、ローカル変更と削除をpreviewしてから適用します。
- 復元してもリモートHEADを直接巻き戻しません。次のpushが復元元revisionを親とする新しいHEADを条件付きで作るため、元の新しい世代はbranchとして履歴に残ります。

## 制限と安全性

- timelineで復号するのは新しい順の最大50 revision、暗号文合計128 MiBまでです。S3内の全オブジェクトは従来のバケット状態一覧で確認できます。
- revisionの系譜とファイルdigestは暗号化manifest内だけに保存し、S3 providerへ平文で公開しません。
- 履歴オブジェクトの指定は設定済みの `snapshots/` prefix内へ制限し、パストラバーサルを拒否します。

## 検証

- 連続push、path-only diff、過去版のpreview/apply、復元元からのbranch作成、不正な履歴キー拒否をGoのHTTP/S3相当テストで確認しました。
- Webのrevision選択、差分表示、復元preview/applyをユニットテストとPlaywright E2Eで確認しました。
- desktopと360px幅の同期画面をスクリーンショットで目視確認しました。
