# sshc v0.39.2

v0.39.2は、Apple SiliconのmacなどarmのマシンでVPNを使えなかった問題を直す修正リリースです。arm64では、VPNのコンテナイメージの作成に毎回失敗していました。

あわせて、コンテナイメージの作成とスマートフォンでの承認待ちを、接続ログの設定に関係なく表示するようにしました。

## VPN

- **arm64のマシンで、VPNのコンテナイメージを作成できない問題を直しました。** Apple Siliconのmac（Docker Desktop）やarm64のLinuxでは、`docker build`がパッケージを1つも見つけられず、「VPNのコンテナイメージの作成に失敗しました」と表示されていました。arm64のパッケージの取得先を、amd64と同じ固定の版から取るように直しています。
- **コンテナイメージを作成するあいだ、`[sshc] VPNのコンテナイメージを作成しています。初回は数分かかることがあります。`と表示するようにしました。** これまでは接続ログを`-v`以上にしないと何も表示されず、初回の数分間、止まっているように見えました。Terminalと`sshc <接続先>`のどちらでも、接続ログの設定に関係なく表示します。
- **スマートフォンでの承認を待つあいだ、`[sshc] スマートフォンでの承認を待っています。`と表示するようにしました。** これまでは接続ログを`-v`以上にしないと表示されませんでした。
- VPN画面と`sshc vpn`の「コンテナイメージを準備しています」は、コンテナイメージを実際に作成するときだけ表示するようにしました。作成済みのイメージを確認するだけのときは表示しません。

## 更新後に必要な操作

更新後はengineを再起動して、新しいバージョンを使用してください。

VPN機能を使用している場合、次にVPNに接続するときに、コンテナイメージがマシン上で1度だけ作り直されます。作成にはネットワークが必要です。
