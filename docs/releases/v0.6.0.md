# sshc v0.6.0

SFTP、分割Workspace、Snippetsを追加し、複数の接続先を扱う作業をsshc内で完結できるようにしたリリースです。

## SFTPとリモート編集

- 保存済み接続のリモートファイルを閲覧し、download、upload、directory作成、名前変更、削除を実行できます。
- 複数ファイルの選択とDrag & Dropに対応し、ファイルごとの進捗と結果を表示します。1件が失敗しても残りの転送を続行します。
- UTF-8の2 MiB以下のファイルは、遅延ロードされるMonaco Editorで編集できます。保存前にリモート更新を検査し、競合時は上書きを止めます。
- SFTPは既存のOpenSSH設定、vault、`known_hosts`、`ProxyJump`を使用します。未知のホスト鍵は自動登録しません。

## WorkspaceとSplit View

- 複数のSSH接続を縦または横へ分割し、paneを切り替えながら操作できます。
- Broadcast Inputを有効にすると、キー入力をWorkspace内の全paneへ送信できます。
- 接続aliasとpane layoutを端末内へ保存し、同じ構成を再オープンできます。remote processやsession IDは保存せず、各接続を新しく開始します。

## Snippetsとautomation

- 変数を含むcommandをSnippetとして保存し、展開後のcommandと接続先を確認してから実行できます。
- 1つのSnippetを複数hostへ並列実行し、hostごとの結果を確認または取消できます。
- hostごとにstartup Snippetを設定し、初回接続と再接続でSSH shellの準備完了後に送信できます。
- secret型の入力値は保存せず、previewと実行結果では伏せます。secret変数を持つSnippetはstartup automationに設定できません。

## UI

- StartをHome、Connections、Terminalの1列表示へ整理しました。
- FilesをConnection filesへ、SnippetsをMaintenanceへ配置しました。
- Snippetのcommand previewと実行結果をlight／dark themeの両方で読み取れるようにしました。

## 検証

- Goの通常テストとrace detector、Android／Windows build、Go vet、dead code検査を実行しました。
- Webのユニットテスト805件、TypeScript型検査、ESLint、npm auditを実行しました。
- Playwright E2E 106件と、追加画面のlight／dark／360px表示を検査しました。
- 固定digestのOpenSSHコンテナで実SFTP subsystemを開き、text／binary upload、download、編集競合、rename、list、deleteのround tripを確認しました。
