# sshc v0.46.0

v0.46.0では、SFTPの接続と転送設定の操作を見直しました。接続先を選ぶとその場で接続し、転送設定は［Settings］→［SFTP］のページで変更できます。

あわせて、空き容量の表示単位、接続先タブの高さ、接続中のタブを閉じるときの確認を改善しています。

## SFTPの接続

- これまでは接続先を選んだあとに中央の［接続］を押す必要がありましたが、**接続先を選ぶとその場で接続するようにしました。** SFTP画面を開いたときに前回のタブを復元した場合は、これまでどおり自動では接続せず、［接続］を押したときに接続します。
- SSHホストに接続中のタブを閉じるときに、確認を表示するようにしました。Shiftを押しながら×を押すと、確認せずに閉じます。保存していない編集があるタブは、Shiftを押していても保存せずに閉じてよいかを確認します。
- タブの×にマウスを乗せたときに、背景を付けて表示するようにしました。

## 転送設定

- これまでは転送マネージャーの［転送設定］でダイアログを開いていましたが、**転送設定を［Settings］→［SFTP］のページへ移しました。** ［転送設定］を押すと、このページへ移動します。［Menu］のSettingsからも開けます。
- 速度と復旧、同時実行と完了項目、分割転送、除外ルールの項目と、変更するとすぐに保存される動作は変わりません。ページを開くとengineから現在の設定を読み込み、読み込めるまでは変更できません。

## 表示

- これまでは空き容量と合計容量をバイト数で表示していましたが、大きさに応じてMiB、GiB、TiBなどの単位で表示するようにしました。例えば23,322,673,152バイトは21.7 GiBと表示します。
- PCをマウスで操作する場合は、接続先タブにフォルダ名と接続先を1行で表示し、タブの列の高さを45pxから33pxにしました。タッチ操作とスマートフォンでは、押しやすい大きさを保つため、これまでの高さのままです。
