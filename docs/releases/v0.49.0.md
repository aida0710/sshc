# sshc v0.49.0

v0.49.0では、sshcのバージョン情報と更新を1つのページで確認できるようにしました。画面を開いたままでも、新しいバージョンが公開されたことに気づけます。

あわせて、メニューの並びを見直しています。

## About sshc

- **メニューのOthersに「About sshc」のページを追加しました。** サイドバーのバージョン表示を押しても開きます。
- 「このsshc」には、バージョン、コミット（GitHubへのリンク）、コミットの日時、ビルドしたときに未コミットの変更があったか、Goのバージョン、OSとCPU、導入方法（Homebrew・install.sh・install.ps1）、実行ファイルの場所を表示します。
- 「更新」には、最新のバージョン、その公開日時、最後に確認した日時を表示します。［更新を確認］でその場で確認でき、新しいバージョンがあれば［sshcを更新］から更新できます。
- 今のバージョンから最新のバージョンまでのリリースノートを、ページの中で読めます。本文はそのまま表示します。

## 更新の確認

- これまでは、sshcエンジンの起動直後と、画面を読み込んだときにだけ更新を確認していました。画面を開いたままでは新しいバージョンに気づかず、読み込むたびにGitHubへ問い合わせていました。**sshcエンジンが確認の結果を覚えておき、6時間ごとに確認し直す**ようにしました。サイドバーはその結果を1時間ごとに読み直すので、画面を開いたままでも新しいバージョンのお知らせが出ます。

## メニュー

- メニューの並びを、Others、Preferences、サインアウトの順に変更しました。Othersは、ほかのグループと同じ大きさの枠にし、空いている列に並ぶようにしました。
