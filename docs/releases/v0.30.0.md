# sshc v0.30.0

v0.30.0では、保存したワンタイムパスワード（TOTP）を接続先へ割り当てる導線を見直しました。接続先の設定画面からTOTPを選択でき、`Verification code:`のような認証質問へ自動入力できます。

あわせて、Terminalへアップロードした背景画像のファイル名を、保存済みの設定を壊さず変更できるようにしました。

## ワンタイムパスワードの設定

- これまではVault画面で接続先のエイリアスを手入力してTOTPを割り当てていましたが、**Connectionsで対象の接続先を開き、［基本］→［認証］から保存済みTOTPを選択する方式**に変更しました。
- TOTP自体の登録と編集は、これまでどおりVaultで行います。Vault画面からは、接続先名を手入力する割り当て欄を削除しました。
- 接続設定とTOTPの割り当てを一度の保存操作で反映します。保存途中で片方だけが更新されることはありません。
- `OTP:`、`TOTP:`、`Verification code:`、`認証コード:`など、ワンタイムパスワードであることが明示された非表示の認証質問へ、その時点のコードを自動入力します。Terminal、SFTP、`sshc ssh`、`sshc run`、ProxyJumpの各接続で同じ設定を使用します。
- 接続先、ユーザー、ポート、ProxyJump経路を変更した場合は、以前の相手向けに保存したTOTPを自動では送りません。Connectionsの基本設定でTOTPを選び直すと、新しい認証先へ割り当てられます。
- パスワードとTOTPのセットアップキーを同じ端末へ保存すると、端末を失った場合に両方の認証要素を失う可能性があります。この点はVault画面とドキュメントで引き続き案内します。

## Terminalの背景画像

- アップロード済みの背景画像に「名前を変更」を追加しました。JavaScriptの入力欄ではなく、ほかの名前変更操作と同じアプリ内ダイアログを使用します。
- 入力した拡張子で画像形式を偽装せず、実際の画像形式に対応した拡張子を維持します。
- 全体のTerminal設定または接続先ごとの設定で画像を使用している場合は、画像と設定内の参照を同じ操作で更新します。名前変更後に保存済みの背景が消えることはありません。
- 同じ名前の画像がすでにある場合は、既存画像を上書きせず、名前を変更できないことを表示します。
