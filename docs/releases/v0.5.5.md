# sshc v0.5.5

セッションが無効になったときの復旧表示と、初期画面・ナビゲーションの細部を修正したリリースです。

## 修正

- 別のタブでセッション情報が更新された場合は、CSRFトークンを更新して操作を一度だけ安全に再試行するようにしました。
- セッション自体が終了している場合は、左上に一部のUIが残る状態をやめ、再読み込み方法を案内する全画面表示へ切り替えるようにしました。
- マスターパスワードの作成・入力画面から装飾アイコンを削除しました。
- サイドバーの履歴とバージョン表示の間に出ていた二重の区切り線を1本にしました。

## 検証

- 360px幅を含む全105件のブラウザE2Eテストを実行しました。
- S3互換サーバーを使い、2つの新規ワークスペース間の同期、競合解決、鍵変更、通信断からの復旧を確認しました。

## インストール

```sh
brew install aida0710/tap/sshc
```

または:

```sh
curl -fsSL https://raw.githubusercontent.com/aida0710/sshc/main/install.sh | sh
```

Android版は、このリリースの `sshc-android-v0.5.5.apk` をダウンロードして更新してください。
