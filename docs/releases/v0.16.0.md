# sshc v0.16.0

sshcの画面を、黒と寒色系グレーを基調にした高密度な操作画面へ刷新しました。青いグラデーションや浮いたカードを抑え、SSH・SFTP・Workspaceの情報と操作をより広く、落ち着いて確認できます。

## graphiteデザイン

- 初期外観をダークへ変更し、canvas、sidebar、toolbar、control、terminalを黒からcool grayの階調で統一しました。ライト外観とシステム連動も引き続き選べます。
- ブランドマーク、選択状態、境界線をmonochrome中心に変更し、強い青、グラデーション、大きな角丸、不要なshadowを削減しました。
- HomeのQuick Connect、recent connections、状態指標を密度の高い行と区切り線へ整理しました。
- SFTP、Terminal、接続設定、鍵、同期など共通surfaceとformの余白・角丸を揃え、一覧で見える情報量を増やしました。

## desktopとmobile

- desktopは高さ48pxのtoolbarへ現在地、session状態、外観、言語を一列にまとめました。
- mobileは下部navigationを追加せず、従来どおり左上のbuttonからdrawerを開きます。外観と言語は右上の表示menuへ収め、通常時の縦方向をterminalやfile一覧へ譲ります。
- mobile drawer内の主要section間隔を詰め、360px幅でも操作対象とversionを独立してscrollできます。
- mobileのheader高、drawerの初期非表示、表示menu内の外観・言語controlをE2Eで固定しました。

## 検証

- Web unit test、TypeScript、ESLint、production buildを確認しました。
- Chromium E2E全119経路を、最終コードを埋め込んだbinaryで確認しました。
- desktop 1280×720とmobile 360×800でHomeとdrawerを撮影し、見切れ、横overflow、menu transitionを目視確認しました。
