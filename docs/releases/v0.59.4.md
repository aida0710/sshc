# sshc v0.59.4

v0.59.4では、Windowsで設定などの保存がまれに失敗し、`internal_error`（HTTP 500）が出る不具合を修正しました。

## 修正

- **Windowsで、保存するファイルをほかのプログラムが開いていると、保存が「Access is denied.」で失敗していました。** sshcは、新しい中身を一時ファイルに書いてから名前を付け替え、前のファイルと置き換えます。Windowsの従来の付け替えは、置き換える先を誰かが開いていると断ります。画面が5秒ごとに設定を読み直すときや、Windows Defenderが検査するときと保存が重なると、プリセットの保存などが`internal_error`（HTTP 500）になり、sshcエンジンのログには「Access is denied.」と出ていました。
- これからは、この理由で断られたときだけ、WindowsのPOSIX方式の置き換えでやり直します。ファイルを開いていた側は、前の中身を最後まで読めます。この方式を使えないドライブ（FAT、exFATなど）では、これまでどおりの結果になります。
- 設定とプリセットのほか、スニペット、マシンの状態、転送の一覧、同期で受け取ったファイルなど、sshcが自分の記録を保存するときはすべて同じように動きます。
