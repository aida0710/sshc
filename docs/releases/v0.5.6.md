# sshc v0.5.6

Web UIのブランド表示をアプリの正式なアイコンへ揃えたリリースです。

## 修正

- デスクトップのヘッダーに表示していた仮の「`>_`」アイコンを、Android版と同じsshcアイコンへ置き換えました。
- スマートフォンのナビゲーションメニューにも同じアイコンを表示し、画面幅によってブランド表示が変わらないようにしました。
- コンソールが開かれていない画面の仮アイコンも、同じsshcアイコンへ置き換えました。
- マスターパスワード画面は、前のリリースで変更したアイコンなしの表示を維持しています。
- ConfigのInclude階層で、長いパスや条件が隣の編集領域へはみ出さないようにしました。
- Keysでは、対応する公開鍵と証明書を秘密鍵の直下で開閉できるようにしました。対応する秘密鍵がない公開鍵は、これまでどおり独立して表示します。

## 検証

- 正式アイコンの形状と、複数表示時にSVGグラデーションが衝突しないことをユニットテストで確認しました。
- デスクトップ幅と360px幅の実ブラウザで、正式アイコンの表示と旧アイコンの不在を確認しました。
- 長い条件付きIncludeと、実際に生成した秘密鍵・公開鍵のペア表示をブラウザE2Eテストで確認しました。

## インストール

```sh
brew install aida0710/tap/sshc
```

または:

```sh
curl -fsSL https://raw.githubusercontent.com/aida0710/sshc/main/install.sh | sh
```

Android版は、このリリースの `sshc-android-v0.5.6.apk` をダウンロードして更新してください。
