# sshc v0.12.0

リモート同期を現行仕様だけに整理し、過去形式の互換レイヤーを廃止しました。

## 変更内容

- snapshot manifestをschema v5へ更新し、v1〜v4の読み取りと暗黙変換を削除しました。
- revision、parent revision、commit messageを現行のrevision graph契約として必須化しました。
- 旧snapshotのsecret markerと旧ローカル同期状態の読み取りを削除しました。
- push APIは空でないcommit messageを必須とし、本文なしの旧クライアント要求を拒否します。
- 同期設定APIは`both`、`push`、`pull`のいずれかを必須とし、空値の既定化を削除しました。
- vaultの暗号化・復号codecを必須化し、ディスク上の旧暗号化ファイルをそのまま同期する経路を削除しました。
- 未対応schemaのエラーを`snapshot_schema_unsupported`へ統一しました。

## 破壊的変更

v0.12.0は過去のsnapshot、履歴、ローカル同期状態を読み取りません。同じ同期先を使うすべての端末をv0.12.0へ更新し、**新しい空のバケットまたは新しい保存パス**から同期を開始してください。旧世代が残る保存パスとの混在、旧クライアントとの併用、旧snapshotからの移行はサポートしません。
