# sshc v0.46.3

v0.46.3では、別のターミナルへ切り替えて戻ったときに、以前のコピーがもう一度実行される問題を修正しました。

あわせて、再接続で過去の出力を表示し直す際にも、コピーと通知を繰り返さないようにしています。

## ターミナルのコピー

- これまでは、リモートアプリのコピー命令（OSC 52）が過去の出力に残っていると、ターミナルを開き直した際にクリップボードを上書きし、コピー通知も出していました。**過去の出力を復元する間は、コピーと通知を止める**ように修正しました。
- 新しいコピー命令は、同じ文字列でもその都度処理します。範囲選択による通常のコピーも引き続き使えます。
