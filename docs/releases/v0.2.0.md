# sshc v0.2.0

インストール方法を追加し、設計監査で見つかった不整合と重複実装を修正したリリースです。

## 主な変更

- Homebrew formula を追加しました: `brew install aida0710/tap/sshc`
- macOS と Linux 向けの検証付きインストールスクリプトを追加しました。
- `sshc version` と `sshc --version` を追加しました。
- デスクトップアプリによる CLI の自動配置を廃止し、利用者が明示的にインストールする方式へ変更しました。
- 接続設定の解決、API 型、入力検証、HTTP 層と永続化層の責務を整理しました。
- 鍵 vault のバックアップ暗号化、Windows の鍵管理、Match ブロックの評価などの不具合を修正しました。
- TypeScript と ESLint によるデスクトップおよび Web UI の静的検査を追加しました。
- ライセンスを明記しました。

## インストール

```sh
brew install aida0710/tap/sshc
```

または:

```sh
curl -fsSL https://raw.githubusercontent.com/aida0710/sshc/main/install.sh | sh
```
