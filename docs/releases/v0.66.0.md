# sshc v0.66.0

v0.66.0では、設定がどこまで効くかを、設定が出る場所で読めるように改善しました。Settingsの各ページとターミナルの「…」に、効く範囲を同じ札で示します。

あわせて、スマホの画面の切り替え、遠いサーバでのSFTPのプレビュー、ターミナルの表示の不具合、セッションのログの保存先の確認を改善しています。

## 設定の効く範囲

- これまでは、ある設定がすべてのマシンに効くのか、プリセットごとなのか、このマシンだけなのかを画面から読めませんでした。**Settingsの各ページの名前の横に、「全マシン共通」「プリセット: （名前）」「マシンごと」「このマシンだけ」の札を出す**ようにしました。プリセットのページでは、編集中のプリセットの名前が札に出ます。
- ターミナルの「…」の「すべてのターミナル」を、効く範囲ごとの2つの見出しに分けました。OSC 52は「全マシン共通」、画面を常にオンとタッチ操作は「プリセット: （名前）」の下に並びます。
- 接続先の編集で「アプリ全体の設定に従う」と書いていた説明を、実際に従う先の「プリセット」に直しました。
- 設定の保存のしかたは変えていません。更新しても、今の設定はそのまま残ります。

## スマホの画面の切り替え

- これまでは、タブ・リンク・戻るボタンで画面を移るとフェードが入り、移ってから約0.3秒は押しても反応しませんでした。**フェードをやめ、移った直後から押せる**ようにしました。
- Androidの戻るジェスチャーで指を離したときだけ、短いフェード（0.15秒）を残しています。

## SFTP

- プレビューと編集でファイルを開くとき、これまでは小さく分けて順に読んでいたため、遠いサーバでは返事を何度も待っていました。**大きくまとめて読む**ように変更しました。往復に0.1秒かかるサーバで約185KBの写真を開くと、写真が出るまでが約2.3秒から約1秒になりました。
- 接続先を選んでいないときの見出しを「接続先が選ばれていません」にしました。

## ターミナル

- スクロールバックをファイルに保存するとき、ファイル名にターミナルを開いた時点のタイトルを使っていたのを直しました。保存した時点のタイトルを使います。
- ターミナルを開いたあとに表示言語を変えても、ターミナルの中の知らせが前の言語のままだったのを直しました。
- 終了したと表示していたセッションを、ほかのブラウザがつなぎ直した場合に、新しいシェルの出力がこの画面に出なかったのを直しました。

## セキュリティ

- セッションのログの保存先が、Syncで同期するフォルダ（`~/.ssh`）の下を指しているときは、**ログを書かず、ターミナルに理由を表示する**ようにしました。そこへ書くと、ターミナルの出力がほかのマシンへ同期されるためです。
- 開き直しの記録にあるtmuxのセッション名は、sshcが付けた形の名前だけを受け付けるようにしました。
- 動画と音声のプレビューが同時に持てる再生用のチケットを、全体で256枚までにしました。

## 更新後に必要な操作

- Settingsの「セッションのログの保存先」に`~/.ssh`の下のフォルダを指定している場合は、別のフォルダに変えてください。変えるまで、そのマシンではセッションのログが保存されません。保存先が空欄（初期値）の場合は、何もする必要はありません。
