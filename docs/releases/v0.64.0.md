# sshc v0.64.0

v0.64.0では、スマホ版（Androidのアプリ）の画面の切り替えと操作の手ざわりを、スマホのアプリらしく改善しました。

あわせて、Androidのアプリの起動の見え方、戻るジェスチャーの動き、キーバーを押したときの振動を改善しています。

## 画面の切り替え

- これまでは、Home・Connections・SFTP・Menuを切り替えるたびに画面を作り直していたため、灰色の仮の表示や「読み込んでいます…」が一瞬出て、スクロール位置も先頭に戻っていました。**一度開いたこれらの画面は裏に残し、切り替えるとすぐに前の状態で出る**ように変更しました。PCでも同じです。
- Menuから開くページ（SSH Keys、Settings、Aboutなど）は、これまでどおり開くたびに作ります。保存していない変更を捨てて離れた画面も、次に開くときは作り直します。
- 画面の部品を起動のあとに読み込んでおき、初めて開く画面でも灰色の仮の表示を出さないようにしました。
- スマホの大きさの画面では、画面を移るときに短いフェードで切り替わるようにしました。「動きを減らす」がオンのときはフェードしません。

## 押したとき・長押ししたとき

- スマホの大きさの画面では、ボタンや行を押している間、地の色が明るく（ライトのテーマでは暗く）なるようにしました。これまでは少し薄くなるだけで、暗いテーマではほとんど見えませんでした。
- スマホの大きさの画面では、見出しやボタンの文字を長押ししても選択されないようにしました。ターミナル、入力欄、パスやフィンガープリントのような等幅の値、エラーの文は、これまでどおり選べます。

## Androidのアプリ

- これまでは、起動するとスプラッシュのあとに真っ黒な画面、灰色の仮の表示、「読み込んでいます…」が続けて出ていました。**最初の画面が中身まで出そろうまでスプラッシュを出しておく**ように変更しました。3秒たっても出そろわないときは、スプラッシュを消してページの読み込み中の表示を出します。Android 11以前では、これまでどおりです。
- 戻るジェスチャーの途中で、画面が指に合わせて少し縮むようにしました。指を離すと前の画面へ移り、取り消すと元に戻ります。Homeの一番上で何も開いていないときは、Androidの「ホームへ戻る」の動き（アプリが縮んで後ろにホーム画面が見える）になります。
- キーバーのキーと送信ボタンを押した瞬間に振動するようにしました。Androidの振動の設定に従います。
