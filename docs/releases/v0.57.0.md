# sshc v0.57.0

v0.57.0では、まだ共通の形になっていなかったページを、ほかのページと同じ形に作り直しました。対象はSSH Keys、Settings → Terminal・SFTP、VPN、Remote Keys、Snippets、SSH Config、Vaultの各ページです。どのページも、角丸の板の中に、見出しと線で区切った節を置く形になりました。一覧は1件を1行で並べ、操作は行の「…」にまとめています。

あわせて、スリープから覚めたあとのターミナルの接続、さし色のカスタム、SFTPのタブの並べ替え、スマホとタッチ対応のPCの表示を改善しています。

## ターミナル

- **PCがスリープから覚めたあと、実行先のターミナルに入力できなくなることがある不具合を直しました。** スリープのあいだに実行先へのSSHが切れても、sshcエンジンが気づくまでの1分半ほどは、画面からはつながっているように見えます。そのあいだ、打った文字はどこにも届かず、何も表示されませんでした。スリープから覚めたとき、ネットワークが戻ったとき、ブラウザの「戻る」「進む」でページに戻ったときには、接続をすぐ張り直すようにしました。出力は最後に受け取った続きから読み直すので、欠けません。
- タッチの画面やタッチパッドで横に払う操作が、ブラウザの「戻る」「進む」にならないようにしました。これまでは払うとページが前の画面へ戻り、すべてのターミナルの接続が切れていました。

## SSH Keys

- **鍵の一覧を、1つの鍵を1行で並べる形にしました。** 秘密鍵・公開鍵・証明書は1行にまとめ、行には名前と場所、種類、状態（使用中・未使用・確認が必要）を出します。指紋や関連するファイルは、名前を押すと右に開く詳細の欄で見ます。
- 鍵の操作（秘密鍵・公開鍵・証明書を表示、ssh-agentへの登録と解除、保存したパスフレーズ、パスフレーズの変更、名前の変更と移動、ゴミ箱へ移動）は、行の「…」にまとめました。パスフレーズの変更などの入力欄は、ページの下ではなく、押した行の下に開きます。
- ゴミ箱は、グループの一覧の一番下に移しました。
- これまでは、1280幅の画面では表の右端が板の外に出て、横にスクロールしないと操作の列が見えませんでした。幅に合わせて列を収めるようにしました。グループの件数が、公開鍵や証明書のファイルまで数えて行の数と合わなかった不具合も直しました。
- スマホでは、1つの鍵が約270pxを使っていました。札1つの短い行にしました。

## Settings

- **Settings → Terminalを「表示」「接続」「操作」のタブに分けました。** PCではどのタブも1画面に収まります。スマホではタブを出さず、節ごとの板に並べます。接続が切れたときの再接続の選択肢の文が、欄の幅で切れて読めなかった不具合も直しました。
- Settings → SFTPを「転送」と「転送の除外」の2つの節にし、分割転送の3つの数を1行の文にまとめました。変えるとすぐ保存し、除外の指定だけ自分のボタンで保存する動きは、これまでどおりです。
- 入力の行の名前の列を160pxから184pxに広げました。「現在のマスターパスワード」などが途中で折り返さなくなりました。

## VPN・Remote Keys

- VPNを、VPNプロファイルの一覧と追加の2つの節にしました。一覧の行では、［接続］と［切断］は行のボタンに残し、ログ・編集・名前の変更・削除を「…」にまとめました。
- **Remote Keysは「1. 公開鍵」「2. 接続先」の順の節にし、~/.sshに公開鍵があれば最初の公開鍵を選んでおくようにしました。** 接続先は、枠の箱の中ではなく、3列のチェックで全部並べます。

## Snippets・SSH Config

- **SnippetsとSSH Configを、Connectionsと同じ作業場の形にしました。** 左に一覧、右に選んだものの中身を出します。スマホでは一覧から選ぶと中身に移り、［スニペット一覧］［ファイル一覧］で戻ります。
- Snippetsでは、選んだスニペットの編集・実行する接続先・接続時の自動実行を、右に節で並べます。
- SSH Configでは、左にIncludeの階層、右にエディタを置きました。ファイルの名前の変更・削除・フォルダの操作は「…」にまとめました。
- SSH Configでフォルダを作る・消すと、成功していても「要求は拒否されました」と出ていた不具合を直しました。
- Snippetsの実行内容の確認で、経路に「ProxyCommand: undefined」と出ていた不具合を直しました。コマンドパレットから開いたスニペットが、閉じても開き直されていた不具合も直しました。

## Vault

- **Account passwords・Key passphrases・OTPを、1件を1行で並べる形にしました。** これまでは1件ごとに、コードの箱と割り当て先の箱が入れ子になり、スマホでは1件で約175pxを使っていました。行には、名前と割り当て先を1行で出します。OTPは、今のコード（押すとコピー）と、残りの秒数の輪も右に出します。
- 前後のコード・割り当て先のホスト（割り当ての解除）・編集・削除は、行の「…」から開きます。編集は、画面をふさぐダイアログではなく、行の下に開きます。
- 追加の欄はいつも出さず、見出しの［追加］を押したときに一覧の上に開きます。
- ページの見出しを、Menuと上のバーと同じ英語の名前（Account passwords・Key passphrases・OTP）にしました。

## さし色

- **Settings → Appearanceのさし色に「カスタム」を追加しました。** カラーピッカーか、色コード（#rrggbb）で好きな色を1つ選べます。用意した5色と同じく、ほかのマシンへ同期されます。
- 今の配色の背景と見分けにくい色を選ぶと、選んでいる項目やフォーカスの枠が見えにくくなることを知らせます。
- 同期しているほかのマシンのsshcがv0.56.0以前なら、そのマシンでは最後に選んだ用意した色で表示されます。

## SFTP

- **タブをドラッグして並べ替えられるようにしました。** もう一方のペインのタブの列へ落とすと、その位置に入ります。落ちる位置には縦の線を出します。
- 選んでいるタブに「…」を追加しました（タブの右クリックでも開きます）。左へ移動・右へ移動・もう一方のペインへ移動（ペインが1つのときは右に新しいペインで開く）・左右のペインを入れ替えを選べます。キーボードでは、Ctrl+Shift+←／→で並べ替えます。
- 同じペインの中での並べ替えと、左右のペインの入れ替えでは、タブは接続したままです。

## スマホとタッチ

- **スマホの下のタブを、ページの上に浮かせました。** これまでは下のタブの後ろに帯があり、ページはその帯の上で切れていました。ページは下のタブの下まで続き、一番下の行はスクロールすれば下のタブの上に出ます。
- **スマホで、ページの上を右へ払うとメニューが開き、左へ払うと閉じるようにしました。** 払っているあいだ、メニューは指についてきます。ターミナル・入力欄・横にスクロールする物の上では開きません。
- **タッチ対応のPCでも、画面がPCの大きさならPCと同じ表示にしました。** これまでは、タッチの画面だと分かると、幅に関係なくボタンを指で押す大きさ（44px）にしていました。そのため、サイドバーのセッションの行が高くなり、どの行にも「…」と×が出ていました。
- スマホでは、見出しのボタン（［鍵を作成］など）を上のバーに出すようにしました。これまでは、ボタンだけで1行を使っていました。PCでは、右上にあった詳細の欄の開閉ボタンを、見出しのボタンの先頭に移しました。

## そのほか

- サイドバーのWorkspacesの見出しを、スクロールしても上に残るようにしました。
- PCの窓の幅が1024px未満のとき、SSH KeysやGroupsの詳細の欄はページを覆い、見出しの開閉ボタンも隠れていました。欄の右上に閉じるボタンを置きました。
- `sshc telnet`と`sshc serial`の`--non-interactive`の自動処理を、Ctrl+CやSIGTERMで止めたとき、まれに終了コードが130ではなく1になっていた不具合を直しました。
