# sshc v0.70.0

v0.70.0では、画面ごとに作りが違っていた部品をそろえました。知らせ、入力欄の誤り、押したあとに待つボタン、操作が済んだときとコピーしたときの知らせ方、ダイアログやフォームの最後のボタンの行、読み込み中の表示が、どの画面でも同じ形になります。設定や接続先などの編集は、画面の下の帯の［保存］でまとめて保存する形に変更しました。

あわせて、リモートセッションをショートカットとコマンド検索で切り替えられるようにし、リモートセッションの枠の色を接続先ごとに決められるようにしました。リモートセッションの直し漏れ、ターミナルのフォーカス、Key barの読み込みの遅れなども修正しています。

## 設定と編集の保存

- これまでは画面ごとに保存の仕方が違い、スマホではキーボードのEnterを押さないと保存できない欄がありました。**変えた内容は、画面の下に表示する帯の［保存］を押したときにまとめて保存する形に変更しました。** 1行の欄でEnterを押すと、［保存］と同じように保存します。
- 帯は、変更があるあいだだけ表示します。スマホでは下のバーの上に、キーボードを開いているあいだはそのすぐ上に表示します。［変更を破棄］を押すと保存前の値に戻ります。保存しないまま別の画面へ移ろうとすると、変更を破棄してよいかを確かめます。
- 入力に誤りがあるあいだは、［保存］を押せません。
- 対象は、Settingsの全ページ（マスターパスワードの変更を除く）、接続先とグループの編集、VPNプロファイルの編集、Snippets、SSH Config、Vaultの認証情報の編集、Syncの除外設定です。新しく作るフォーム（接続先、VPN、認証情報の追加）とマスターパスワードの変更は、これまでどおりそれぞれのボタンで保存します。
- 設定を保存したときの「保存しました」は、これまで欄の横に表示していましたが、画面の下の短い知らせで表示するように変更しました。VPNとVaultの編集の［キャンセル］は［閉じる］に変更しました。

## 知らせ

- 画面の中の知らせを、枠と地にだけ色を付けたカードに変更しました。字は読みやすい色で表示し、見出しと、最初は畳んでおく詳しい説明を持てるようにしました。赤い字で書いていた段落や注意の箱も、同じカードにそろえました。
- 接続先でsshcエンジンが動いていないためにリモートセッションを使えないときは、見出しと接続名を表示し、接続先で実行するコマンドを［直し方］に畳みます。［もう一度試す］と［×］も表示します。
- これまでは、サイドバーの失敗の知らせ（リモートセッションのsshcエンジンを足せなかった理由、セッションやワークスペースの操作の失敗）と、Home、Connections、SFTP、Menuの失敗の知らせは、次の操作をするまで消せませんでした。**右上の［×］で消せるようにしました。**
- 操作が済んだときの結果（ポート転送の開始と停止、履歴の復元、Syncの送信や適用など）は、これまで画面に残る緑の知らせや1行の文で表示していました。**画面の下の短い知らせで表示するように変更しました。** マスターパスワードを変えたときと、Syncの設定を取り込んだときの案内は、あとで読み返せるよう、これまでどおり画面に残します。
- コピーのボタンは、押したボタンが2秒ほど「✓ コピーしました」に替わります。リンクの吹き出しのように押すと閉じるものは、画面の下の短い知らせでコピーしたことを知らせます。

## 入力欄の誤り

- 値に誤りのある欄は、枠を赤くし、直し方を赤い字で表示します。
- これまでは、ポートのような狭い欄のすぐ下に直し方を表示していたので、文が何行にも折り返していました。**狭い欄が並ぶ所（新しい接続先、接続先の基本のタブ、Settingsのマシンの一覧のポート）では、欄を並べたまとまりの下に、欄の名前を付けて表示するように変更しました。**
- 自作のキーのダイアログは、誤りのときに補足の文が誤りの文に入れ替わっていました。補足を残し、その下に誤りを表示するように変更しました。
- 接続先のパスワードの注意（「PasswordAuthenticationがnoのため…」など）から△の印を外し、ほかの設定の行の注意と同じ形にしました。

## 待っているあいだのボタンと読み込み中の表示

- これまでは、押したあとに処理を待つボタンに、文言を「作成しています…」などに替えるもの、薄くなるだけのもの、文言を変えないものが混ざっていました。**押したボタンだけが、回る印と「保存中…」「接続中…」のような文言に替わる形に変更しました。** ほかのボタンは押せなくなるだけです。
- ホスト鍵の確認の［やめる］、パスワードの保存の［保存しない］、Snippetsの［中止］は、文言を変えずに回る印だけを表示します。
- VPNの行の［接続］は、ルートを用意しているあいだ、左の状態の札が回る印と「接続中」を表示するので、ボタンは押せなくなるだけにしました。
- Diagnosticsの［設定を解析］［疎通を確認］［認証を確認］は、押しても押せなくなるだけでした。押したボタンに回る印を表示するように変更しました。
- 「読み込み中…」の1行は、場所ごとに字の大きさや回る印の有無が違っていました。補足の字と同じ大きさの1行に小さい回る印を添える形にそろえました。すぐに読み込みが終わるときは表示しません。

## ダイアログとフォームのボタンの行

- ダイアログやフォームの最後のボタンの行を、右に寄せ、狭い幅では折り返す形にそろえました。Syncの強制送信と受信の確認の確定のボタン、秘密鍵の表示の［閉じる］［秘密鍵を表示］、Historyの確認のスマホでのボタンは、これまで左にありましたが、右に移しました。
- ページのフォームの最後のボタンの行には、上に線を引きます。Syncの設定の取り込みにも線を引くようにしました。
- 字の無い印だけのボタン（［×］など）の大きさと押せる範囲を、置き場所の種類ごとにそろえました。

## リモートセッション

- **リモートセッションを、キーボードのショートカットとコマンド検索から切り替えられるようにしました。** これまでは、サイドバーの一番下の［リモートセッション］から選ぶ必要がありました。
  - 「次のリモートセッション」「前のリモートセッション」の既定は、Alt+Shift+PageDown／Alt+Shift+PageUpです。
  - 「1番目のリモートセッション」〜「9番目のリモートセッション」の既定は、Ctrl+1〜Ctrl+9（Macでは⌘+1〜⌘+9）です。番号は［リモートセッション］の一覧の並びで、1番目はlocalhostです。その番号のリモートセッションが無いときは、キーをそのままターミナルへ送ります。
  - コマンド検索に「リモートセッション: 接続名」の項目を表示します。
- リモートセッションの枠と名札の色を、リモートセッションごとに変えられるようにしました。色は、そのsshcエンジンの接続先（このマシンのConnections）の「色」、［Settings］→［Appearance］の「リモートセッションの枠の色」、さし色の順に決まります。何も決めていないときの色は、これまでの橙からさし色に変更しました。［リモートセッション］の一覧の［…］の［接続設定を開く］から、その接続先の色を変えられます。
- リモートセッションを選んでいるのに、最近使った接続先（新しいセッションと分割の接続先の選択、SFTPの接続先の選択と「最近」）と、SSH KeysのOSを、このマシンから読んでいました。接続先のsshcエンジンから読むように修正しました。
- スマホで、リモートセッションの枠と名札がダイアログの下に隠れることがありました。ダイアログを開いているあいだも見えるように修正しました。

## そのほかの修正

- セッションを開いた直後にサイドバーで名前を変え始めると、あとから表示されたターミナルが入力を受け取り、名前の欄が閉じて、打った文字がシェルに入ることがありました。ターミナルではない欄に打っているあいだは、ターミナルが入力を受け取らないように修正しました。
- SettingsのKey barを開くと、約5秒「キーの並びを読み込み中…」のままでした。すぐに読み込むように修正しました。
- 接続先の［踏み台・転送・その他］のポート転送の表は、狭い幅で転送先の幅が足りず、`127.0.0.1:9000`のような値が途中で折れていました。狭い幅では待ち受けを種類の下に重ね、転送先に幅を残すように変更しました。
- Homebrewでソースから入れるときに画面を組み立てるNode.jsを、PATHの`node`を置き換えない`node@24`に変更しました。
- ドキュメントのサイトの角の丸めを8pxと4pxにそろえました。日本語のページでは、検索や表示の切り替えも日本語で表示します。
