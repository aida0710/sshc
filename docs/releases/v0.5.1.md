# sshc v0.5.1

CI とプロジェクト文書を整備したメンテナンスリリースです。新機能の追加はありません。

## 修正

- macOS で短命な子プロセスを使う PTY テストが不安定になる問題を修正しました。
- 実行時間の長い E2E テストを GitHub Actions から外し、`make e2e` によるローカル実行へ変更しました。E2E テスト自体は維持しています。
- `install.sh` が実行中エンジンのバージョンを人間向け出力から読み取ろうとしていた問題を修正しました。
- README、設計文書、コードコメント、CLI と UI の文言を、現行実装に合わせて整理しました。
- GitHub Release の本文を `docs/releases/<tag>.md` で管理し、公開内容とリポジトリ内の正本を一致させました。

## インストール

```sh
brew install aida0710/tap/sshc
```

または:

```sh
curl -fsSL https://raw.githubusercontent.com/aida0710/sshc/main/install.sh | sh
```
