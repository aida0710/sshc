# sshc v0.55.0

v0.55.0では、画面の見た目を作り直しました。サイドバーは一段明るい板に、ターミナルとすべてのページは角丸の板になり、見出し・節・入力欄の形がページをまたいでそろいます。Settings → Appearanceで、テーマに加えてさし色を選べるようにしました。

あわせて、ターミナルに出たパスから画像以外のファイルも開けるようにし、音声と動画はその場で再生できるようにしました。サイドバーのセッションの行と分割表示の一覧、Menu、ログイン前の画面、Home・Connections・SFTPも新しい形にしています。

## 見た目

- **ターミナルとすべてのページを、角丸の板に入れました。** これまでは画面いっぱいに広がり、枠や帯で区切っていました。ページは見出し（名前・件数・右に主な操作）の下に、線で区切った節を並べます。入力欄は広い画面では左に名前、右に入力の行になり、狭い画面では名前の下に入力が来ます。
- **Settings → Appearanceで、さし色を選べるようにしました。** 薄紫・青・水色・ピンク・モノクロから選びます。選んだ色はマシン間で同期します。
- 見出しの下の説明文は、画面を見れば分かることの説明をやめ、知らないと困ることだけを残しました（VPNにDockerが要ること、Diagnosticsは検査を始めるまで接続しないこと、Engineの設定は同期されないことなど）。
- 選択欄の矢印、ボタンの大きさ、表の行の高さ、空のときの表示も、ページをまたいで同じ形にしました。

## サイドバーと分割表示

- **セッションの行を、詰めた2行にしました。** 1行目に名前、2行目に接続先（つながっていないときは状態の文）を出し、名前をなるべく長く見せます。未読の通知がある行は橙の点が付き、見出しに［未読の通知 N］が出ます。
- **分割表示の一覧に、ペインの並び方の小さな図と、入っているセッションを出すようにしました。** 中のセッションを選ぶと、その分割を開いてそのペインにフォーカスします。［解除］はグループの［…］の中に移しました。
- Workspacesの行には、そのセッションが分割のどの位置にいるかを小さな図で出します。

## Home・Connections・SFTP

- **Home**の接続先は、さし色の四角にOSの印、名前と宛先、右にグループ名（無ければ「未分類」）を並べたカードにしました。マウスを乗せると、グループ名の位置に［…］が出ます。
- **Connections**のグループの一覧は、Settingsのページの一覧と同じく板の外に置きました。板の中は、接続の一覧と編集を線で分けます。Basicとsshcのタブの入力欄は、左に名前・右に入力の行になりました。接続の一覧の幅は既定の300pxに戻ります。
- **SFTP**は、タブ・場所の帯・ファイルの表・転送マネージャーを1枚の板にまとめました。左右に並べたときは、ターミナルの分割と同じく板を2枚並べます。［比較］は右端のタブの帯にあります。
- SFTPでこのPCのホームフォルダの中を開いているときは、場所の表示を`~`から始めるようにしました。これまでは`/home/…`の上のフォルダから並べていたので、今いるフォルダが右へ押し出されていました。

## ターミナルに出たファイルのプレビュー

- **画像以外のファイルも、ターミナルに出たパスから開けるようにしました。** テキストとソースコード、SVG、PDF、音声、動画、圧縮ファイルの名前も押せます。テキストは読み取り専用のエディタで色付きで表示します（2 MiBまで）。
- **音声（mp3・wav・m4aなど）と動画（mp4・webm・movなど）は、プレビューの中で再生できるようにしました。** SSHの接続先のファイルも、再生する位置の分だけを読み込みます。ブラウザが再生できない形式は、そう表示してダウンロードのボタンを出します。
- **どのファイルにもダウンロードのボタンを付けました。** プレビューできない形式や大きすぎるファイルでも、画面を開いて理由を表示します。
- ←→ と［前へ］［次へ］で、押せるファイルを順に移れます。

## ログイン前の画面

- Vaultの作成、ロックの解除、セッションの終了の画面を、左に名前と説明、右に入力の横長のカードにしました。スマホでは縦に並びます。
- 外観と言語の切り替えは、カードの外の右上に小さく置きました。マスターパスワードの［表示］は、欄の中の右端にあります。
- 見つからないページは、ほかのページと同じ板の真ん中に、URLと［ホームへ移動］を置きました。

## スマホ

- セッションを操作できる間は、上の見出しと下のタブの代わりに、ナビゲーションを開くボタン・名前と接続先・［…］の上のバーを出すようにしました。
- ターミナルに送る文の入力欄を、いつも出すようにしました。変換を確定するEnterでは送りません。改行を含む文は、貼り付けの確認画面を通ります。

## 不具合の修正

- **ターミナルがつながった直後に、ほかの入力欄からフォーカスを奪わないようにしました。** これまでは、開いた直後にサイドバーでセッションの名前を変えようとすると、欄が閉じることがありました。
- Vaultのパスワードを間違えたとき（短すぎるときも）、欄の下の文だけを出すようにしました。これまでは、エラーコード付きの診断の箱も同時に出ていました。
- Historyの日時を、`2026-10-26T17:25:23Z`のような形ではなく、表示の言語に合わせた形で出すようにしました。
- Settingsで長いページを下へ送っても、左のページの一覧が見えたままになるようにしました。

## Homebrewとソースからのビルド

- **Homebrewのformulaは、画面をNode.js 22で組み立ててからビルドするようにしました。** 組み立てた画面をリポジトリに入れるのをやめたためです。Node.js 22は、ビルドのときだけHomebrewが入れます。
- 画面を組み立てずに作ったバイナリ（`go install`など）は、画面の代わりに「画面が入っていない」と表示します。sshcは、リリースの成果物かHomebrewで入れてください。
