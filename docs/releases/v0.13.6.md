# sshc v0.13.6

Android 16で初回vault作成が失敗する問題を修正し、vault作成・解除画面から安全な診断情報を確認できるようにしました。

## Android 16のvault保存修正

- 初回vault保存時に取得するworkspace更新lockのpath traversalを修正しました。AndroidのSELinuxが`/`や`/data`の一覧読み取りを拒否する環境でも、中間directoryを`O_PATH`で辿り、アプリ専用directoryだけを読み書き用に開きます。
- descriptor-relativeな`openat`、`O_NOFOLLOW`、lock directoryのidentity固定、symlink拒否は維持しています。
- API 36のKVM Emulatorで、初回インストール状態からvault作成、アプリ強制終了、再起動、同じvaultの解除までを実行するruntime integration testを追加しました。

## vaultエラー診断

- vault作成・解除失敗時に、version、安定したerror code、HTTP status、操作pathname、安全確認済みdetailを画面で確認・コピーできます。
- Android private storageの権限拒否、容量不足、read-only、I/O失敗、更新競合を個別のcodeと案内へ分類します。
- request body、マスターパスワード、query、内部の絶対pathは診断レポートへ含めません。
- 初期画面が古く、既にvaultが作られていた場合は状態を再取得し、破壊的な再作成を行わず解除画面へ切り替えます。

## 検証

- Linuxでdirectory一覧のread権限を持たず通過権限だけを持つancestorを再現し、workspace更新lockを取得できることを継続検証します。
- Go、Web、Android debug buildに加え、Android 16 Emulator上のvault lifecycleと作成後・再解除後のホーム画面をスクリーンショットで確認しました。

## 互換性

vault、設定、Workspace、Snippet、同期snapshot、SFTP転送queueの保存形式は変更していません。
