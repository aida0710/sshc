# sshc v0.21.1

自動同期が不要な履歴オブジェクトを増やさないよう、受信確認と送信のタイミングを分離し、受信専用端末の復旧導線とモバイル操作を整えたパッチリリースです。

## 自動同期

- 自動同期中の定期処理を、1分ごとのリモート更新確認だけに変更しました。変更のない巡回ではS3へアップロードしません。
- sshcで設定、接続、鍵、Known Hosts、保存パスワード、スニペットを変更すると、最後の変更から5秒間ほかの変更がなかった時点で1回だけPushします。5秒以内の再変更は待機時間を延長します。
- Pullの適用や同期状態の記録をローカル編集として扱わず、受信した内容を直後に送り返すことや、同じ内容の履歴を繰り返し作ることを防ぎました。
- engine再起動後は、Sync画面を開かなくてもVault内の保存済みバケット設定を復元して自動同期を再開します。
- 自動同期欄と日英ドキュメントへ、1分ごとの受信確認と5秒の送信待機を明記しました。

## 受信専用と画面操作

- 受信専用端末でリモート履歴が分岐した場合、現在のリモートを確認して明示的に受信できる導線を追加しました。受信専用の操作はリモートへ書き込みません。
- 同期設定の管理領域をバケットと暗号化キーへ整理し、スナップショット操作と履歴を通常の同期画面へ分離しました。
- Androidの戻る操作がアプリ内の画面履歴をたどるよう修正しました。
