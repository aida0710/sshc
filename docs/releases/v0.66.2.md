# sshc v0.66.2

v0.66.2では、画面の見た目の不ぞろいをまとめて直しました。文字の大きさ、見出しの太さ、フォーカスの枠が、どの画面でも同じ決まりで表示されます。

あわせて、作業中のセッションに出る回る印の、向きのずれと表示の遅れを直しています。

## 作業中の印

- 作業中のプログラムがあるセッションの行には、回る印が出ます。これまでは、作業を始めた時刻が違うと、印がセッションごとに違う向きで回っていました。**どのセッションの印も同じ向きで回るようにしました。**
- Claude Codeなどが作業を始めた・終えたことが、セッションの行に出るまで最大2秒遅れていました。表示しているターミナルでは、すぐに出るようにしました。

## 画面の見た目

- 文字の大きさに、12pxと12.5px、13pxと13.5pxのような見分けの付かない差が混ざっていました。**名前は14px、補助の文は12px、入力欄とボタンは13pxにそろえました。**
- ページやダイアログの中の節見出しが、太字と中太に分かれていました。太字にそろえました。
- Syncの「詳細と履歴」は、箱の中に箱が重なっていました。重なりを1段減らし、警告の文を周りの文と同じ大きさにしました。
- 英語の表示で、一部のラベルだけが大文字になっていました。書いたとおりの表記にしました。接続先を選ぶ画面では、付けたグループ名がそのまま表示されます。
- 選択中の行と、マウスを載せた行が同じ色になる画面がありました。載せた行は通常のホバーの色で表示します。

## キーボードでの操作

- 入力欄にフォーカスしたときの枠が、ボタンと違う形でした。どちらも同じ2pxの枠で表示します。
- 一覧の端まで届く行やタブでは、フォーカスの枠の片側が欠けて見えませんでした。Connectionsのグループ、サイドバーの「新しいセッション」、接続エディタのタブ、スニペットの一覧、SFTPのタブとパンくずで、枠の全体が見えるようにしました。
- スマホの送信ボタンは、送れないときの薄さがほかの押せないボタンと違っていました。同じ薄さにしました。
