# sshc v0.33.2

パスワードレスVaultで不要だったパスワード入力と手動ロックを省き、CLIのパスワード確認と画面のサイズを改善しました。

## Vaultの操作

- パスワードレスでは、Web・CLIともパスワード変更時の「現在のパスワード」入力を省略します。
- パスワードレスVaultへの手動ロック要求は解錠状態を維持します。Webのロックボタンとコマンドパレットのロック項目も非表示になります。パスワードを設定すると、現在パスワード欄とロック操作が再び使えます。
- CLIの`vault change-password`は、現在パスワードでEnterを押した直後に検証します。間違っている場合は、新しいパスワードを尋ねずに終了します。
- CLIの`vault unlock`は、パスワードレスならパスワード入力や対話端末を要求しません。`vault status`にはパスワードレスであることを表示します。
- パスワードありのVaultは、現在パスワードの確認と手動ロックを維持します。engine終了時のメモリ上の鍵の破棄も維持します。

## 画面と補完の案内

- 接続一覧のPanels／List切り替えボタンを、横にある検索バーと同じ高さに揃えました。
- Menu最下部のOthers → Licenseを、ほかのメニューと同じ1列分の幅に揃えました。
- LinuxのBashがHomebrewの補完を読み込まない場合の対処をCLIガイドに追記しました。現在のBashでは`source <(sshc completion bash)`で操作名・接続先名の補完を読み込めます。

## 更新後

CLIとWebの変更を反映するため、バイナリ更新後に稼働中のengineも再起動してください。古いengineに対して新しいCLIでパスワード変更を行うと、更新・再起動の案内を表示します。

v0.33.1で導入したメタデータ形式v5を引き続き使用します。同じデータを同期する端末は、すべてv0.33.1以降へ更新してください。
