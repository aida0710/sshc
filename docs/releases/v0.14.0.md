# sshc v0.14.0

接続済みターミナルを直接Drag & Dropして組み立てるLive Workspaceを追加しました。デスクトップでは自由な分割配置、スマホでは1画面ずつの切り替えとして、同じ接続を使い続けます。

## Live Workspace

- 接続一覧のSSHターミナルを、表示中のターミナルの左・右・上・下へDrag & Dropして分割できます。
- Drop前に配置予定の半面を表示し、既にWorkspace内にあるpaneも同じ操作で別の位置へ移動できます。
- Dragした接続は開き直さず、既存のsession ID、process、scrollbackを維持します。
- 2つ以上のpaneは接続一覧で1つのLive Workspaceへ自動的にまとまり、必要な場合だけメンバーを展開できます。
- paneをWorkspaceから外してもSSH接続は切断しません。2 paneから1つを外した場合はグループだけを解消し、両方を独立した接続として残します。

## デスクトップとスマホ

- デスクトップでは従来の分割resize、Focus Mode、Broadcast Input、Workspace全体へのcommand／Snippet実行とDrag配置を組み合わせられます。
- スマホでは複数paneを狭く並べず、Workspace専用タブから1つずつ切り替えます。分割・Broadcast・pane移動操作は表示しません。
- 接続一覧からWorkspaceメンバーを選ぶと、デスクトップとスマホの両方で対応するpaneへfocusが移ります。

## 保存Workspace

- Live Workspaceは接続中のsessionをまとめる実行単位、保存Workspaceはaliasとlayoutを保存する再接続用の定義として分離しました。
- 名前を付けて保存したlayoutは従来どおりHomeから再オープンでき、失敗したpaneがあっても成功した接続を維持します。
- 単独の接続を保存しても、既に開いているLive Workspaceを上書きしません。

## 検証

- layout reducer、端Drop、既存pane移動、接続一覧の折りたたみ、スマホの1 pane切替、resize、Focus Mode、部分的な復元失敗を自動テストしました。
- Chromiumの実画面でデスクトップと360×800のスマホ幅を撮影し、分割、グループ化、単一pane表示、横方向のはみ出しがないことを確認しました。
- Webの全テストとGo全packageのテストを通過しています。

## 互換性

vault、設定、保存Workspace、Snippet、同期snapshot、SFTP転送queueの保存形式は変更していません。Live Workspaceは実行中のUI状態で、永続化は明示的な「Save layout」から行います。
