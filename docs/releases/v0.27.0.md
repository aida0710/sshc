# sshc v0.27.0

v0.27.0では、SFTPの2ペイン表示を左右対称のタブ構成へ変更しました。左側だけでなく右側にも複数の接続先やディレクトリを開き、表示中のタブ同士でファイル操作を行えます。

タブが画面に収まらない場合の操作と、スマートフォンでの1ペイン表示も見直しました。

## SFTPの2ペインとタブ

- 左右のペインが、それぞれ最大8個のタブを持つようになりました。各タブは接続先、ディレクトリ、履歴、選択状態を個別に保持します。
- 初めて2ペインへ切り替えたときは、左側で開いているタブを右側へ複製します。1ペインへ戻しても右側のタブは破棄せず、次に2ペインへ切り替えたときや画面を再表示したときに復元します。
- ディレクトリ比較とペイン間のドラッグ＆ドロップは、左右で表示中のタブを対象にします。TerminalやCommand PaletteからSFTPを開いた場合も、操作中のペインにある表示中のタブへ反映します。

## タブが多い場合の操作

- タブがペインの幅を超えると、タブ列だけを横へスクロールできます。画面幅を理由に新しいタブの作成を止めることはありません。
- 新しいタブを作る`+`ボタンはスクロール領域の外へ固定しました。タブを選択または作成すると、そのタブが見える位置まで自動でスクロールします。

## スマートフォン

- スマートフォンでは、横スクロールできるタブ列と1つのファイルペインだけを表示します。右ペイン、ディレクトリ比較、2ペイン切り替えは動作させません。
- デスクトップで開いていた右側のタブは削除しません。広い画面へ戻ると、保存していた2ペインの状態を再び利用できます。

## ドキュメント
