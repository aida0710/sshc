# sshc v0.17.3

接続先が多い環境でも所属グループを把握しやすくし、Connectionsの編集画面をPCとスマートフォンの両方で扱いやすくした更新です。v0.17.2はリリース用Linuxテストのタイミング依存によって公開前に停止したため、同じ製品変更と安定化した回帰テストをv0.17.3として公開します。

## 変更

- HomeのQuick Connectを階層ドリルダウンへ変更し、現在の階層にある子グループだけを小型パネルで表示するようにしました。選択した親グループ以下の接続先は子孫グループを横断して絞り込めます。
- Connectionsをグループ管理へ集中させ、接続先一覧を`parent`、`parent/child`の細い見出しで区切りました。SSH ConfigのファイルとパターンルールはSSH Config画面で確認できます。
- スマートフォンでは横スクロールするグループツリーを廃止し、フルパスを表示するネイティブセレクターへ変更しました。
- 接続編集の主ナビゲーションを`Basic`、`Analysis`、`Advanced`のフラットな下線タブへ変更し、編集領域を囲っていた大きなカードを撤去しました。
- Advanced内はPCで`Jump Host`、`Directives`、`Raw`の下線タブ、スマートフォンでネイティブセレクターを使用します。
- 疎通・認証確認を設定フォームの一段上へ移し、保存・破棄操作は値を変更したときだけ親と同じ背景上へ表示するようにしました。

## リリース安定化

- 無効なUTF-8をbase64で報告する回帰テストから1msタイマーと非同期書き込みへの依存を除き、低速なビルド環境でも決定的に検証できるようにしました。
