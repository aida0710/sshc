# sshc v0.61.1

v0.61.1では、スマホの画面で、リモートセッションにつながらないときのパネルの周りから、裏のターミナルが見える不具合を修正しました。

## スマホの画面

- スマホの画面では、リモートセッションのsshcエンジンにつながらなくなると、「〜にSSHで接続できませんでした」のようなパネルが出ます。これまでは、セッションを開いたあとにこのパネルが出ると、下のタブバーの左右と下の隙間から、裏のターミナルのキーバーと入力欄が見えていました。**パネルが出ている間は、裏のターミナルを隠す**ように修正しました。
- 隠すだけで閉じはしないので、sshcエンジンがまた答えると、ターミナルは前の大きさと出力のまま戻ります。パネルが出ている間も、タブバーはこれまでどおり押せます。
- 「〜のVaultがロックされています」「〜のsshcとは組み合わせて使えません」など、ほかの理由で出るパネルでも同じように隠します。
