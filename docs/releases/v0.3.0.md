# sshc v0.3.0

実行中の接続を誤って終了しないための確認操作と、鍵管理画面の改善を追加しました。

## 主な変更

- 実行中のコンソールを閉じる前に確認ダイアログを表示します。
- 「すべて閉じる」操作でも、実行中の接続がある場合は確認します。
- 接続の削除を、同じボタンの二度押しではなく明示的な確認ダイアログへ変更しました。
- 終了済みのコンソールは、失われる実行状態がないため確認せずに閉じます。
- 鍵のフィンガープリント、鍵長、権限、参照元を詳細ペインへ移し、狭い画面でも表が横にあふれないようにしました。
- ごみ箱を鍵一覧の隣へ移動し、不要な SSH 設定解決を削除して表示を高速化しました。
- 接続拒否時の詳細な理由を API 契約へ追加しました。

**変更履歴**: [v0.2.0...v0.3.0](https://github.com/aida0710/sshc/compare/v0.2.0...v0.3.0)
