# sshc v0.65.0

v0.65.0では、スマホ版（Androidのアプリ）の指の操作を、写真のアプリのように指に付いてくる動きに改善しました。対象はサイドバーのスワイプ、ファイルのプレビューのスワイプとズーム、ターミナルの指のスクロールです。

どの操作も、指が触れている間は指と同じだけ動き、指を離したあとは離した速さを引き継いで止まります。動いている途中で指が触れると、その位置から続けて動かせます。

## サイドバー

- これまでは、指を離すと決まった時間をかけて開閉していました。離した速さを引き継いで開閉するように変更しました。速く払うほど早く開閉します。
- 後ろの暗い幕を、パネルの出ている割合だけ濃くするようにしました。これまでは、指を離した瞬間に幕が出たり消えたりしていました。

## ファイルのプレビュー

- これまでは、画像や動画を指で動かしても、指を離すまで絵は動きませんでした。**横や下へ動かすと、絵が指に付いてくる**ように変更しました。
- 前後のファイルへ移るのは、絵の幅の4分の1まで動かしたときか、その向きへ払ったときです。足りないときは元の位置へ戻ります。
- 前や次のファイルが無い向きや上へ動かすと、少しだけ動いて戻ります。
- 下へ動かすと、絵が小さくなって後ろの画面が透けて見え、見出し・ズームのボタン・プロパティも薄くなります。そのまま離すと閉じ、指を戻すと元に戻ります。
- 拡大した絵を指で払うと、少し流れてから止まります。端より先へ引くと少しだけ動き、ピンチで最小より小さく・最大より大きくすると少しだけ縮み・広がります。どちらも離すと戻ります。

## ターミナル

- これまでは、指でスクロールすると、いちばん新しい行と古い行でぴたりと止まりました。**端より先へ引くと少しだけ動き、離すと戻る**ように変更しました。払った勢いで端に着いたときも、軽く跳ね返って止まります。
- 指の動きの知らせが届かないまま指が離れたとき、払う操作をタップと見なしてキーボードを開いていたのを直しました。

## Androidのアプリ

- 画面を移った直後（切り替えのフェードの途中）に戻るジェスチャーをすると、Homeではなく前のページへ戻ることがあったのを直しました。

「動きを減らす」がオンのときは、指を離したあとの動きを省き、すぐに行き先へ移します。指が触れている間の動きは変わりません。
