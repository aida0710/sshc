# sshc v0.33.1

キーコンフィグを名前付きプリセットとして同期できるようになりました。使用するプリセットはブラウザーごとに選べます。

## キー設定の同期プリセット

- Settings → Shortcutsで、プリセットの作成・複製・名前変更・削除ができます。8操作のショートカット設定をプリセットごとに保存できます。
- プリセットの内容は既存の暗号化同期に含まれます。たとえばLaptopとDesktopを用意して、各ブラウザーで使い分けられます。選択中のプリセットは同期しません。
- 既存のブラウザー内のカスタム設定は、初回にImported shortcutsとして移行します。新しいブラウザーではDefaultから開始します。
- 別の画面で更新された設定を古い内容で上書きしないよう、保存時の競合を検出します。使用中のプリセットが削除された場合はDefaultに戻ります。

## 更新時の注意

プリセットの保存に伴い、メタデータ形式をv5へ更新します。**同じデータを同期する端末は、すべてv0.33.1以降へ更新してください。** 旧バージョンは新しいメタデータ形式を読み込めません。

## テストの安定性

macOS CIで同期履歴と鍵変更の並行テストが失敗する問題を修正しました。鍵導出にかかる時間を2秒以内と仮定せず、処理の実行順序を同期して検証します。
