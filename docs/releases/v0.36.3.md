# sshc v0.36.3

v0.36.3は、大きなファイルの転送を既定で1つのSFTP接続にし、ワンタイムコード（TOTP）で認証するホストから100 MiB以上のファイルを取得できなかった問題を直す修正リリースです。

## SFTP

- **大きなファイルの分割転送は既定で行わなくなりました。** これまでは100 MiB以上のファイルを4つのSFTP接続で並列に転送していましたが、パイプライン化した1接続で多くの回線は埋まり、2本目以降の接続はワンタイムコードのホスト、ユーザーごとの接続数制限、認証の遅いホストで失敗の原因になっていました。並列にする場合は、Webの転送マネージャーの設定、`sshc sftp settings --split-jobs`、または`get`／`put`の`--split-jobs`で接続数を指定してください。既に接続数を保存している場合はその値のままです。

- **ワンタイムコードのホストで100 MiB以上のダウンロードが`sftp_failed`で即座に失敗する問題を直しました。** 大きなファイルは範囲ごとにSFTP接続を増やして並列に読みますが、TOTPのホストでは同じ時間窓に開く2本目以降の接続が「使用済みのコード」として拒まれていました。ワンタイムコードが割り当てられたホスト（ProxyJumpの経由地を含む）は1接続で逐次に読みます。
- 範囲用の接続は読み始める前にまとめて開き、開けなかった場合は開いている1本で逐次に読みます。これまでは途中で失敗して転送全体が落ちていました。

## 更新後に必要な操作

v0.36.0以降から更新する場合、追加の操作はありません。v0.35.0以前から更新する場合は、[v0.36.0のリリースノート](v0.36.0.md)にあるブラウザーの再登録とengineの再起動が必要です。
