# sshc v0.47.0

v0.47.0では、ターミナルで画像を表示できるようにしました。Sixel、iTerm2のインライン画像、kittyの画像形式に対応し、Claude Codeが会話の中で出す画像もターミナルの中に表示されます。

あわせて、プログラムが知らせる進み具合の表示、絵文字の幅のずれ、Androidアプリでのファイルのアップロード、ファイルの選択、ターミナルのリンクと通知を改善しています。

## 画像の表示

- これまではターミナルに画像を表示できませんでしたが、**Sixel、iTerm2のインライン画像（OSC 1337 File=）、kittyの画像形式を表示できるようにしました。** `chafa`、`img2sixel`、`timg`、`imgcat`などで試せます。
- Claude Codeは画像をkittyの画像形式で出します。これまではsshcで画像の代わりに「[img] 📷 (image)」と表示されていましたが、画像そのものを表示するようになりました。
- kittyの画像形式は試験的な対応で、データとして送られた画像だけを表示します。ファイルの場所や共有メモリで送る方法には対応しておらず、プログラムから問い合わせがあればそう答えます。
- iTerm2形式はPNG、JPEG、GIFに対応し、アニメーションは表示しません。大きさ（`size=`）を付けずに送られた画像は表示しません。`imgcat`などは大きさを付けて送ります。
- 画像は1つのターミナルにつき32 MiBまで保持し、超えた分は古いものから消します。
- セッションを開き直したときは、残っている出力から画像も描き直します。engineが保持しきれず途中で切れた画像は、データを文字として表示せずに読み飛ばします。

## 進み具合とフォルダの通知

- プログラムがOSC 9;4で進み具合を知らせると、**ペインの見出しの下端に細い線で表示**するようにしました。エラーは赤、一時停止は黄、終わりの分からない処理は動く線で表示します。進み具合は、プログラムが消去を送ったとき、シェルがOSC 133でコマンドの終了を知らせたとき、セッションが新しいシェルに替わったときに消えます。
- WindowsのPowerShellやcmdが送るOSC 9;9を、OSC 7と同じく現在のフォルダとして受け取るようにしました。WindowsのサーバーへSSHで接続しているとき、Terminalの「…」からそのフォルダをSFTPで開けます。

## 絵文字の幅

- これまでは絵文字を1マス分の幅で数えていたため、絵文字を2マスで数えるプログラム（Claude Codeなど）の表示で、絵文字より後ろの文字が1マスずつずれていました。**文字の幅をUnicode 11の規則で数える**ように変更し、絵文字は2マス分になりました。

## Androidアプリ

- これまでは、SFTPのアップロードでファイルを2つ以上選ぶと何も起きませんでした。1つ選んだ場合も「The SFTP operation failed.」と表示されて送れませんでした。**どちらも送れるように修正しました。**
- VPNのWireGuardとOpenVPNで設定ファイルを読み込むとき、ファイルの選択画面に.confや.ovpnのファイルが表示されない問題を修正しました。
- Androidのファイル選択画面はフォルダを選べないため、何も起きなかった［フォルダをアップロード］は表示しないようにしました。
- ターミナルに表示されたURLやパスをタップすると、ブラウザで開く、コピーするなどのメニューが開くようになりました。それ以外の場所をタップすると、これまでどおりキーボードが開きます。プログラムが出力するOSC 8のリンクは、タップでは開けません。
- これまでAndroidアプリでは、ターミナル内のプログラムからの通知（OSC 9／99／777）と長いコマンドの完了を知らせられませんでしたが、**sshcを閉じているあいだはAndroidの通知で届く**ようにしました。通知を押すと、そのターミナルを開きます。許可は［Settings］→［Notifications］の［通知を有効にする］で行います。通知の音は、sshcの「通知音」の設定で鳴らします。通知の本文はロック画面には表示しません。

## セキュリティ

- Sixelの画像の解読にWebAssemblyを使うため、画面のContent Security Policyの`script-src`に`'wasm-unsafe-eval'`を加えました。WebAssemblyのコンパイルだけを許すもので、`eval`や`new Function`によるスクリプトの実行はこれまでどおり止めています。
- ターミナルの描画部品xterm.jsを6.1.0-beta.315に更新しました。kittyの画像形式に対応した画像表示の部品が、この版を必要とするためです。
