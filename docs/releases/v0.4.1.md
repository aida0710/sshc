# sshc v0.4.1

SSH 接続ログとコンソールの終了処理を改善したリリースです。

## 新機能

- `ssh -v` 相当の接続ログをコンソールへ表示できます。
- ログの詳細度を、無効、`-v`、`-vv`、`-vvv` 相当の 4 段階から選択できます。

モバイル向けの Go エンジンでは、将来 iOS へ組み込む場合にローカルシェルを利用できないことを明示的に扱うようにしました。このリリースに iOS アプリは含まれません。

## 修正

- 利用者が閉じたコンソールで、自動再接続が開始される場合がある問題を修正しました。
- 手動で閉じたコンソールを一覧から直ちに削除するようにしました。
- 実行されない再接続予定が画面に表示される問題を修正しました。
- E2E テストが利用可能な CPU コアを使用するようにし、実行時間を短縮しました。
- README を利用者向けの概要に整理し、設計の詳細を `docs/design.md` へ移動しました。
