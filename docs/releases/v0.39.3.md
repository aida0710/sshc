# sshc v0.39.3

v0.39.3は、VPNのコンテナイメージの作成が、Ubuntuのミラーの状態によって失敗することがある問題を直す修正リリースです。

## VPN

- **VPNのコンテナイメージの作成が、Ubuntuのミラーが同期している最中に失敗することがある問題を直しました。** これまでは、パッケージの版を固定するスナップショットに加えて、通常のミラーからも索引を取得していました。ミラーが同期している最中だと、`File has unexpected size`や`Mirror sync in progress?`で作成に失敗していました。今後はスナップショットだけから取得します。amd64とarm64で同じ取得先を使います。

## 更新後に必要な操作

更新後はengineを再起動して、新しいバージョンを使用してください。

VPN機能を使用している場合、次にVPNに接続するときに、コンテナイメージがマシン上で1度だけ作り直されます。作成にはネットワークが必要です。
