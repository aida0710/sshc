# sshc v0.27.2

v0.27.2では、Terminal設定を変更しても保存エラーが表示される問題を修正しました。設定内容は保存されていた場合でも、Web側が成功応答を正しく扱えず失敗と表示していました。

あわせて、Terminalの描画方式を設定から切り替えられるようにし、macOSのChromium系ブラウザーで入力した文字が二重に見えたり、削除した文字が残ったりする描画問題への対策を追加しました。

## Terminal設定の保存

- Terminal設定とengine設定の保存結果を、それぞれのAPIが実際に返す内容に合わせました。OpenAPIから生成した検証処理が、正常な保存結果をエラーとして扱わないようになりました。
- 背景画像を設定した状態から「画像なし」へ変更する場合を含め、Terminal設定を正常に保存できるようになりました。
- 保存後に開いているTerminalへ設定を反映する処理が一時的に失敗しても、完了済みの保存を失敗として表示しないようにしました。通常の状態更新で表示を再取得します。
- 他のマシンから同期した開始ディレクトリが現在のマシンに存在しない場合でも、開始ディレクトリ自体を変更しなければ、フォントや描画方式などの他の設定を保存できます。

## WebGLと文字の描画

- Terminal設定へ「WebGL描画を使用する」を追加しました。既定では有効です。GPUやブラウザーとの組み合わせにより文字が二重に見える、または残像が残る場合は無効にできます。
- 背景画像を使用しているTerminalでは、設定にかかわらずWebGLを使わずDOM描画へ自動的に切り替えます。
- xterm内部では不透明な背景を使って文字を確実に消去し、背景画像はTerminalの外側のレイヤーで表示する構成へ変更しました。背景画像を維持しながら、行編集時の残像を避けます。
- 実際のローカルPTYを使い、入力、Backspaceによる書き換え、WebGL無効化、背景画像の設定と解除を確認するブラウザーテストを追加しました。
