# sshc v0.7.0

SFTPのフォルダ転送、Workspaceのresize／Focus Mode、Terminal内検索と補完を追加し、日常の接続作業を強化したリリースです。

## SFTP

- file／folder pickerとDrag & Dropから、directory階層を維持して再帰アップロードできます。Drag & Dropでは空directoryも維持します。
- file別状態とaggregate progressを表示し、転送中のcancelに対応しました。
- 既存fileは暗黙に置換せず、409応答後に個別のoverwrite／skipを確認します。
- directoryをZIPとしてdownloadできます。symlinkは追跡せず、安全な通常fileとしてlink targetを格納します。
- 種別、size、更新日時、権限を表示・sortし、file／directoryのchmodに対応しました。chmodはmetadata revisionと単回action tokenで保護します。
- SFTPはStart内のTerminal直前へ配置し、hostを選択するまで接続しません。

## WorkspaceとTerminal

- 縦横のsplit separatorをpointerまたはkeyboardでresizeし、比率をWorkspaceへ保存・復元できます。
- 保存layoutを変更せず単一paneだけを表示するFocus Modeを追加しました。Escまたはtoolbarで元layoutへ戻れます。
- Ctrl/Cmd+Fでscrollbackを検索し、前後の一致へ移動できます。
- live session内のcommand履歴から、prefix一致候補を頻度と新しさで表示します。履歴はdisk、Workspace、snapshotへ保存しません。
- SSH aliasがあるterminalでは、absolute remote pathの候補をSFTPで列挙します。terminalのcwdを推測するrelative path補完は行いません。

## 表示改善

- Keys、Known Hosts、SFTPのdata列を昇順／降順でsortできるようにしました。
- Sync画面を暗号化キー、旧形式移行、自動同期、送信・変更確認へ整理しました。
- terminalの空状態に表示するCLI例を`sshc host`へ修正しました。
- スマートフォンのheaderでは判断材料にならないsession online表示を削除しました。デスクトップ表示とscreen reader向けの状態通知は維持しています。

## 検証

- Goの全package testとrace detector、Android arm64 build、dead code検査を実行しました。
- Webのユニットテスト827件、TypeScript型検査、ESLint、production buildを実行しました。
- Playwrightの全108 E2E（Workspaceのresize／Focus／保存、360px表示を含む）を確認しました。
- 固定digestのOpenSSHコンテナで、SFTPのupload、file／directory download、chmod、競合拒否、rename、list、deleteを確認しました。
