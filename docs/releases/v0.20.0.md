# sshc v0.20.0

SSH接続設定の確認と安全なheadless同期をCLIへ追加し、Terminalの日常操作とAgent通知を整えた更新です。

## 接続設定をCLIで確認

- `sshc info <alias>`で、実際の接続処理と同じresolverが解決した接続先、認証方式、IdentityFile、ProxyJump、文字コードなどをSSH接続なしで確認できます。
- `sshc info <alias> --json`は自動化向けの安定したJSON schemaを返します。
- password、passphrase、vault／sync key、`SetEnv`の値、`ProxyCommand`本文は出力しません。人向け出力の制御文字も安全にエスケープします。
- 複数段のProxyJumpを接続、疎通確認、設定表示で同じ順序に解決するよう統一しました。

## headless sync

- 起動済みengineに対して、`sshc sync`、`setup`、`push`、`pull`、`now`、`auto on|off`をCLIから実行できます。
- `--json`では、成功・失敗を一つのJSON objectとして返すため、画面のないLinux環境や自動処理から利用できます。
- `sync setup`は端末上でcredentialを非表示入力し、remoteの確認が完了してから保存します。生成されたsync keyは対話端末に一度だけ表示します。
- force pushはremoteの確認結果に結び付いた短命action tokenを要求し、pullはETagとrevisionを照合します。競合や削除を暗黙に上書きせず、不確実な変更結果を自動再試行しません。
- CLI用sessionは短命かつcommand単位で失効し、browser bootstrapや既存Web sessionを消費しません。
- WindowsのCRLF入力でもsetupの回答がずれないよう修正しました。

## TerminalとAgent通知

- スマートフォンで画面左端から右へスワイプするとnavigation drawerを開けるようになりました。
- デスクトップの貼り付けが二重入力になる問題と、検索barを開いた際にTerminal描画がずれる問題を修正しました。
- Terminalのオートコンプリート実装を削除し、shellや接続先本来の補完を妨げないようにしました。
- Agentの`ready`状態を時間経過だけで「状態不明」へ戻さず、次のeventまたはprocess終了まで維持します。
- Settingsからbrowser通知を明示的に許可し、テスト通知を送れるようにしました。permission promptを起動時に自動表示しません。

## SSHと同期の安定性

- ProxyJump先で利用できる鍵やpasswordがない場合、失敗したhopを区別した診断を返すようにしました。
- 実OpenSSH serverを使う多段ProxyJump認証のintegration testを追加しました。
- 同期pullの上書き競合を通常の接続障害と分け、安全な再試行や明示操作へ案内します。
