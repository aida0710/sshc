# sshc v0.17.1

暗号化同期でSSH設定が参照する鍵を確実に運び、日本語UIの用語と識別表示を整えた更新です。

## 変更

- Remote Syncが`~/.ssh`配下の通常ファイルを元の相対パスのまま再帰収集し、ルート直下や任意のサブディレクトリに置いた秘密鍵・公開鍵も暗号化スナップショットへ含めるようにしました。
- 同期資格情報、端末固有状態、履歴・バックアップ・一時ファイルは同期対象から除外し、シンボリックリンク、socket、FIFO、deviceは追跡しません。
- 日本語UIの主要ナビゲーションをConnections、Terminal、SSH Config、SSH Keys、Vaultなどの定着した製品名へ揃え、説明文、状態、助数詞を自然な日本語へ修正しました。
- History、Snippets、Keys、Terminalで内部のoperation、status、key kind、problem codeを直接表示せず、既知値は翻訳し、未知値は安全な一般表現へ置き換えるようにしました。
- Reactの障害画面とAndroidネイティブ外殻へ日本語表示を追加し、英日メッセージのキー・プレースホルダー整合性を回帰テストで固定しました。
- Quick Connectの`>_`をsshcのアプリアイコンへ置き換え、言語切替の表示を英語・日本語とも`Lang`へ統一しました。

**変更履歴**: [v0.17.0...v0.17.1](https://github.com/aida0710/sshc/compare/v0.17.0...v0.17.1)
