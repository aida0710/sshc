# sshc v0.53.1

v0.53.1では、ターミナルに出た画像の相対パスを押して開けるようにしました。Claude Codeが送った画像の行（`[image] artifacts/….png`）は、作業フォルダの下にある画像を相対パスで示します。v0.53.0では`/`で始まるパスしか押せず、この行を開けませんでした。

あわせて、サイドバーのセッションをドラッグで別のワークスペースへ移せるようにしています。

## 画像の相対パス

- **`artifacts/shot.png`のような相対パスも、押して［プレビュー］で開けるようにしました。** 押せるのは、名前が`.png`、`.jpg`、`.jpeg`、`.gif`、`.webp`、`.bmp`で終わるものだけです。ふつうの出力に出る`src/main.go`などには下線を引きません。
- 相対パスは、それを出したプログラムの作業フォルダから見たものとして開きます。Linuxのローカルシェル（実行先で開いたシェルを含む）では、sshcエンジンがその作業フォルダを調べます。Claude Codeが動いているあいだは、Claude Code自身の作業フォルダです。
- SSHのセッションと、macOS・Windowsのローカルシェルでは、シェルがOSC 7で知らせたフォルダを使います。知らせていないときは開けず、その理由を表示します。フルパスなら、これまでどおり開けます。
- 相対パスのメニューは［プレビュー］と［リンクをコピー］だけです。SFTPで表示・編集・ダウンロードする操作は、フルパスに出します。
- プレビューの←→キーで移る画像にも、相対パスの画像が入ります。

## ワークスペース

- **セッションの行を、別のワークスペースの行か、その中のセッションの上へドラッグして移せるようにしました。** ワークスペースの行に落とすとその末尾に、セッションの上に落とすとそのセッションの前に入ります。閉じているワークスペースや、空のワークスペースにも落とせます。
- ドラッグしているあいだは、落とせるワークスペースの行を点線で、ポインタの下の行を実線で示します。
- タッチ操作ではドラッグできません。これまでどおり、セッションの［…］→［ワークスペースへ移動］で移せます。

## 更新後に必要な操作

- 実行先として使う接続先も、同じv0.53.1に更新してください。接続先では`sshc update`を実行します。相対パスの作業フォルダは、実行先で開いたシェルでは実行先のsshcエンジンが調べます。
