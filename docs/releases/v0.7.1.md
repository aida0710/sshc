# sshc v0.7.1

スマートフォンのheaderを簡潔にし、接続先や操作名へ使える幅を広げたリリースです。

## 修正

- スマートフォンでは、ローカルengineの常時session status badgeを表示しないようにしました。
- デスクトップでは、従来どおり状態点とsession statusを表示します。
- 起動状態とversionはscreen reader向けのlive regionへ残し、見た目から削除しても状態通知を失わないようにしました。

## 検証

- Goの全package testとrace detector、Android arm64 build、dead code検査を実行しました。
- Webのユニットテスト827件、TypeScript型検査、ESLint、production build、依存監査を実行しました。
- Playwright E2E 108件を実行し、360pxでbadgeが非表示、デスクトップでは表示されることを確認しました。
- 固定digestのOpenSSH／SeaweedFSコンテナで、SFTP、SSH接続、暗号化S3同期を確認しました。

## インストール

```sh
brew install aida0710/tap/sshc
```

または:

```sh
curl -fsSL https://raw.githubusercontent.com/aida0710/sshc/main/install.sh | sh
```

Android版は、このリリースの `sshc-android-v0.7.1.apk` をダウンロードして更新してください。
