# sshc v0.15.4

Workspace Command Centerの一括コマンドを、新しいSSH接続ではなく、Workspaceで現在開いているSSHセッションへ送るように修正しました。各paneの作業ディレクトリ、環境変数、shell stateを維持したまま操作できます。

## live sessionへの一括送信

- 接続済みSSH paneの実session IDを対象にし、同じaliasを開いた複数paneにもsessionごとに送信します。
- Focus Modeで一時的に隠れているpaneもWorkspace全体の対象に含めます。
- 出力はjob結果へ複製せず、それぞれのterminal paneへ表示します。結果画面はPTYへの配信成否だけを示します。
- 新しいSSH clientや非対話command runnerを起動しないため、現在のdirectory、environment、shell stateをそのまま使います。

## 誤送信と秘密情報の防止

- preview evidenceへcommand、session ID、alias、title、process generationを固定し、確認後に切断・再接続された別shellへの送信を拒否します。
- 接続済みSSH sessionだけを対象にし、local shell、接続中、再接続中、終了済みsessionをaliasから暗黙に開き直しません。
- commandとEnterを1つのexact input frameとして通常打鍵と直列化し、buffer不足時の部分送信やbyte interleaveを防ぎます。
- secret変数を含むSnippetは、TTY echo、scrollback、shell historyへ値が残り得るためlive terminalへの送信を拒否します。
- foregroundでshell以外のprogramが動いている場合は、そのprogramの標準入力へ届くことをpreview画面で説明します。
