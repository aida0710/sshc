# sshc v0.8.0

SSH切断後の再接続状態を見えるようにし、保存済みWorkspaceをHomeから直接開けるようにしたリリースです。

## 接続・再接続

- terminal session APIへ `connecting`、`connected`、`reconnecting`、`exited` の状態を追加しました。
- 再接続中は試行回数、上限、次回試行時刻、公開用の問題コードを表示します。
- 同時切断した接続が一斉に再試行しないよう、sessionごとに安定した±20%のjitterを加えました。
- 10秒以上安定して接続できた場合は再試行回数を戻し、短時間に切断を繰り返す接続だけを有限回で停止します。
- host key変更、認証取消、秘密鍵やpassphraseの不足など、利用者の操作が必要な失敗は自動で繰り返しません。
- terminal一覧を開いている間は接続状態を低頻度で更新し、古い応答が新しい状態を上書きしないようにしました。

## Workspace

- Homeへ保存済みWorkspaceの名前、pane数、更新時刻を表示しました。
- 「ワークスペースを開く」を押したときだけTerminalへ移動し、保存したlayoutの全paneへ接続します。Homeを表示しただけでは接続しません。
- 複数paneは並行して開き、一部が失敗しても成功したpaneを維持します。
- Homeへ戻って同じWorkspaceを再度開く操作も、毎回新しい要求として処理します。

## 検証

- Go unit/race、Android向けbuild、deadcode、Web unit 835件、TypeScript型検査、ESLint、production buildを実行しました。
- Playwright E2E 109件を実バイナリと隔離HOMEで実行しました。
- OpenSSH SFTP/SSHとS3互換serverをcontainerで起動し、実server統合テストを通しました。
- 日本語UIをデスクトップと360px幅で撮影し、Home、Workspace、保存済みWorkspaceカードに文字切れと横overflowがないことを確認しました。
