# sshc v0.70.1

v0.70.1では、v0.70.0に続いて、画面ごとに作りが違っていた部品をそろえました。画面や区画の上の端に出る帯、［…］などを押すと開くメニュー、名前の横の札、開閉の見出しが、どの画面でも同じ形になります。

あわせて、ドキュメントのサイトの画像を今の画面に撮り直し、設定と編集の保存の帯と、画面に出る知らせの説明を足しています。

## 画面や区画の上の帯

- ターミナルの上の帯、画面の上のエラーの帯、区画の知らせ、ファイルのプレビューの失敗の1行で、余白、字の大きさ、ボタンの置き方をそろえました。地の色は、これまでどおり帯ごとに違います。
- 区画の知らせ（接続先の作成を途中で離れたとき、Vaultを新しいバージョンに更新したときなど）は、字を14pxから12pxに、ボタンを小さいボタンに変更し、帯が10px低くなりました。スマホでは、文が「…」で切れなくなりました。
- 画面の上のエラーの帯は、これまで広い画面では中央に寄せていましたが、**左端から右端までの幅で表示するように変更しました。**
- スマホでボタンが2つ並ぶ帯は、これまでボタンの横の細い列で文を何行にも折り返していましたが、文に帯の幅を使い、ボタンを次の行へ送るように変更しました。

## メニュー

- ［…］などを押すと開くメニュー（セッションの行、ターミナルの［…］、SFTPのフォルダの［…］、［作成・アップロード］、選んだ項目の［…］、右クリック、転送の一覧の［…］）の枠と項目をそろえました。
- SFTPで選んだ項目の［…］のメニューは、これまで区画の右端に開いていましたが、**押した［…］のすぐ下に開くように変更しました。** フォルダの［…］のメニューはボタンの右端に、［作成・アップロード］のメニューはボタンの左端にそろえて開きます。
- メニューの幅を224pxにそろえました（これまでは192〜240px）。スイッチが並ぶターミナルの［…］のメニューは288pxです。日本語でいちばん長い項目（「この項目があるフォルダへ移動」）も1行に入ります。
- 右クリックのメニューは、押した点の下に入りきらないときは、点の上に開きます。
- スマホのSFTPの下から出るメニューは、これまでどおりです。

## 札と開閉の見出し

- 名前の横の短い札（クイック接続の最後に接続した日、Settingsのマシンの一覧の「このマシン」、ターミナルのプリセットの「このマシンで使用中」、ターミナルの見出しの「〇〇で実行中」、Syncの鍵の札）の高さを20px、字を12pxにそろえました。
- Settingsのマシンの一覧の「このマシン」の札は、選んだ行の地と同じ色で見分けにくかったため、灰色の地に変更しました。
- 「このマシンで使用中」の札の字をさし色に変更しました。「〇〇で実行中」の札は、等幅の字で表示するのをやめました。
- Syncの詳細、除外、設定の開閉の印は、これまで淡い色でしたが、ほかの開閉と同じく見出しと同じ色に変更しました。

## ドキュメント

- ドキュメントのサイトの画像を、今の画面で撮り直しました。
- 設定と編集の画面の説明に、画面の下の帯の［保存］でまとめて保存することを足しました。トラブルシューティングに、画面に出る知らせの見方の節を足しました。
