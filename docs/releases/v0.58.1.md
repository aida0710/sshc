# sshc v0.58.1

v0.58.1では、ターミナルを大きく改善しました。シェル統合（OSC 133）を使うシェルでは、コマンドと出力の左に結果の色の線が付き、線に乗せると終了コードやかかった時間が分かります。長い出力をさかのぼっている間はそのコマンドが上に残り、スクロールバーにもコマンドの位置が出ます。プロンプトの間の移動、合字、VT320のステータス行、色つきのコピー、スクロールバックの保存も追加しました。最近見たセッションは、戻ってもスクロールバックが残るようになりました。

あわせて、Connectionsの接続先の編集とグループの扱いを作り直し、実行先で使える機能を増やしました。点検で見つかった不具合と安全面の問題も直しています。古い形式の設定を読む処理を消したので、更新の前に「更新後に必要な操作」を確認してください。

## 更新後に必要な操作

- **v0.57.0でさし色に「カスタム」を選んでいた場合、更新後は既定の色に戻ります。** Settings → Appearanceで選び直してください。用意した色と選んだ色を1つの項目で保存する形に変えたためです。
- **Keyboard shortcutsで自分で作ったプリセットは、更新後に読み込まれずに消えます。** 新しい操作（前のプロンプトへ・次のプロンプトへ）の割り当てを持たないためです。必要なら作り直してください。いま使っているキーの割り当ては、新しい操作に既定のキーを足してそのまま使えます。
- **OSC 52（プログラムによるクリップボードへの書き込み）の許可を、接続先ごとの設定から、すべてのターミナルに効く1つの設定に変えました。** 接続先ごとに許可していた場合は、Settings → Terminalの「OSC 52のクリップボード書き込みを許可」をオンにしてください。ターミナルの「…」でも切り替えられます。
- 次の古い形式を読む処理を消しました。
  - v0.42.0より前のsshcが書いたmetadata.json（schema 9より前）は、読まずに断ります。
  - v0.40.0までの形（サーバー・相手の公開鍵・アドレスの項目）で保存したままのWireGuardのVPNプロファイルは、使えなくなります。設定ファイルでプロファイルを作り直してください。
  - v0.20.x以前が残した平文のスニペットの文書は、開かずに断ります。
  - ブラウザの登録の古い形式（版2）は読まず、登録なしから始めます。ブラウザでsshcを開けないときは、`sshc open`で入り直してください。
  - グループと接続先のメモ（画面に欄の無かったもの）は消しました。
- 実行先との互換の番号は変わっていないので、実行先（SSHの接続先で動くsshcエンジン）の更新は必須ではありません。ただし、実行先で開いたセッションのポート転送、パスのプレビュー、コマンドの時刻などの新しい機能は、実行先のsshcもv0.58.1へ更新すると使えます。

## ターミナル: シェル統合

- **コマンドと出力の左に、結果の色の線を出すようにしました。** 成功は薄い灰色、失敗は赤、実行中は黄色です。線に乗せる（スマホではタップする）と、終了コード、かかった時間、始めた時刻、フォルダと、［出力をコピー］［出力をファイルに保存］を出します。これまでは、コマンドの始まりの行の左端に小さな点を出すだけでした。
- **長い出力をさかのぼっている間、そのコマンドと結果をターミナルの上に表示するようにしました。** 押すとコマンドの行へ移ります。
- **スクロールバーに、履歴のどこにコマンドがあるかを結果の色で出すようにしました。** 遠くで失敗したコマンドも見つけやすくなります。あわせて、ターミナル内検索の一致の印もスクロールバーに出るようになりました（これまでは出ていませんでした）。
- 線・上の表示・スクロールバーの印は、Settings → Terminalの［操作］で1つずつオフにできます。始めた時刻とかかった時間はsshcエンジンが測るので、あとから開き直したセッションの履歴でも正しく出ます。
- **前・次のプロンプトへ移るショートカットを追加しました。** 既定はCtrl+Shift+↑／↓（Macは⌘↑／↓）で、Keyboard shortcutsで変えられます。スマホではターミナルの「…」から選べます。シェルがプロンプトを知らせていないときは、キーをそのままプログラムへ送ります。
- プロンプトで打っている行をクリック（スマホではタップ）すると、その位置へカーソルを動かすようにしました。
- **30秒以上かかったコマンドの終わりを、sshcエンジンが測って知らせるようにしました。** これまでは画面が測っていたため、別のワークスペースや分割表示の外のセッション、どのブラウザでも開いていないセッションのコマンドは知らせませんでした。失敗したときは「コマンドが95秒で失敗しました（終了コード2）。」のように分けて知らせます。

## ターミナル: 表示

- **Settings → Terminalの［操作］に「合字（リガチャ）を使う」を追加しました（既定はオフ）。** オンにすると、`->`、`!=`、`===`などを1つの記号のように表示します。字体がJetBrains Monoのときに効きます。合字も元の文字と同じマス数を使うので、カーソルや選択の位置はずれません。
- **プログラムがVT320のステータス行を出すと、ターミナルの下に1行で表示するようにしました。** これまでは、ステータス行へ書いた文字が本体の画面に出ていました。表示している間は、プログラムへ伝える行数が1つ減ります。「ステータス行を表示する」をオフにすると、表示せず、その出力も画面に出しません。
- 文字の幅をUnicode 17の表で数えるようにしました。これまでは、Unicode 13以降に足された絵文字（🥲、🫠など）を1マスと数え、後ろの文字が1マスずれていました。
- プログラムがmode 2027（書記素クラスタ）を有効にしている間は、ZWJでつないだ絵文字（👨‍👩‍👧）、国旗（🇯🇵）、肌の色を付けた絵文字（👍🏽）、VS16を付けた文字（❤️）を1つの文字として2マスに描くようにしました。有効にしていない間は、これまでどおり1文字ずつ数えます。
- プロンプトで画面を消したとき（bash・zshのCtrl+L）、消した出力をスクロールバックに残すようにしました。`clear`はこれまでどおりスクロールバックごと消します。
- Windowsのローカルシェルでは、mode 2027とステータス行は効きません。WindowsのConPTYが、これらの列を文字より先にまとめて送るためです。SSHで接続した先では効きます。

## ターミナル: コピーと貼り付け

- **ターミナルの「…」に［色つきでコピー］を追加しました。** 選んだ範囲を、色・太字・斜体・下線と背景の色を保ったHTMLと、文字の両方でコピーします。いつものコピーは文字だけのままです。
- **ターミナルの「…」に［スクロールバックをファイルに保存］を追加しました。** 画面を含むスクロールバック全体を、折り返した行をつないだテキストファイルにします。［直近のターミナル出力をコピー］は200行までです。
- Kitty clipboard protocol（OSC 5522）に対応しました。書き込みはOSC 52と同じ設定で許可したときだけ受け付けます。読み取りは断り、プログラムが貼り付けの知らせ（mode 5522）を求めているときだけ、貼り付けた中身を渡します。
- 画像だけ、または空のクリップボードを貼り付けたとき、何も起きずに終わらず、理由を知らせるようにしました。
- Macで、マウスを使うプログラム（Claude Code、vim、tmuxなど）の中でも、Optionを押しながらドラッグすれば文字を選べるようにしました。
- ターミナル内検索を閉じたら、ターミナルへフォーカスを戻すようにしました。最後の検索語を覚え、検索するたびにクリップボードが検索語に置き換わっていた不具合も直しました。

## ターミナル: セッション

- **最近見たセッションのターミナルを、表示から外れても裏に残すようにしました。** 戻ったとき、スクロールバックがそのまま残ります。これまでは戻るたびにsshcエンジンの再生バッファ（既定256 KiB）から作り直していたので、それより前の履歴が消えていました。残す数は既定で3つで、Settings → Terminalの［接続］で1〜99から選べます。
- **出力が画面の描画より速いときも、接続を切らずに続けるようにしました。** これまでは、`yes`のように出力が絶えないと接続が切れては張り直され、そのあいだ打ったCtrl+Cが届きませんでした。追いつけない分は飛ばし、そのことを画面に出します。
- 終了コードが0以外、シグナルで終わった、SSHの接続が切れた、のどれかで終わったセッションを赤で示すようにしました。接続が切れたときは、終了コード-1ではなく「SSHの接続が切れました」と出します。開いてすぐ（250 ms未満で）終わったセッションも、終了コードが0でも赤で示します。
- 接続をまとめて閉じる・sshcの更新・実行先の停止の確認に、終了するセッションの一覧を出すようにしました。
- 通知を出したセッションを表示したとき・閉じたときに、ブラウザとAndroidの通知を取り下げるようにしました。sshcのウィンドウにフォーカスが無いときも、未読の印・通知音・通知を出します。
- ターミナルの「…」に［画面を常にオン］を追加しました。オンのあいだ、Terminalを表示している間は画面を消しません。このブラウザだけの設定で、HTTPSか`localhost`で開いたときに使えます。
- タッチ操作の向きを自動で判定するようにし、オフにしたら「タッチ」か「マウス」に固定できるようにしました。2in1のPCで、マウスを付けたままタッチ向けの動きになり、ドラッグでの選択などが効かなかった場合に使います。ターミナルの「…」とSettings → Terminalの［操作］で選べます。
- セッションを開いたり読み込み直したりしたとき、再生した出力の中の問い合わせに答え直して、シェルに`62;4;9;22c`のような文字が入っていた不具合を直しました。
- ローカルシェルに`COLORTERM=truecolor`と`TERM_PROGRAM=sshc`を渡し、SSHの接続先には`COLORTERM=truecolor`を送るようにしました（接続先のsshdが受け入れる場合）。sshcエンジンを起動したターミナル（Ghosttyなど）が置いた変数は、ローカルシェルへ渡しません。
- 行単位で読むプログラム（`cat`、シェルの`read`など）で日本語を打ってBackspaceを押すと、1文字ではなく1バイトずつ消えていた不具合を直しました。
- Kitty keyboard protocolの問い合わせに答えるようにしました。問い合わせてから有効にするプログラム（fish、Neovim、Helixなど）でも使えます。
- SGR形式を使わずにマウスを有効にしたプログラムへ、クリックとホイールが届かなかった不具合を直しました。
- ファイルのパスを押したら、メニューを挟まずにそのままプレビューを開くようにしました。［SFTPで表示］などの操作は、プレビューの見出しの「…」に移しました。Claude Codeが出す形のパスも拾えるようにしました。
- スマホで、Claude Codeやless・vimのような全画面のプログラムを指でスクロールできるようにしました。

## 分割表示

- ペインの取っ手を相手のペインの端へ落とすと、その側へ移すようにしました。中央へ落とすと、これまでどおり入れ替えます。Split viewsのセッションの行もつかんで動かせます。
- ターミナルとセッションの行の「…」に［分割表示から外す］を追加しました。
- 入れ子の分割でも、ペインを見出しと1行・見出しのボタンが収まる大きさより小さくしないようにしました。
- ペインの見出しをクリックしたら、そのペインに入力が入るようにしました。サイドバーでは、入力先のセッションの行に枠を付けます。

## Connections

- **Groupsのページをなくし、グループの操作をConnectionsにまとめました。** グループを選ぶと、そのフォルダ（`connections/<グループ>/`、`keys/<グループ>/`）の中身とIncludeの行を出します。表示順の変更とConnectionsで隠す操作はグループの「…」に、フォルダの食い違いの確認はグループの一覧の上に移しました。
- **接続先の編集を「基本」「踏み台・転送・その他」「表示とターミナル」「最終的な値」の4つのタブにしました。** どのタブも1画面に収まります。基本のタブでは、ホスト名・ユーザー・ポートを1行に並べました。継承した値と既定値は、入力欄の見本の文字で見せます。
- **新しい接続を、モーダルではなくConnectionsの右の欄で開くようにしました。** 一覧やグループを見ながら入力できます。
- スマホで接続先を開いたら、上のバーに一覧へ戻る‹と［接続］・「…」を出すようにしました。
- 日本語の画面で、保存した項目を「接続先」、aliasを「接続名」と呼ぶようにそろえました。

## 実行先

- 実行先で開いたセッションでも、クイックコマンド、一括送信、ポート転送（ローカル・ダイナミック・リモート）を使えるようにしました。
- 実行先で開いたSSHのセッションも、このマシンの同じ接続名と行き先が同じなら、パスのプレビューと［SFTPで表示］を使えるようにしました。
- 選んでいない実行先のセッションに通知があると、実行先の切り替えに未読の印を付けるようにしました。
- 実行先を選んでいるとき、新しいセッションに実行先のシェルを出すようにしました。これまでは、このマシンのシェルの一覧を出していました。
- 実行先がすぐに起動し直したときも、開き直すかを聞くようにしました。開き直したセッションを二重に記録していた不具合も直しました。

## スマホ・Android・Windows

- Androidで、システムがライトのとき、起動の失敗などのネイティブの画面が白地に白い文字になっていた不具合を直しました。最近のタスクから払って閉じても、開き直しの記録を書き終えるようにしました。
- Windowsで、PCの終了やサインアウトのときに、裏で動くsshcエンジンが止まり方の手順を通り、開き直しの記録を書くようにしました。
- スマホで、知らせが下のタブに重ならないようにしました。キーボードを閉じているとき、キーバーのCtrlや矢印でキーボードが開かないようにしました。上のバーに出す見出しのボタンを高さ30pxにしました。
- Windows PowerShell 5.1に付属のPSReadLine 2.0で、幅を変えたあとに入力の行がずれることと、PowerShell 7を入れるかPSReadLineを更新する手順を説明書に書きました。

## 安全面の修正

- 出力が報告したUNCの形のフォルダ（`//ホスト/共有`、`\\ホスト\共有`）を、セッションを開くときの作業フォルダに使わないようにしました。Windowsでその相手へ接続し、資格を渡すおそれがありました。fish・PowerShell・cmd.exeで、出力が報告したフォルダ名の`cd`の引用が途中で終わりうる問題も直しました。
- 出力の中のUTF-8のC1制御文字を無視するようにしました。xtermとGhosttyと同じ扱いです。貼り付けの確認の対象にも加え、bracketed pasteの中のESCを無害にしました。
- SFTPのフォルダの一覧で、受け取る応答の合計を64 MiBまでにしました。悪意のあるサーバーが長い名前を返し続けると、sshcエンジンのメモリを使い果たせました。
- kittyの画像形式で、置き直しのたびの解読の量と、送るだけの画像の保存量に上限を置きました。断ったときは、プログラムへ理由を返します。
- 実行先への接続と資格の受け取りが答えないとき、いつまでも待ち続けていた不具合を直しました。別のページが置いたcookieや、実行先の画面のサインアウトで、このマシンの画面に入れなくなる問題も直しました。
- OSC 8のリンクの前に日本語があると、表示の文字と行き先の照合がずれ、行き先を見せずに開くことがあった不具合を直しました。

- Keyboard shortcuts、Sync、SSH Keysの結果を、ほかのページと同じ形にしました。知らせの操作ボタンを、文の横ではなく文の下に置くようにしました。
- 説明書に、sshcのターミナルが受け取るエスケープシーケンスの一覧のページを追加しました。説明書とREADMEの画面写真を、今の画面で撮り直しました。
