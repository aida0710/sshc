# sshc v0.33.0

v0.33.0では、Vaultをパスワードなしで使えるようにし、アプリのキーコンフィグとライセンス一覧を追加しました。接続先のOSアイコンや、Terminal・SFTPの操作も改善しています。

## Vaultの保護方式

- 初回作成時とSettings → Master passwordで、パスワードあり／なしを選べます。パスワードは4文字以上とし、数字だけでも設定できます。
- パスワードなしでは端末内にランダムな鍵を保存し、既存の暗号化形式を維持します。engine起動時に自動解錠し、自動ロックは適用しません。端末鍵と暗号文の両方を読める相手への保護はありません。
- 同期データは独立した同期キーで暗号化します。同期キーの最低12文字という条件は維持し、端末の解錠鍵は同期しません。
- CLIでも`sshc vault create`と`sshc vault change-password`で、新しいパスワードと確認入力を空欄のままEnterを押すとパスワードレスにできます。実行時に英語の案内を表示します。既存Vaultの変更では現在のパスワードが必要で、ロック中は先に`sshc vault unlock`を実行します。
- 保護方式の変更ではVault、同期設定、Snippet、既存バックアップをまとめて再暗号化し、中断時は起動時に復旧します。

## キーコンフィグ

- Settings → Shortcutsで、コマンドパレット、Terminal検索、コピー、貼り付け、前後の接続への切り替え、Home、SFTPの8操作を設定できます。
- 貼り付けの初期設定はCtrl+V／⌘VとCtrl+Shift+Vです。設定はブラウザーに保存します。
- Ctrl+F／⌘FはTerminal画面でアプリが処理し、それ以外の画面ではブラウザー標準の検索を使えます。

## 接続とTerminal・SFTP

- HomeとConnectionsに小さな単色のOSアイコンを表示します。接続後に取得するOS情報と手動指定に対応し、Amazon Linux、Ubuntu、Debian、Fedoraなどを判定できます。
- 貼り付け確認モーダル内で、送信前に内容を編集できます。
- 接続を閉じる確認ではキャンセル側に初期フォーカスを置き、キーボードで操作できます。
- HomeやSFTPへ移動した際の接続選択表示と、接続一覧のボタン周辺のクリック範囲を修正しました。
- SFTPの転送マネージャーは、折りたたみ時のヘッダー全体をクリックして展開できます。

## ライセンスと依存関係

- Menu末尾のOthers → Licenseに、同梱する68コンポーネントの一覧を追加しました。上部で検索し、各行を開いてライセンス全文・NOTICE・出典を確認できます。オフラインでも閲覧できます。
- Vitest／@vitest/mockerを4.1.11、js-yamlを4.3.2へ更新しました。

## 移行確認

v0.32.0のコードで作成したテスト用Vaultを同版の公開バイナリで開き、今回のバイナリで「パスワードなしへ変更 → engine終了・再起動 → 4文字のパスワードへ戻す → 再起動・解錠」を確認しました。各段階で、秘密鍵の復号、資格情報と割り当て、Snippet、同期キーを含む同期設定が保持されることを確認しています。
