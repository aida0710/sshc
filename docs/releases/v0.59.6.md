# sshc v0.59.6

v0.59.6では、設定をどのページでも変えたらすぐ保存するようにし、キーボードショートカットに割り当てられる操作を増やしました。テーマは、ダークとライトの灰色から青みをなくし、ダークブルー、ダークパープル、ホワイトブルー、ホワイトパープルを足して7つにしました。

あわせて、スマホの横向きとタブレットの縦向きの画面の組み方、広い画面の一覧、スマホのファイルのプレビューとSFTPの一覧、ターミナルのリンクの下線を改善しています。更新のあとにsshcエンジンが起動しないままになる不具合と、古い設定のファイルがあるWindowsでsshcエンジンが起動しない不具合も直しました。

## 設定

- **どのページも、変えたらすぐ保存するようにしました。** これまでは、Appearance・Notifications・SFTPは変えるとすぐ保存し、TerminalとVaultの自動ロックは下の［保存］を押すまで保存しませんでした。選ぶ欄はその場で、数や開始ディレクトリを打つ欄は、欄を離れたときかEnterを押したときに保存します。打っている途中の値は保存しません。
- 保存したことは、変えた欄の下に「保存しました」と2秒だけ出します。マシンの一覧など、欄の外で変えたものは、ページの名前の横に出します。
- SFTPの除外指定は［除外指定を保存］をやめ、欄を離れたときに、すべての行が正しければ保存するようにしました。
- Vaultの自動ロックで「自動ロックしない」から「操作がない場合にロック」に戻すと、その場で既定の12時間で保存するようにしました。これまでは［保存］を押すまで保存しませんでした。

## テーマ

- **ダークとライトの灰色を、青みのない色にしました。** これまでは地や線の灰色が青に寄っていました。明るさは変えていません。ダークでは、ターミナルの地も青みのない黒になります。
- これまでのダークの色は「ダークブルー」として残しました。前の見た目に戻したいときは、Settings → Appearanceで「ダークブルー」を選んでください。
- 「ダークパープル」を足しました。地をダークより一段明るくし、既定のさし色（薄紫）とターミナルの選択・カーソルを紫にします。
- 「ホワイトブルー」と「ホワイトパープル」を足しました。地と線を、それぞれ青と紫に寄せます。ホワイトパープルでは、既定のさし色を少し濃い紫にします。
- テーマの見本は、ライトの行とダークの行に分けて並べるようにしました。

## キーボードショートカット

- **割り当てられる操作に、「文字を大きく」「文字を小さく」「文字の大きさを戻す」「クイックコマンドを開く」「新しいセッション」「セッションを閉じる」「次のペイン」「前のペイン」「ナビゲーションを開閉」を足しました。**
- 文字の大きさの3つには、既定のキー（Ctrl+=、Ctrl+-、Ctrl+0。macOSでは⌘）があります。JISキーボードでは、Ctrl+;でも大きくなります。変えた大きさは、ピンチと同じくそのターミナルだけに効き、保存しません。
- ほかの操作には、既定のキーがありません。ほかのターミナルが使うキー（Ctrl+Shift+Tなど）は、ブラウザやターミナルの中のプログラムが先に使うためです。
- 「新しいセッション」はサイドバーの［新しいセッション］と同じ画面を開き、「セッションを閉じる」はセッションの行の×と同じ確認を出します。
- PCで「ナビゲーションを開閉」を使ってナビゲーションを隠すと、左に細い列と［ナビゲーションを開く］のボタンだけが残ります。隠したかどうかはブラウザに保存するので、ページを読み込み直しても隠したままです。スマホでは引き出しを開閉します。
- **作ったショートカットのプリセットを、操作が増えても残すようにしました。** これまでは、操作を足したバージョンに更新すると、足す前に作ったプリセットを読み込まずに捨て、標準のショートカットに戻していました。プリセットに無い操作は、キーの無い状態で読み込みます。

## 画面の組み方

- **スマホを横にしたとき（幅600px以上・高さ480px未満）、下のバーを左の縦のレールに移しました。** これまでは上下の帯で高さを使い、SFTPの中身が約120pxしか残りませんでした。SFTPの転送マネージャーの行も、転送が無いあいだは出しません。
- **タブレットを縦にしたとき（タッチで操作する、幅600〜1023px・高さ480px以上の画面）、ナビゲーションを左に出したままにしました。** これまではスマホの形のまま横に伸び、セッションの一覧は引き出しの中にしかありませんでした。
- 広い画面のHomeで、カードを幅330pxごとに並べ、画面が広いほど列を増やすようにしました。Settingsのページの一覧は、左のサイドバーの隣に寄せました。
- ConnectionsとSnippetsで、何も開いていないあいだは一覧に全幅を渡し、列で並べるようにしました。Connectionsは名前・宛先・グループ・最終接続、Snippetsは名前・コマンドの1行目・説明の列です。これまでは右側に「接続先を選択」だけが出て大きく空き、一覧の名前が切れていました。開くと、これまでどおり2列になります。
- 幅640px未満のKnown Hostsで、1件を2行の行にしました。行を押すと、ホストとフィンガープリントの全文が出ます。削除は行の「…」から行います。これまでは1件が4行のカードでした。
- SSH Keysの鍵を作る欄は、見出しの［鍵を作成］を押したときだけ開くようにしました。これまではページの下に常にあり、鍵を作る場所が2つありました。幅640px未満では、検索欄を虫眼鏡のボタンに畳みます。

## SFTPとファイルのプレビュー

- **スマホでは、ファイルのプレビューを画面いっぱいに出すようにしました。** 画像と動画は黒い地の中央に置き、パスと操作の帯を上に重ねます。SFTPの詳細も、スマホでは全画面にしました。
- 画像と動画には［ファイルを編集］を出さないようにしました。PCでも同じです。
- スマホのSFTPの一覧で、行の2行目を「大きさ · 更新日時」にしました。権限と所有者は詳細で見られます。
- 拡張子からファイルを画像・動画・音声・圧縮ファイル・テキストに分け、アイコンと種類の列に出すようにしました。画像と動画のアイコンには色を付けます。
- PCの表では、名前の列だけを伸ばし、ほかの列は中身の幅にしました。

## ターミナル

- **タッチで操作するとき、タップで開けるURLとパスのすべてに、いつもさし色の下線を引くようにしました。** これまでは下線が無く、開けるかどうかが見た目で分かりませんでした。Settings → Terminalの「タッチ操作」にある［リンクにいつも下線を引く］をオフにすると消えます。プリセットに入るので、スマホが使うプリセットでだけ消すこともできます。
- マウスで操作するときは、マウスを乗せたリンクにだけ、同じさし色の線を引くようにしました。これまでは文字と同じ色の細い線でした。

## sshcエンジンとCLI

- **更新のあと、sshcエンジンが起動しないままになる不具合を直しました。** 起動の失敗が続くと、WindowsのタスクスケジューラとLinuxのsystemdは、sshcエンジンを起動し直すのをやめます。これまでは、そのあとに更新しても止まったままで、`sshc service install`をやり直す必要がありました。これからは、更新のときに止まっていたsshcエンジンを起動し直します。`sshc stop`で止めたsshcエンジンは、これまでどおり起動しません。
  - Windowsでは、v0.59.6へ更新するときから効きます。
  - Linuxでは、更新を実行する古いsshcが起動し直すので、v0.59.6から次のバージョンへ更新するときから効きます。
  - macOSは、これまでも止まったままにはならないので、変えていません。
- **以前のsshcが管理者の権限で作った`~/.ssh/sshc/engine-settings.json`があるWindowsで、v0.59のsshcエンジンが起動しなかった不具合を直しました。** タスクスケジューラから起動したsshcエンジンがこのファイルを読めず、止まっていました。これからは、v0.58.1までと同じく、読めないファイルは無いものとして扱い、マシンごとの決まったポートを使います。このファイルで変えていたポートは移らないので、必要ならSettings → Machinesで設定し直してください。
- 中断した変更が残っているときに`sshc ssh`などが出す文を、Historyで片付けるよう案内する文にしました。これまでは、別のsshcが更新中と読める文（`another sshc process is updating this workspace`）で止まり、待っても消えませんでした。
