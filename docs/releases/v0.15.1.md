# sshc v0.15.1

vault の形式が現在の sshc と一致しないとき、単なる「開けませんでした」ではなく、古い形式か新しい形式かと双方の schema バージョンを表示するようにしました。

## vault の版差を明示

- 古い vault では「必要なバージョン: 4、現在: 3」のように、必要な版と検出した版を表示します。
- この sshc より新しい vault は別のエラーとして表示し、古い形式と取り違えません。
- 暗号化 envelope 自体の非対応も schema の版差と分け、診断コードと安全な詳細を表示します。

## 復旧

- ローカルの世代履歴から、現在の sshc で開ける最新の vault バックアップを復元できます。
- 互換バックアップがない場合は、確認チェック後に空の現行 vault を作成できます。保存済みパスワード、鍵パスフレーズ、同期設定は初期化されますが、SSH 設定と鍵ファイルは残します。
- 初期化前の vault と同期設定は暗号化された世代バックアップへ保持します。
- 通常の現行 vault に復旧 API を使って置き換えることはできません。

## 検証

- 古い形式・新しい形式の判定、版番号を含む API 応答、互換バックアップ復元、安全な初期化を Go テストで確認しました。
- React unit test と Chromium E2E で、エラー表示と復旧操作を確認しました。
- 360×800 の日本語画面で、版番号と操作が横にはみ出さないことをスクリーンショットで確認しました。
