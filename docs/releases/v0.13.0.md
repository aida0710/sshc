# sshc v0.13.0

同期、SFTP転送、ローカルファイル操作、Android配布経路を横断して、データ破損と秘密情報の漏えいにつながる境界条件を修正しました。

## 変更内容

- 同期previewをリモートのETagとrevisionへ束縛し、確認後に別世代へ変わった内容を適用しないようにしました。
- 同期済みのlive objectが削除された場合を検知し、自動送信による意図しない再作成を停止します。
- 読めない履歴は個別にスキップし、同じ壊れた世代のdownloadと鍵導出を毎分繰り返さないようにしました。
- 同期鍵の置換をremote CAS、local state、vaultの順に確定し、途中失敗時は可能な限り元の世代へ戻します。
- 同期鍵の置換とmaster password変更へ復旧journalとcommit markerを追加し、応答喪失、rename失敗、directory sync失敗、process停止後も旧世代か新世代のどちらかへ収束します。
- SFTPのupload／downloadをserver jobへ束縛し、接続断後の再開、content revision検査、atomic rename、進捗の整合性を強化しました。
- 大量downloadはブラウザーのメモリーへ全量保持せず、OPFSとengine側の上限付きspoolを使います。folder archiveにも容量、file数、深さの上限を追加しました。
- SFTP queueを最大200件、同時転送を設定値以内に制限し、pause、resume、retry、cancel後のremote partと一時fileを回収します。
- workspace配下のread／write／rename／removeをdirectory handle相対にし、検査直後のsymlink／reparse point差し替えによる範囲逸脱を防ぎました。
- workspaceの全更新をprocess横断lockで直列化し、複数engineやCLIによるknown_hosts、鍵、設定のlost updateを防ぎました。
- CSRF tokenをlocalhostのportごとに保持し、更新にも発行済みtokenを必須化しました。複数tabは最大8個の有効tokenを共有し、別portのCookieだけではsessionへ昇格できません。
- 保存済みpasswordを解決済みの認証先へ束縛し、aliasのHostName、Port、User、ProxyJump変更後に別serverへ自動送信しないようにしました。ProxyJumpの全hopでknown_hostsを必須化しました。
- Androidのbackupとdevice transferからSSH鍵とprivate stateを除外し、foreground service timeout時にengineを停止します。
- Gradle、NDK、APK署名者、GitHub host keyを固定し、tagと同一commitのCI成功、成果物attestation、Homebrew更新をrelease条件にしました。
- 残っていた旧schema読込、旧SFTP API、旧queue移行、重複した永続化処理と未使用の生成型を削除しました。
- serverとWebのwire型をOpenAPI契約へ照合し、生成済みGo型の未到達コードを削除しました。

## 検証

- Goの通常test、race test、vet、dead-code検査、7 fuzz targetを通過しました。
- Webの871 test、TypeScript、lint、i18n、production buildとPlaywright 112 testを通過しました。
- 固定digestのOpenSSH／SeaweedFS containerでSSH、SFTP再開転送、S3 conditional writeを検証しました。
- 実R2の隔離prefixでobject storeとremote syncを検証し、試験objectが0件であることを確認しました。既存のlive objectと履歴は変更していません。
- Linux、Windows amd64、Darwin arm64、Android向けGo buildを確認しました。Android APK buildとWindows固有testはCIで実機相当環境を確認します。

## 互換性

このリリースは現行形式だけを扱います。旧vault、metadata、SFTP queueなどの移行分岐は削除しました。必要な端末は同じバージョンへ揃えてください。
