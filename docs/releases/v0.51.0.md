# sshc v0.51.0

v0.51.0では、SFTPでSSHの接続を待つあいだに、ターミナルと同じく接続の段階と接続ログを表示するようにしました。

あわせて、［+］で接続先を選んでからタブを開くようにし、［比較］をSFTPの画面の上の帯へ移しています。

## SFTPの接続中の表示

- これまでは、SFTPのタブが接続し終わるまで「〜に接続しています…」とだけ表示していました。**ターミナルと同じく、「bastionへ接続中 · 1/1」「bastionで認証中 · 1/1」のように今の段階を表示するようにしました。** 1/1は、ProxyJumpの経由ホストを含めて何番目のホストに接続しているかを表します。
- Settingsの［Terminal］にある「接続のログ」を「表示しない」以外にしている場合は、その深さの接続ログを一覧の場所に表示します。ターミナルで接続するときに表示される行と同じです。
- これまでは、接続に失敗すると「接続できませんでした。」とだけ表示していました。**接続ログを残したまま、最後の行に失敗の理由（例: `this host is not in known_hosts`）を表示するようにしました。** 理由は「接続のログ」の設定に関わらず表示します。
- 接続できたら、接続ログを閉じて一覧を表示します。すでに接続しているホストで一覧を読み直すときは、何も表示しません。

## SFTPのタブと比較

- これまでは、［+］を押すと接続先の無い空のタブができ、タブの▾から接続先を選んでいました。**［+］を押すと接続先の選択画面を開き、選んだ接続先で新しいタブを開いてすぐ接続するようにしました。** 選ばずに閉じた場合、タブは増えません。
- 接続先をまだ選んでいないタブ（SFTPを初めて開いたときなど）の一覧に、［接続先を選択］を表示するようにしました。
- これまで［比較］は、2ペインのときだけ右のペインのタブの並びの右端にありました。**HomeやConnectionsと同じく、SFTPの画面の上の帯の右端に置くようにしました。**
  - 2ペインで左右のタブのどちらにも接続先があるときは、これまでどおり左右で選択しているタブのディレクトリを比較します。
  - 1ペインのとき、または片方に接続先が無いときは、比較する2つのタブを選んでから比較します。これまで1ペインでは比較できませんでした。
  - 接続先のあるタブが2つ以上になるまでは押せません。
  - スマートフォンでは、これまでどおりタブの並びの右端に表示します。
- ［+］で開いたタブを、接続し終わる前に別のペインへドラッグすると、［接続］を押すまで接続しない状態に戻っていた問題を修正しました。
