# sshc v0.16.5

ターミナルの「閉じる」を、SSHとローカルシェルで共通の確実な強制終了操作へ整理した更新です。

## 変更

- 実行中のターミナルで「閉じる」を確認すると、SSH／ローカルを区別せず強制停止します。
- 一度の操作とAPI要求でターミナルを一覧から削除し、SIGHUP待ちや二度目の削除操作を不要にしました。
- 明示的に閉じたターミナルは自動再接続せず、接続中のstreamも同時に終了します。
- 自然終了または接続失敗したターミナルは、原因と最後の出力を確認できるよう従来どおり保持します。
- 強制停止自体に失敗した場合は、存在しないターミナルとして扱わず専用のサーバーエラーを返します。
- 実プロセスを使うブラウザテストで、確認1回・DELETE 1回だけで一覧から消えることを検査します。

**変更履歴**: [v0.16.4...v0.16.5](https://github.com/aida0710/sshc/compare/v0.16.4...v0.16.5)
