# sshc v0.5.7

Homeから最近使った接続先へ戻れるようにしたリリースです。

## 追加

- SSH接続とstream ticketの発行が成功した接続先を、端末ごとに最大20件記録します。
- HomeのQuick connect直下に最近使った接続先を最大5件表示し、その場から再接続できます。
- 表示するhostname、user、portは現在のOpenSSH設定から解決します。設定を変更した後に古い接続先を表示しません。

## 安全性

- 履歴にはHost aliasと最終接続時刻だけを保存します。hostname、user、port、資格情報は保存しません。
- 認証、host key確認、stream ticket発行の途中で失敗した接続は履歴に残しません。
- 最近使った接続先は端末固有の操作状態として扱い、S3互換バックアップの対象から除外します。

## 検証

- Goの通常テストとrace detector、Android arm64 build、dead code検査を実行しました。
- Webのユニットテスト793件、TypeScript型検査、ESLintを実行しました。
- Playwright E2E 106件を実行し、360px幅で最近使った接続先とConnect操作が画面内に収まることを確認しました。

## インストール

```sh
brew install aida0710/tap/sshc
```

```sh

```
