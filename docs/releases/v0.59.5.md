# sshc v0.59.5

v0.59.5では、中断した変更を片付ける前に、その中身をファイルごとに変更前と変更後で比べられるようにしました。

## History

- **［History］の「中断した変更」に［変更を見る］を追加しました。** これまでは、中断した変更がどのファイルを書く途中だったかの名前しか分からず、中身を確かめないまま［取り消す］か［完了させる］を選ぶしかありませんでした。［変更を見る］を押すと、左にファイルの一覧、右に変更前と変更後を並べた画面が開きます。変更前は赤、変更後は緑で示します。
- 一覧には、ファイルごとに書き込み済みかまだか、新しいファイルか消すファイルかが出ます。比べたあとは、同じ画面から、すべてのファイルを変更前に戻す［取り消す］か、変更後にそろえる［完了させる］を選べます。ファイルごとに選ぶことはできません。
- 秘密鍵、Vaultのファイル、sshcが内部で使うファイルは、中身を出さず、変わることだけを示します。文字でないファイルと、1MiBを超えるファイルも中身を出しません。書き込み済みのファイルの変更前の中身はVaultの鍵で暗号化してあるので、マスターパスワードのあるVaultがロックされているあいだは比べられません。
- 「中断した変更」の開始の時刻を、日時の形で表示するようにしました。これまでは記録の形式（例: 2026-10-30T13:12:05Z）のまま出ていました。
