# sshc v0.65.1

v0.65.1では、スマホ版（Androidのアプリ）のターミナルで、これ以上スクロールできないときに画面を引っ張れる動きをやめました。

## ターミナル

- v0.65.0では、指でスクロールしていちばん新しい行や古い行より先へ引くと、画面が少しだけ動き、離すと戻っていました。払った勢いで端に着いたときも、端の先へ出てから戻っていました。**v0.64.0と同じく、端でぴたりと止まる**ように戻しました。
- v0.65.0で直した、払う操作をタップと見なしてキーボードを開いていた不具合は、直したままです。ファイルのプレビューの動きも変わりません。
