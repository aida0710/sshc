# sshc v0.44.0

v0.44.0では、SFTPのファイル操作と転送を拡充しました。ローカル側の削除・名前変更・フォルダ作成に加え、複数選択の一括権限変更、転送速度の上限、通信断からの自動復旧、内容検索、SHA-256による内容比較を追加しています。

あわせて、Web画面からの自己更新と`sshc service restart`を追加しました。WebログインやVaultのロック解除後にターミナルの高さが合わなくなる問題と、上下左右の余白が黒い枠に見える問題も修正しています。

## SFTPのファイル操作

- ローカル側で、ファイル・フォルダの削除、名前変更、フォルダ作成ができるようになりました。削除はローカル・リモートとも三点メニューにまとめ、**削除前の確認モーダルを必須**にしました。
- リモート側でシンボリックリンクの作成・リンク先変更、所有者・グループの変更を追加しました。所有者とグループは数値のUID・GIDで指定し、リンク先の所有者は変更しません。
- 接続先のディスク空き容量を表示できるようになりました。接続先が必要なSFTP拡張に対応していない場合は、未対応と表示します。
- 複数選択したリモート項目の権限を、ファイルとフォルダで別々に指定できるようになりました。再帰的な変更では対象数と省略するリンクを確認してから適用し、途中で変更された対象には適用しません。
- 権限変更には、接続先の`lsetstat@openssh.com`拡張への対応が必要です。リンク先を誤って変更する方法へ切り替えず、未対応の接続先では操作を断ります。

## 転送速度と通信断からの復旧

- 転送マネージャーに「速度上限」を追加しました。単位はKiB/sで、すべての転送を合算して制御し、既定の`0`は無制限です。
- 速度上限には、転送再開のためにリモートファイルを照合する通信と、準備済みファイルのブラウザへの配信も含みます。順次アップロードではブラウザからengineへの受信を制限せず、SFTP側への書き込みを制限します。
- **「通信断後に自動復旧」を有効にすると、最大3回まで再接続を試みます。** 既定では無効で、認証・ホスト鍵・権限の問題やファイルの競合は自動で再試行しません。
- engine側の単一ファイル転送は、転送元・転送先と保存済みの部分を照合してから続きを転送します。完了したか判断できない場合は停止し、転送先を確認するよう案内します。
- ブラウザのアップロードを自動復旧するには、ファイルを選択したページが開いていて、engineと通信できる必要があります。ZIPやダウンロード準備中の再試行は先頭から行い、engine側のフォルダ転送・移動・削除とCLI自身の転送は自動復旧の対象外です。
- `sshc sftp settings --speed-limit 2048 --reconnect-attempts 3`でも共通設定を変更できます。速度はKiB/s、再接続回数は`0〜10`で指定し、`--speed-limit 0 --reconnect-attempts 0`で無制限・自動復旧無効に戻します。

## 内容検索とフォルダの比較

- リモート側の検索対象に「内容」を追加しました。複数のUTF-8テキストファイルを、大文字・小文字を区別する固定文字列で検索し、一致した行をエディタで開けます。
- 内容検索は1ファイル2MiB、合計64MiB、最大200一致行まで行います。リンク・バイナリ・読めないファイル・上限に達したファイルは、理由を表示して省略します。
- ローカル同士、ローカルとリモート、リモート同士のフォルダを比較できるようになりました。既定ではサイズや更新日時などを比較し、「内容（SHA256）」を選ぶと、サイズと更新日時が同じでも内容の違いを検出します。
- 内容比較で読み込む量は両側合計256MiBまでです。読めない項目や上限で比較できなかった項目を一致と扱わず、ローカルを含む比較ではファイルを変更しません。

## Web画面からの自己更新とサービスの再起動

- macOS・Linuxの`install.sh`版では、新しい安定版があるとWeb画面から更新できるようになりました。確認したバージョンへ更新し、engineを再起動して、更新結果を画面に表示します。
- Web更新は、導入記録と実行ファイルが一致し、インストール先に書き込める場合に限ります。Homebrew版は`sshc update`を使用し、Windows・Android・手動配置・開発ビルドでは表示された更新方法に従ってください。
- Linux・macOSに`sshc service restart`を追加しました。`sshc service install`で管理する稼働中のユーザーサービスについて、定義と実行ファイルを確認してから再起動します。
- 更新や再起動で、接続中のセッションと転送は終了します。パスワード付きVaultは再びロックされるため、再起動後にロックを解除してください。

## ターミナルと安全性の修正

- WebログインやVaultのロック解除後に、フォントの読み込みや非表示時の寸法が影響して、ターミナルの高さが合わなくなる問題を修正しました。表示時にフォントとセルの寸法を確認して、ターミナルのサイズを合わせます。
- ターミナルの上下左右に黒い帯が見える問題を修正しました。余白の背景を選択したテーマの背景色に合わせ、背景画像にも対応しています。
- ローカル操作でアクセス権が不足した場合の案内を、接続先のエラーと分けました。macOSでは権限を確認する設定の場所も案内します。
- SFTP操作中のパスやリンクの差し替え、Web更新の確認後に条件が変わる場合の検証を強化しました。サイズ・種類・更新日時を取得できないリモートファイルは、空ファイルとみなさず内容照合や自動復旧を断ります。
- `golang.org/x/mod`と`source-map-js`を更新し、依存ライブラリの脆弱性を修正しました。
