# sshc v0.5.4

Androidでリモート同期画面を初めて開いたときの表示不具合を修正したリリースです。

## 修正

- 自動同期がまだ一度も動いていない端末で、同期状態の初期値が空にならないよう修正しました。
- 新規インストール直後のAndroidでも、リモート同期の未設定画面を正常に表示できるようにしました。
- Androidと同じ起動順序で同期APIを検証する回帰テストを追加しました。

## インストール

```sh
brew install aida0710/tap/sshc
```

または:

```sh
curl -fsSL https://raw.githubusercontent.com/aida0710/sshc/main/install.sh | sh
```

Android版は、このリリースの `sshc-android-v0.5.4.apk` をダウンロードして更新してください。
