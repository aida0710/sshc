# sshc v0.68.0

v0.68.0では、ワークスペースの中のセッションの並びを、どのブラウザやマシンから開いても同じにしました。並べ替えた順はsshcエンジンが持つので、ページを読み込み直しても変わりません。

あわせて、［ワークスペースへ移動］で移したセッションが入る位置と、一覧に残す終了したセッションの選び方を直しています。

## 更新後に必要な操作

- **リモートセッションを使っている場合は、接続先のsshcもv0.68.0へ更新してください。** 接続先で`sshc update`を実行します。リモートセッションのやり取りの互換の番号を上げたので、このマシンと接続先の片方だけがv0.68.0だと、その組み合わせはリモートセッションとして使えません。
- 接続先がv0.67.0以前のままのときは、リモートセッションのターミナルの領域に両方のバージョンが表示されます。その場の更新のボタンで接続先を更新することもできます。更新すると、接続先で動いているセッションはすべて終了します。

## セッションの並び

- これまでは、ワークスペースの中で並べ替えた順を、そのブラウザのタブだけが覚えていました。そのため、別のブラウザやマシンでは開いた順のままで、同じブラウザでもページを読み込み直すと開いた順に戻っていました。**並べ替えた順をsshcエンジンが持つように変更しました。** どのブラウザやマシンから開いても同じ順に並びます。リモートセッションを別のマシンから開いた場合も同じです。
- ほかの画面で並べ替えると、開いている画面にも数秒のうちに同じ順で表示されます。
- sshcエンジンが止まる処理を通ったあと、セッションを開き直したときも同じ順で戻ります。
- 並べ替えの操作は変わりません。セッションの行をドラッグするか、セッションの［…］→［上へ移動］［下へ移動］を選びます。

## ワークスペースへの移動

- セッションの［…］→［ワークスペースへ移動］で移したセッションは、これまでは移す前の位置によって、移した先のワークスペースの途中に入ることがありました。移した先のワークスペースの末尾に入るように修正しました。

## 終了したセッション

- 一覧に残す終了したセッションは、これまでどおり20件までです。20件を超えたときに一覧から外すセッションを、これまでの開いた時刻の古いものから、終わった時刻の古いものに変更しました。並べ替えても、最近終わったセッションが一覧に残ります。
