# sshc v0.3.1

Android などの狭い画面で、鍵画面のヘッダーと検索欄が表示領域からはみ出す問題を修正しました。

## 修正内容

- 狭い画面ではページヘッダーの操作項目を折り返すようにしました。
- セクション内部の横方向オーバーフローも検出する E2E テストを追加しました。
- 遅延読み込みが完了してから画面幅を検証するようにテストを修正しました。
- 修正後の Web UI を Go バイナリへ再埋め込みしました。
