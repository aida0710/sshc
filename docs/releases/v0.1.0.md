# sshc v0.1.0

最初の公開リリースです。OpenSSH の設定管理、SSH 接続、鍵と資格情報の管理、リモート同期を、ローカルで動作する Web UI から利用できます。

## 主な機能

- `~/.ssh/config` のコメント、記述順、空白を保つ編集
- Include グラフ、Host、Match、ProxyJump の解析
- ブラウザ内 SSH ターミナルとポート転送
- SSH 鍵の生成、移動、ssh-agent 連携、`authorized_keys` への登録
- マスターパスワードで暗号化する資格情報 vault
- S3 互換オブジェクトストレージを使用した暗号化バックアップと同期
- macOS、Linux、Windows、Android のサポート
- 日本語と英語の UI

## 配布物

このリリースには、各 OS 向け CLI、macOS と Linux のデスクトップパッケージ、Windows インストーラ、Android APK が含まれます。デスクトップパッケージは署名および公証を行っていません。

現在の配布形式とインストール方法は、[インストールガイド](https://github.com/aida0710/sshc/blob/main/docs/release-install.md)を参照してください。
