# sshc v0.44.2

v0.44.2では、Web UIに常に表示されていた説明を整理しました。Web画面から更新できない理由はサイドバーのバージョンの下に折りたたみ、転送マネージャーの長い説明は削除しています。

あわせて、[公開デモ](https://sshc-demo.aida0710.work/index.html)を日本語と英語に対応し、確認画面と安全性を改善しています。

## Web UI

- これまでは、Homebrew版やWindowsなどWeb画面から更新できない環境で、その理由がサイドバーのバージョンの下に常に表示されていましたが、**バージョンをクリックしたときだけ表示する**ように変更しました。新しいバージョンの案内、［sshcを更新］、更新中の状態は、これまでどおり常に表示されます。
- 転送マネージャーの「速度上限と復旧の対象」の説明を削除しました。速度上限と自動復旧の設定は、これまでどおり使えます。

## ブラウザデモ

- 画面を日本語と英語に対応しました。前に選んだ言語、ブラウザの言語の順に決め、どちらでもない場合は英語で表示します。起動前の画面右上のボタンで切り替えられ、選んだ言語はデモ内のWeb UIにも引き継がれます。CLIが表示するsshcのメッセージは日本語のままです。
- 確認画面の表に、初回にダウンロードするデータの合計を表示するようにしました。見出しは「sshcをWebで試してみる」に変更しています。
- 他のページに埋め込まれた状態では、デモを起動しないようにしました。代わりに、新しいタブで開くためのリンクを表示します。
- デモ一式を展開するとき、ファイルの保存先がデモのフォルダの外にならないかを確認するようにしました。
