# sshc v0.48.1

v0.48.1では、Windowsでの導入・更新・削除を改善しました。Windowsでも、`sshc update`と画面から更新できるようになり、「インストール済みアプリ」から削除できるようになりました。

あわせて、PowerShellのインストーラーで、改ざんされていないことの確認とPATHの扱いを改善しています。

## Windowsの更新

- これまでは、Windowsでは`sshc update`と画面からの更新を使えず、インストーラーを再実行する必要がありました。**PowerShellのインストーラーで入れたsshcは、`sshc update`と画面から更新できる**ようにしました。公開済みのリリースのインストーラーを取得し、checksums.txtと照合してから実行します。
- インストーラーは、sshcエンジンが動いていれば止めてからexeを入れ替え、入れ替えたあとに起動し直します。ログオン時の起動（`sshc service install`）を使っている場合はタスクで、そうでなければ裏で起動します。
- v0.48.0以前から更新する場合は、一度インストーラーを再実行してください。v0.48.0以前の`sshc update`は、Windowsでは更新を断ります。

## Windowsのインストーラー

- **「インストール済みアプリ」に登録する**ようにしました。そこから削除すると、ログオン時の起動を解除し、sshcエンジンを止めてから、exe・導入記録・PATHの項目を削除します。データ（`%USERPROFILE%\.ssh\sshc`）とSSHの設定・鍵は残します。
- GitHub CLI（`gh`）がある場合は、取得したexeとchecksums.txtが公式のリリースで作られたことを、attestationで確かめるようにしました（macOS・Linuxのインストーラーと同じ）。`gh`が無い場合は、確かめなかったことを表示し、SHA-256の照合で進めます。
- これまでは、ユーザーのPATHの末尾に追加していたため、古いsshc.exeがあるとそちらが使われていました。**PATHの先頭に追加する**ようにし、`%USERPROFILE%`などを含むPATHの書き方も保つようにしました。入れた場所より先に別のsshc.exeがあれば警告します。
- `irm ... | iex`で実行しても、PowerShellの設定や変数を呼び出し元に残さないようにしました。
