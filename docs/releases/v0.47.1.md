# sshc v0.47.1

v0.47.1では、Androidアプリでフォルダをアップロードできるようにしました。Androidのフォルダの選択画面で選んだフォルダを、中のフォルダとファイルごと送れます。

あわせて、表示していないセッションの進み具合をセッション一覧に出すようにし、Androidの通知から開いたときの動作と、画像の説明を改善しています。

## Androidアプリ

- これまでは、Androidのファイル選択画面がフォルダを選べないため、［フォルダをアップロード］を表示していませんでした。**Androidのフォルダの選択画面で選んだフォルダを、中のフォルダとファイルごと送れるようにしました。** 空のフォルダも作ります。一度に送れるファイルは、転送の上限の200件までです。
- これまでは、ターミナルの通知が届いたあとに画面が読み込み直されていると、通知を押してもアプリが開くだけで、そのターミナルへは移りませんでした。**画面を読み込み直したあとでも、通知を押すとそのターミナルを開く**ように修正しました。長いコマンドの完了の通知も、押すとそのターミナルを開きます。

## 進み具合

- これまでは、プログラムがOSC 9;4で知らせる進み具合を、表示しているペインの見出しにだけ出していました。**セッション一覧の各項目にも細い線で出す**ようにしました。別のセッションを表示しているあいだも、裏で動いているコマンドの進み具合が分かります。

## 画像

- v0.47.0の説明書には、大きさ（`size=`）を付けずに送られたiTerm2形式の画像は表示しないと書いていましたが、v0.47.0から表示できていました。説明書を直しました。

## そのほか

- 依存しているkin-openapiを0.149.0に更新しました（APIの定義からコードを作る道具が使うもので、sshcの動作は変わりません）。
- SFTPのエディタの検索・置換・括弧の対応と、JSONを開いたときにエラーが出ないことを、自動テストで確かめるようにしました。
