# sshc v0.17.4

リリース作業を1コマンド化し、検証済みのmainから公開成果物とHomebrew tapの確認までを一貫して実行できるようにした運用更新です。sshcの実行時機能はv0.17.3から変更していません。

## リリース自動化

- `scripts/release/publish.sh <tag>`を追加し、HEADと`origin/main`、同じSHAのmain CI成功を照合してから注釈付きtagを作成します。
- Release workflowを監視し、想定した`release` environmentの保護ゲートだけを承認します。未知のenvironmentが要求された場合は停止します。
- 公開後にImmutable Release、8成果物の完全性、checksums、全attestation、APK archive、実行可能なnative binary、release本文を検証します。
- stable releaseではHomebrew Formulaのtagと、実際に取得したsource archiveのSHA-256が一致することも確認します。
- `--verify-only`で既存Releaseを変更せずに再検証できます。失敗時は保護tagを移動・削除せず、新しいpatch versionで復旧する契約を維持します。

## 運用手順

- 必要なツール、事前条件、公開・再検証コマンドを`docs/releasing.md`へ記載しました。
- build contractへ自動化スクリプトの供給網境界を追加し、force pushやtag上書きを持ち込まないことを固定しました。
