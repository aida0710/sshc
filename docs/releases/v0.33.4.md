# sshc v0.33.4

v0.33.4では、Sessionsの選択表示をシンプルにしました。

## セッション一覧

- 選択したセッションの左端に表示していた青い縦バーを取り除きました。選択中の行は、背景色とタイトルの太字で示します。
- セッションの切り替え、操作メニュー、閉じる操作はこれまでどおり使えます。Web・Androidの両方に反映しています。

## 更新後

Webで変更を反映するには、バイナリ更新後に稼働中のengineを再起動してください。Androidでは正式版APKを更新してください。

**変更履歴**: [v0.33.3...v0.33.4](https://github.com/aida0710/sshc/compare/v0.33.3...v0.33.4)
