# sshc v0.66.1

v0.66.1では、画面の角丸を部品の役割ごとにそろえました。同じ役割の箱や入力欄が、どの画面でも同じ丸みで表示されます。

あわせて、ビルドに使うGoを、標準ライブラリの脆弱性の修正を含むバージョンに更新しています。

## 画面の見た目

- これまでは、同じ役割の部品でも画面によって角丸が違っていました。たとえば注意の箱は、画面によって4px・8px・9px・10px・12pxのどれかでした。**角丸を役割ごとの5段階（6px・8px・10px・12px・14px）にそろえました。**
- 板・ダイアログ・メニューは12px、板の中に置く箱と注意の箱は10px、入力欄・ボタン・一覧で選ぶ行は8px、小さな札とチェックボックスは6px、スマホのカードとログイン前の画面のカードは14pxです。
- ターミナルの分割表示の板は11pxでしたが、隣に並ぶサイドバーやほかのページの板と同じ12pxに変更しました。
- Settingsのキーバーのプレビューは、キーの角丸が実際のキーバーと違っていました。実際のキーバーと同じ丸みで表示するように修正しました。
- 変わるのは角の丸みだけです。操作と設定は変わりません。

## セキュリティ

- Goの標準ライブラリ（net/http）の脆弱性（GO-2026-6859）の修正を含むGo 1.26.11でビルドするように変更しました。
