# sshc v0.68.1

v0.68.1では、スマホのSnippetsの一覧を、Account passwordsと同じ角の丸い枠に入れて表示するようにしました。

あわせて、タッチの画面のサイドバーで行の右のボタンを押しやすくし、VPNのコンテナイメージに入れるパッケージを更新しています。

## Snippets

- これまでは、スマホでSnippetsを開くと、スニペットの一覧を枠なしで表示していました。**Account passwordsと同じく、一覧を角の丸い枠に入れ、スニペットの間を線で区切るように変更しました。** タブレットを縦に持ったときも同じ表示です。PCの表示は変わりません。

## サイドバー

- スマホとタブレット縦のサイドバーで、ワークスペースとセッションの［…］［×］［＋］のボタンの幅を36pxから44pxに広げました。高さは36pxのままなので、行の高さは変わりません。ボタンが広がった分、セッションの名前と接続先を表示する幅は16px狭くなります。PCのボタンの大きさは変わりません。

## VPN

- VPNのコンテナイメージに入れるUbuntuのパッケージを、2026年11月20日時点のものに更新しました。これまでは2026年10月20日時点のものでした。VPN機能を使用している場合、次にVPNに接続するときに、コンテナイメージがマシン上で1度だけ作り直されます。作成にはネットワークが必要です。
