# sshc v0.56.0

v0.56.0では、sshcが止まる前に開いていたセッションを、作業フォルダごと開き直せるようにしました。更新、PCの再起動、手動の停止のあとに起動すると、開き直すかを聞きます。実行先（SSHの接続先で動くsshcエンジン）のセッションも、その実行先が起動し直したあとに聞きます。

あわせて、実行先に届かないときの表示と再接続の表示、スマホのキー入力と下のタブを改善しています。Androidでは、sshcの画面のスクリーンショットを撮れるようにしました。

## セッションの開き直し

- **sshcエンジンが止まるとき、開いていたセッションを記録し、次の起動で開き直すかを聞くようにしました。** Vaultのロックを解除すると「前回のセッションを開き直しますか」と出ます。［開き直す］を選ぶと、同じ接続先・ワークスペース・順番で開き直し、作業フォルダが分かるセッションはそこへ移動します。利用者が付けたセッション名も戻ります。
- ［開き直さない］を選ぶと記録を消し、同じセッションについては二度と聞きません。Escや外側のタップで閉じたときは記録を残し、次に画面を開いたときにもう一度聞きます。答えないまま止めた場合も、次の起動でもう一度聞きます。
- **実行先のセッションも開き直せます。** 実行先が起動し直したあと、最初にその実行先を使ったときに聞きます。その実行先のVaultがロック中なら、ロックを解除したあとに聞きます。
- 作業フォルダは、シェルがOSC 7で知らせた場所か、Debian・Ubuntuのbashが既定で付ける`user@host: ~/dir`の形のタイトルから読み取ります。どちらも無いSSHセッションは、接続だけを開き直してホームディレクトリから始めます。Linuxのローカルシェルは、sshcエンジンが作業フォルダを直接読み取ります。
- 接続が切れて再接続を待っているセッションや、再接続をあきらめたSSHセッションも開き直します。プログラムが終わったセッションと、`sshc terminal create`で開いたセッションは開き直しません。
- 記録には接続先の名前とフォルダの場所だけを書き、パスワードや出力は書きません。同期でほかのマシンへ運ぶこともありません。異常終了や電源断のように、sshcエンジンが止まる処理を通らなかった場合は記録されません。
- **［この接続を複製］で開くセッションは、複製元の作業フォルダから始まるようにしました。** ローカルシェルは、複製元と同じシェルで開きます。これまでは、ホームディレクトリと既定のシェルで開いていました。

## 実行先と再接続

- **実行先でセッションを開くと、すぐターミナルの画面へ移り、「bastionに接続しています」のように表示するようにしました。** これまでは、実行先に届かないあいだ何も表示されずに待ち、失敗してもサイドバーに1行出るだけでした。開けなかったときは、一覧を読めないときと同じ板に、理由と［今すぐ再接続］を出します。
- 実行先へ同時に送った要求は、1回の接続の試みの結果を一緒に待つようにしました。これまでは、応答しない接続先へ、並んだ要求の数だけ接続の上限時間（既定は30秒）ずつ待っていました。黙って切れたSSHの接続の上で待ち続けないよう、取り次いだ要求は20秒で打ち切り、次の要求で繋ぎ直します。
- 実行先への接続の試みと結果（かかった時間と理由）を、sshcエンジンのログに書くようにしました。
- 実行先に届かないときの板の「2秒ごとに自動で再試行しています」を、「前の試みが終わると、2秒後にもう一度試します」に直しました。接続先が応答しないと1回の試みに30秒ほどかかるので、2秒ごとには試していませんでした。ページを隠しているあいだは試すのを止めます。
- **SSHの自動再接続の帯に、次に試すまでの秒数を出すようにしました。** 「あと7秒で試します」と「接続を試しています」を分けて出します。ターミナルに書く文は、2回目から「再接続できませんでした」にしました（新しく切れたわけではないため）。
- Settings → Terminalの再接続の回数の「最大40秒」は、試行の間の待ち時間だけの数字だと分かるよう、「待ち時間は最大40秒」に直しました。これとは別に、接続先が応答しないときは、1回の試行ごとにSSHの接続の上限時間まで待ちます。

## スマホ

- **キーバーのCtrlとAltを、素早く2回タップすると押したままに固定できるようにしました。** 固定中はさし色の地になり、もう一度タップすると外れます。1回のタップは、これまでどおり次の1キーだけに効きます。
- **ターミナルに送る文の入力欄で、Enterを押すと改行するようにしました。** 送るときは、入力欄の横のボタンを押します。これまでどおりEnterで送りたいときは、Settings → Terminalの「スマホの入力欄でEnterを押したら送信する」をオンにします。外付けのキーボードでは、Enterで改行する設定のときはCtrl+Enter（Macは⌘+Enter）で送ります。
- 改行を含む文は、ターミナルのプログラムがbracketed pasteを使っているとき、確認せずに1つの貼り付けとして送るようにしました。Enterが改行になると、送るたびに確認が出るためです。制御文字を含む文は、これまでどおり確認します。
- **下のタブを、画面の端から離した丸いバーに、アイコンだけを並べる形にしました。** 選んでいるタブは、さし色の丸い地で示します。ページの名前は上の見出しに出ます。
- **Androidで、sshcの画面のスクリーンショットと画面の録画を撮れるようにしました。** これまでは、画像に残らないよう写らない設定にしていました。ターミナルの出力やパスワードの入力欄を撮るときは、画像の扱いに気を付けてください。
- About sshcを、ほかのページと同じ角丸の板の形にし、一番上に出ていた余分な線を消しました。サイドバーの一番上のバージョンの表示のずれと、Workspacesの見出しとワークスペースの間の広すぎる隙間も直しました。
- Connectionsの［新しい接続］を［接続先を追加］に変え、スマホでは右に置くようにしました。

## そのほか

- セッションが開いていないときのTerminalの案内を、`sshc host`から`sshc ssh host`に直しました。
- Windowsで、同じフォルダへ同時に書き込むと保存に失敗することがある不具合を直しました（背景の画像を2枚同時に取り込むときなど）。一時ファイルとフォルダを、作るときから本人だけが読める形にしています。
