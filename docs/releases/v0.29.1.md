# sshc v0.29.1

v0.29.1では、WindowsでTerminalのカーソルが非常に速く点滅することがある問題と、起動直後にCommand Paletteのキーボードショートカットが反応しないことがある問題を修正しました。

あわせて、Coding Agent連携の導入手順を公開ドキュメントへ追加し、GitHub Pagesの公開workflowをNode.js 24対応版へ更新しています。

## TerminalとSFTPエディターのカーソル

- Windowsの「アニメーション効果」が無効な場合に、Terminalのカーソルが非常に速く点滅する問題を修正しました。この設定では、Terminalのカーソルを点滅させずに表示します。
- SFTPのテキストエディターも同じ設定に従い、カーソルを点滅させずに表示します。アニメーション効果が有効な場合は、TerminalとSFTPエディターのどちらもこれまでどおり点滅します。
- 外部コンポーネントの繰り返しアニメーションが、動きを減らすOS設定によって極端に高速化しないよう、画面全体の共通処理も修正しました。

## Command Palette

- Vaultを開いた直後や高負荷時に`Ctrl+K`／`Cmd+K`を押すと、画面は利用可能になっているのにCommand Paletteが開かないことがありました。アプリケーションの起動時からショートカットを継続して監視し、利用可能な状態へ切り替わる際の短い空白をなくしました。
- 画面上の「Search」ボタンと、Command Paletteを閉じるための同じショートカットの動作は変わりません。

## Coding Agent連携のドキュメント

- Claude Code、Codex、OpenCodeの状態をTerminalペインへ表示する[`sshc-agent-bridge`](https://github.com/aida0710/sshc-agent-bridge)について、日本語と英語の導入ガイドを追加しました。
- 対応環境、製品別のインストール、表示される状態、通知とセッション再開、送信する情報、トラブルシューティングをまとめています。
- Agent Bridgeは引き続き明示的に導入する実験的な機能です。導入しない場合、sshcが通常のターミナル出力からエージェント状態を推測することはありません。

## GitHub Pages

- GitHub Pagesの構成、成果物アップロード、公開に使うActionsをNode.js 24対応版へ更新しました。各Actionはこれまでどおりリリースタグではなくcommit SHAで固定しています。
