# sshc v0.8.1

SFTPの大容量ファイル転送を中断後も再開でき、別画面へ移動しても転送を継続できるようにしたリリースです。

## SFTPアップロード

- ファイルを1 MiB単位に分割して送信し、通信失敗後は確認済みのremote offsetから再開します。
- 一時ファイルへの転送完了後にrenameして確定するため、転送途中の内容を本来のファイルとして公開しません。
- 一時停止では再開用の一時ファイルを保持し、取消では削除します。
- 同じremote pathへの同時転送を直列化し、転送中に対象が変更された場合は上書きを拒否します。
- 画面を移動しても最大2件のbackground uploadを継続し、進捗、一時停止、再開、取消をSFTP画面で確認できます。
- browserを再読み込みした場合は、同じ名前、サイズ、更新日時のlocal fileを選び直すと保存済みoffsetから再開します。

## SFTPダウンロード

- file downloadへHTTP Rangeを追加し、通信が途切れた場合は受信済みoffsetから自動再開します。
- download queueと進捗はSFTP画面を離れても維持します。
- directory ZIP downloadは従来どおりstreamingで作成し、再開対象には含めません。

## 検証

- Go unit/race、Android向けbuild、deadcode、Web unit 839件、TypeScript型検査、ESLint、production buildを実行しました。
- Playwright E2E 110件を実バイナリと隔離HOMEで実行し、2 MiBを超えるuploadが画面移動中も継続することを確認しました。
- 固定digestのOpenSSH containerを使い、chunk転送、offset再開、atomic complete、Range download、取消後の一時ファイル削除を実SFTP subsystemで確認しました。
- 日本語UIをデスクトップと360px幅で撮影し、転送queue、進捗、操作buttonに文字切れと横overflowがないことを確認しました。
