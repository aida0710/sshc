# sshc v0.63.0

v0.63.0では、開いているセッションが無いときのターミナルに、動く文字の絵と、接続のアクティビティ、マシンの状態を出すようにしました。

あわせて、アプリのアニメーションを省く「動きを減らす」を設定に追加しています。

## セッションが無いときのターミナル

- これまでは、セッションが無いときのターミナルには、［ローカルシェルを開く］［接続先を追加］［同期で受け取る］のタイルだけを出していました。**タイルの後ろに動く文字の絵を出し、タイルの下にアクティビティと最近の接続、マシンの状態を出す**ように変更しました。
- アクティビティは、ターミナルのSSH接続の日ごとの回数を、最大1年分のマス目で出します。PCでは最近の接続も並べ、押すとその接続先を開きます。まだ接続していないときは出しません。
- マシンの状態は、新しいシェルが開くマシンのホスト名、OS、CPUの使用率、メモリ、稼働時間です。リモートセッションを選んでいるときは、そのマシンの値を出します。OSが出さない値は省きます（macOSはCPUと使用中のメモリ、FreeBSDとOpenBSDは使用中のメモリ、AndroidのアプリはCPUと稼働時間を出しません）。
- 絵は［Settings］→［Appearance］の「セッションが無いときの背景」で、ネットワーク・等高線・地球儀・水槽・なしから選べます。既定はネットワークです。スマホでは、タイルの上の帯に絵とマシンの状態を出します。
- 水槽の魚は最近の接続で、直近30日によく接続したものほど大きな魚になります。PCでは魚の下に接続先の名前を出します。マウスを近づけると魚が寄ってきて、何も無い所をクリック（スマホではタップ）すると、そこに餌が落ちて魚が食べに来ます。
- 絵はこの画面を出しているあいだだけ動き、タブやアプリが裏に回ると止まります。
- 接続の記録は、マシンごとに`~/.ssh/sshc/connection-activity.json`に置きます。ほかのマシンへは同期せず、372日より古い記録は消します。

## 動きを減らす

- これまでは、画面のアニメーションを省くかどうかを、OSの「視差効果を減らす」などの設定だけで決めていました。［Settings］→［Appearance］に「動きを減らす」（システムに合わせる／オン／オフ）を追加し、**sshcの中で選べるようにしました**。
- オンにすると、セッションが無いときの背景の絵を止め、パネルの開閉や画面の切り替えのアニメーションを省きます。既定の「システムに合わせる」は、これまでどおりOSの設定に従います。

## リモートセッション

- 接続先のsshcがv0.63.0より古いときは、マシンの状態とアクティビティを出しません。リモートセッションの互換の番号は上げていないので、接続先のsshcを更新しなくても、リモートセッションはこれまでどおり使えます。

## 更新後に必要な操作

- 「セッションが無いときの背景」と「動きを減らす」の設定は、v0.63.0より前のsshcが設定を書き直すと消え、既定（ネットワーク、システムに合わせる）に戻ります。同期しているマシンを全部更新してから設定してください。
