# sshc v0.9.1

Androidを含む狭い画面で、接続とTerminalへ使える表示領域を広げたリリースです。

## モバイル操作の改善

- Homeのクイック接続にある操作メニューを、接続行の上側へ開くようにしました。カード下端でメニュー項目が隠れません。
- モバイルのTerminalでは、右分割、下分割、Broadcast Inputを表示しないようにしました。desktopの分割操作と保存済みWorkspaceは維持します。
- モバイルdrawerの外周、group、項目の縦余白を圧縮しました。40pxの操作行を維持しながら、同じ画面高でより多くの項目を表示します。
- drawerを閉じた後はshadowも隠し、画面左端に影が残らないようにしました。

## 検証

- Goの全package testとrace detector、Android arm64 build、dead code検査を実行しました。
- Webのユニットテスト840件、TypeScript型検査、ESLint、production build、依存監査を実行しました。
- Playwright E2E 112件で、360px幅のメニュー位置、分割操作の非表示、drawerの表示密度、全画面の横overflowを確認しました。
- 固定digestのOpenSSH／SeaweedFSコンテナで、SFTP、SSH接続、暗号化S3同期を確認しました。
- 日本語UIの360×800スクリーンショットを撮影し、クイック接続、Terminal、Sidebarを目視確認しました。

## インストール

```sh
brew install aida0710/tap/sshc
```

または:

```sh
curl -fsSL https://raw.githubusercontent.com/aida0710/sshc/main/install.sh | sh
```

Android版は、このリリースの `sshc-android-v0.9.1.apk` をダウンロードして更新してください。
