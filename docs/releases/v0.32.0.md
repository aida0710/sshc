# sshc v0.32.0

v0.32.0では、Terminalの背景画像を選びやすくし、保存できる画像容量を設定できるようにしました。

あわせて、Vaultの資格情報一覧を整理し、日本語・英語UIの案内文とMenuから遷移する画面名を見直しています。

## Terminalの背景画像

- 背景画像の選択を検索可能な画像ライブラリへ移し、スマートフォンでは2列、広い画面では最大4列のカードとして表示するようにしました。
- 名前変更と削除を各画像の三点メニューへまとめ、通常のTerminal設定画面には現在選択している画像と変更操作だけを表示します。
- 背景画像の保存容量をSettingsから変更できるようにしました。既定値は16 MiBで、1〜1024 MiBの範囲を指定できます。
- 保存容量を変更しても、既存画像を自動削除・圧縮・変換しません。画像を削除する場合は、全体設定と接続先別設定からの参照も同じ更新処理で解除します。
- 同期スナップショットの作成では、端末に設定した画像容量を反映しつつ、背景画像以外の同期ファイルに同じ上限を誤って適用しないよう処理を分離しました。

## Vault

- Account passwords、Key passphrases、OTPの一覧を共通のカード構造へ揃えました。
- 割り当て先のホストと対象の鍵は各項目の次の行に配置し、必要なときだけ展開できるようにしました。
- 編集と削除を三点メニューへまとめ、保存件数や名前の長さが異なる場合でも一覧が崩れにくい配置にしました。
- OTPは現在の6桁コード、残り時間、前後コードの展開操作を分けて配置し、複数登録した場合の縦位置を揃えました。

## 表示と案内文

- 日本語表示のMenuで、VaultとSettings配下の画面名を`Account passwords`、`Key passphrases`、`OTP`、`Engine`、`Terminal`、`Notifications`、`Open connections`、`Master password`へ統一しました。遷移先の見出しも同じ名称を使用します。
- SFTPの転送キュー、Terminal設定、同期対象、接続診断、鍵操作、Config Explorerなどの日英案内文を、実際の動作と操作名に合わせて修正しました。
- ProxyCommandとProxyJumpの併用、OpenSSHがコマンドを実行する可能性のある設定、秘密鍵の表示、同期対象などの注意文を、sshcが確認できる範囲と実際のリスクが分かる表現へ変更しました。

## ドキュメント

- 日本語・英語のTerminal設定ガイドと資格情報ガイドを、背景画像ライブラリ、保存容量、Vaultの画面構成に合わせて更新しました。
