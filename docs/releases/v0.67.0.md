# sshc v0.67.0

v0.67.0では、同期の設定を別のマシンへ渡せるようにしました。設定済みのマシンで設定をファイルかQRコードに書き出し、追加するマシンで暗号化キーを入力して取り込みます。

あわせて、Android版にカメラの権限を追加し、同期の設定画面の表示を1か所直しています。

## 同期の設定の書き出しと取り込み

- これまでは、マシンを追加するたびに、エンドポイント、バケット、アクセスキーID、シークレットアクセスキーを入力していました。**設定済みのマシンから設定を渡し、追加するマシンでは暗号化キーを入力するだけで設定できるようにしました。**
- 書き出すには、設定済みのマシンでSyncの［同期設定を管理］を開き、「設定を書き出す」の［書き出す］を選びます。入力するものはありません。QRコードが表示され、［ファイルに保存］で`sshc-sync-settings.json`として保存することもできます。
- 取り込むには、追加するマシンのSyncで「書き出した設定を取り込む」の［ファイルを選択］か［QRコードを読み取る］を選びます。暗号化キーと同期の方向を入力して［取り込む］を選ぶと、接続の確認から設定の保存までを続けて行います。
- 取り込んだ直後は、設定が保存されるだけで、受信はしません。受信は、これまでどおり［変更を確認］か自動同期で行います。
- 同期の方向は書き出す設定に含めません。追加するマシンごとに、送受信、受信のみ、送信のみから選びます。
- 入力した暗号化キーが違うときと、書き出したあとで保存先が空になっていたときは、何も保存せずに理由を表示します。
- 設定が長くてQRコードに入り切らないときは、QRコードを表示せず、ファイルだけで渡します。

## 書き出した設定の安全性

- 書き出したファイルとQRコードには、バケットの接続情報とS3の認証情報が、暗号化キーで暗号化された状態で入ります。暗号化キーそのものは入りません。
- ファイルやQRコードを取得した第三者は、暗号化キーの総当たりをオフラインで試せます。暗号化キーを自分で決めている場合は、書き出しの画面に注意を表示します。sshcが生成した暗号化キーの使用をおすすめします。
- 書き出したファイルは、追加するマシンへ渡したあとに削除してください。詳しくは[セキュリティ](https://aida0710.github.io/sshc/reference/security)を参照してください。

## Android

- **Android版にカメラの権限を追加しました。** ［QRコードを読み取る］を最初に選んだときに、カメラの使用の許可を求めます。カメラを使うのはQRコードを読み取っている間だけで、映像は保存も送信もしません。
- カメラを許可しない場合も、ファイルからの取り込みは使用できます。

## 同期の設定画面

- 暗号化キーを自分で決めて設定を保存したあとも、［自分で決める］のチェックが付いたままでした。保存したあとはチェックを外すようにしました。
