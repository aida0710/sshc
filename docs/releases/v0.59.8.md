# sshc v0.59.8

v0.59.8では、スマホのターミナルで、シェルの出力を指で動かしやすくしました。出力は1行ずつ跳ばずに、指の動きについていきます。指を離したあとも、前より長く滑ります。

あわせて、ファイルのプレビューで前後のファイルへ移った直後に、前の画像が新しいファイル名のまま一瞬出ていた不具合を直しています。

## ターミナルの指のスクロール

- **シェルの出力を指で動かすと、指の動きにピクセル単位でついていくようにしました。** これまでは、指の動きに対して1行ずつ跳んで動いていました。指を離して止まると、近い行にそろいます。
- 指を離したあとの慣性を長く、速くしました。これまでは、指を離すとすぐに止まり、強くはじいても軽くはじいたときと同じくらいしか進みませんでした。速さが約4割に落ちるまでの時間を180msから350msに、はじいたときの速さの上限を3px/msから8px/msにしています。
- vimやlessなどの全画面のプログラムと、Claude Codeのようにマウスを読むプログラムの中では、今までどおり1行ずつ動きます。画面をプログラムが自分で描き直すためです。
- 変えたのは指の操作だけです。マウスとタッチパッドのスクロールは変えていません。端末で「動きを減らす」設定をしているときは、今までどおり指を離しても滑らず、すぐ近い行にそろいます。

## ファイルのプレビュー

- プレビューで前後のファイルへ移った直後に、前のファイルの画像が新しいファイル名のまま一瞬出ていた不具合を直しました。その間に始めたスワイプが効かないことがありました。
