# sshc v0.68.2

v0.68.2では、ターミナルで行をまたぐURLを1つのリンクとして開ける場面を増やし、スマホでサイドバーを出すときにターミナルが動かないようにしました。

あわせて、マウスでなぞって選ぶプログラムへの移動の報告と、画面上部に出る通信の失敗の通知を修正しています。

## ターミナルのリンク

- プログラムが画面の右端で改行して続きを字下げしたURLは、これまで、続きの行が文字、数字、`/`、`.`などで始まるときだけ1つのリンクとして扱っていました。**続きの行が`=`、`&`、`?`などの記号で始まるときも、1つのURLとして開けるように変更しました。** 記号のすぐあとに空白が続く行は、URLの続きとして扱いません。
- 罫線で区切った表のセルの中で折り返したURLも、1つのリンクとして開けるようになりました。対象は、列が2つ以上あり、セルの右端まで文字が詰まって次の行へ続いている表です。となりのセルの文字はURLに含めません。
- どちらも、スマホでのタップとPCでのクリックの両方に効きます。

## スマホのターミナル

- これまでは、画面の左端から横になぞってサイドバーを出すときに指が少し上下に動くと、ターミナルも一緒にスクロールしていました。**横になぞっている間は、ターミナルがスクロールしないように変更しました。** 指を10px動かしたところで向きを決め、上下の動きと決まるまではスクロールを始めません。上下にスクロールする量は変わりません。

## マウスを使うプログラム

- Claude Codeのように、マウスでなぞった範囲を自分でコピーするプログラムで、なぞっている途中で5秒ほど手を止めてから続きをなぞると、止めた位置までしかコピーされないことがありました。プログラムがマウスの報告の設定を送り直したときに、ボタンを押したままの移動が届かなくなっていたためです。**ボタンを押している間に設定が送り直されても、離すまで移動の報告を続けるように修正しました。**

## 通知

- リモートセッションの一覧は15秒ごとに読み直しています。これまでは、スリープからの復帰や回線の切り替えで一瞬つながらなかっただけでも、画面上部に通信の失敗の通知を表示していました。つながらなかっただけの場合は通知を出さず、次の読み直しを待つように変更しました。エンジンがエラーを返した場合は、これまでどおり通知します。
