# sshc v0.43.1

v0.43.1では、SFTPのテキストエディタで`Tab`を押したときの動作を修正しました。エディタの中で`Tab`を押すとインデントが入り、`Shift+Tab`でインデントが戻ります。

## SFTPのテキストエディタ

- これまでは、エディタの中で`Tab`を押すとインデントが入らず、フォーカスがダイアログの［閉じる］へ移っていましたが、**`Tab`でインデントが入るように変更しました。** `Shift+Tab`でインデントが戻ります。
- キーボードだけでエディタから［保存］や［閉じる］へ移るときは、`Ctrl+M`（macOSでは`Ctrl+Shift+M`）で「`Tab`でフォーカスを移すモード」に切り替えてから`Tab`を押してください。エディタのコマンドパレット（`F1`）の「Toggle Tab Key Moves Focus」でも切り替えられます。フォーカスはエディタのダイアログの中だけを移ります。
- このモードは、エディタを閉じるまで続きます。次にファイルを開いたときは、`Tab`でインデントする動作から始まります。
- 保存中（エディタが読み取り専用の間）にエディタで`Tab`を押すと、これまでどおりフォーカスが［閉じる］へ移ります。

## 更新後に必要な操作

- 更新後はengineを再起動してください。`sshc update`で更新した場合、`sshc service install`で登録したサービスは自動で再起動されます。`sshc update`を使わずに更新した場合（`brew upgrade`、install.shやinstall.ps1の直接実行）、サービスは`sshc service install`で再起動します。サービスとして登録していないengineは`sshc engine --replace`で再起動してください。
- 更新の前から開いているWeb UIのタブは、engineを再起動したあとに再読み込みしてください。
