# sshc v0.29.0

v0.29.0では、Terminalへ改行や制御文字を含む内容を貼り付けたときに、送信前の確認を挟むようにしました。誤って複数のコマンドを実行してしまう操作を、送信前に止められます。

あわせて、Terminalの再接続、Vaultの保存、SFTPの転送キュー、CLIの再帰ダウンロードについて、途中で失敗した場合の扱いを見直しています。

## Terminalの貼り付け確認

- これまでは貼り付けた内容をそのままターミナルへ送っていましたが、**改行、末尾のEnter、Escapeなどのターミナル制御文字を含む場合は、送信前に確認画面を表示する**ように変更しました。確認するまで1文字も送信しません。
- 確認画面には、接続先の名前、論理行数、制御文字を`\n`や`\x1b`のように可視化したプレビューを表示します。プレビューは4,096文字で打ち切りますが、選んだ操作は貼り付けた内容の全体に適用されます。
- 「キャンセル」「末尾のEnterを除いて貼り付け」「そのまま貼り付け」から選べます。末尾のEnterを除いた場合は改行が1つだけ取り除かれ、最後のコマンドは実行されずに入力行へ残ります。
- 右クリック、ブラウザーの貼り付け操作、Cmd+V、Ctrl+Shift+Vのいずれも同じ確認を通ります。接続先がbracketed paste modeを有効にしている場合も確認は省略されません。
- 改行も制御文字も含まない内容と、タブ文字だけを含む内容は、これまでどおりそのまま送信されます。
- プレビューと貼り付けた内容は保存しません。確認中にターミナルの出力、セッションの終了、再接続が起きた場合は確認が取り消され、貼り付け直しになります。

## Terminalの再接続

- これまではブラウザーが再接続するたびにengineの保持している出力をすべて再生していましたが、**前回表示した位置以降だけを再生する**ように変更しました。同じ出力が二重に表示されなくなり、ブラウザー側にだけ残っている古いスクロールバックも消えません。
- 切断が長く、必要な出力がengineの再生バッファ（既定256 KiB、設定範囲16 KiB〜4 MiB）から押し出されていた場合は、保持している最も古い位置から再生し、欠落があることを画面で知らせます。
- 貼り付けた内容は、engineへ送る単位を64 KiBに分けて順序どおり送るようになりました。1 MiBを超える貼り付けで接続が切れることはなくなりました。

## Vaultの保存

- これまでは認証情報の一部の更新で、保存に失敗しても画面上の値だけが新しくなることがありました。**保存が成功した場合にだけ画面と内部の値を更新する**ように変更しました。保存に失敗した場合は、変更前の値がそのまま残ります。
- 保存の直前に別の端末やウィンドウがVaultを更新していた場合は、その内容を上書きせず、競合として知らせます。

## SFTPの転送キュー

- これまでは転送キューの保存に失敗しても、操作が成功したように見えることがありました。**保存できなかった場合は操作を失敗として返し、キューの状態を元に戻す**ように変更しました。
- 転送キューのファイルが壊れていた場合も、engineは起動します。壊れた内容は原因調査用として端末内に退避され、キューは空の状態から始まります。退避した内容は同期の対象になりません。
- Remote→Remoteのコピーと移動では、転送先への反映や転送元の削除が済んでいる可能性がある段階で結果を記録できなかった場合、**自動では再実行しない**ように変更しました。この転送は「転送先の確認が必要」と表示され、実行できる操作はキャンセルだけになります。転送先で結果を確かめてから、一覧から外してください。

## CLIの再帰ダウンロード

- `sshc sftp get --recursive`に、深さ64段、ファイルとディレクトリを合わせて10,000項目、合計1,024 MiBの安全上限を追加しました。上限を超える場合は、1ファイルも転送せずに停止します。
- 意図して大きなツリーを取得する場合は、`--max-depth`（最大256）、`--max-entries`（最大1,000,000）、`--max-total-size`（MiB単位、最大8 TiB）でその実行だけ上限を引き上げられます。これらは`get --recursive`専用です。

## ワンタイムパスワードの自動入力

- v0.28.0では質問文のどこかに`otp`が含まれていればワンタイムパスワードを送っていましたが、**質問文の先頭がワンタイムパスワードを指している場合だけ送る**ように変更しました。`Password for otp-admin:`のようにユーザー名へ`otp`を含む通常のパスワード入力へ、ワンタイムパスワードを送らなくなりました。
- `OTP:`、`Enter your OTP code:`、`One-time password (OATH) for user:`、`Verification code:`、`Authenticator code:`、`認証コード:`、`ワンタイムパスワードを入力してください:`などは、これまでどおり自動入力の対象です。判別できない質問には自動入力せず、これまでどおり入力を求めます。

## そのほかの修正

- Terminalのフォントサイズ、スクロールバック行数、カーソルの点滅を変更したときに、ターミナルを作り直さないようにしました。設定を変えても表示中の内容が消えません。
- ワークスペースを続けて復元したときに、先に始めた復元の結果が後から届いても新しいレイアウトを上書きしないようにしました。使われなくなったセッションは自動的に閉じられます。
- SFTPで、古い転送一覧の応答が後から届いたときに閉じたタブが復活することがある問題を修正しました。
- 接続一覧で、同じ`Include`を複数の場所へ展開したときに項目が重複して扱われる問題を修正しました。
- Androidの戻る操作を、OSが用意している標準の仕組みへ統一しました。Android 13以降のジェスチャーと、それ以前のボタンで同じ動作になります。
