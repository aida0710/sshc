# sshc v0.13.3

Android版の起動失敗画面を診断可能なものへ変更し、engine、SSH再接続、SFTP終了処理、session更新、配布経路で見つかった競合とセキュリティ上の弱点を修正しました。

## Android起動診断

- 起動失敗をlocal port、private storage、engine初期化、早期終了へ正しく分類します。一般的な初期化失敗をすべてport取得失敗と表示していた誤分類を解消しました。
- 画面へversion、安定したfailure code、伏せ字化済みのroot error、Android版、device model、ABIを表示します。「診断情報をコピー」でそのままissueへ共有できます。
- dead-endだった失敗画面へ「もう一度試す」を追加し、Activityを閉じずに同じServiceからengineを再起動できます。
- bootstrap、password、passphrase、token、S3 access key、Authorization、URL userinfoを詳細とlogcatへ渡す前に除去し、制御文字と最大長も制限します。
- Goの起動goroutineが具体的な失敗を通知した直後に終了した場合、select順序によって`engine_stopped_early`へ誤分類する競合を修正しました。

## 接続・転送の安定性

- SSHは認証とremote shell開始が完了するまで`connecting`／`reconnecting`を維持します。失敗したhandshakeを接続成功や履歴として記録せず、typed errorと再接続回数を正しく引き継ぎます。
- 切断中のSSHを閉じた場合、進行中の再接続をcancelし、遅れて返ったprocessも回収します。SSH lifetime wrapperがport forward情報を失う問題も修正しました。
- `ProxyJump`に書いたuser／portを、hop側`ProxyCommand`のtoken展開より前に反映します。
- engine停止時にAuto Syncの終了とSFTP Transfer Managerをjoinし、次のAndroid engine世代とlocal writeや保持中remote handleが重ならないようにしました。
- Monaco Editor保存とresumable uploadの同一targetへの公開を直列化し、同じrevisionを同時検証した操作同士の上書きを防ぎます。

## セキュリティと配布

- session cookieはportを区別しないため、CSRF tokenの再発行にも現在の`X-SSHC-CSRF`を必須化しました。tokenはport-originごとの`sessionStorage`に保持します。
- Gradle wrapper JARを公式9.7.0版へ置き換え、checksumを契約テストで固定しました。
- installerのversion入力をSemVerに限定し、文書のpipe installを可変な`main`ではなく同じrelease tagのscriptとartifactへ固定しました。
- 全versionのrelease workflowを直列化し、古い手動runがlatest印やHomebrew tapを巻き戻さないようにしました。完全なattestation付きdraftとtap更新が揃ってから公開し、prereleaseはstable tapへ反映しません。
- source checkout用`startup.sh`がCLIのusageを表示して終了せず、foreground engineを起動するよう修正しました。

## 検証

- 全Go packageの通常testとrace detector、Android arm64 cross build、dead-code検査を実施しました。
- Web 91 test file／877 test、TypeScript型検査、OpenAPI生成物の再生成を確認しました。
- Androidのgomobile Java bindingに新しいfailure APIと定数が生成されること、診断reportのJava unit testを確認しました。
- Android AAR／APK、全Java unit test、APK署名と成果物attestationはrelease前のrequired CIで確認します。

## 互換性

設定、Workspace、Snippet、同期snapshot、SFTP転送queueの保存形式は変更していません。session renewの要求だけが厳格化され、同梱Web UIは現在のCSRF tokenを送信します。
