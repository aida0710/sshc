# sshc v0.50.0

v0.50.0では、Connectionsの画面だけでグループを作成・編集し、複数の接続先をまとめて移動・削除できるようにしました。

あわせて、Home・Connections・SFTPの見た目をそろえ、About sshcに更新の確認と更新の経過を表示するようにしています。グループの共通設定を保存すると、同じ接続先が2つ並んで表示される問題も修正しました。

## Connectionsのグループ

- これまではグループの作成、名前の変更、削除、共通設定の編集をGroupsの画面で行っていましたが、**Connectionsのグループの列から行えるようにしました。** ［＋］で新しいグループを作成し、各グループの「…」（右クリックでも開きます）から、中にグループを作成・名前を変更・編集・削除できます。グループを削除するときは、中の接続先の移動先を選びます。
- グループを選んで、接続先を開いていないときは、右側にグループの編集欄を表示します。共通設定のうち、ユーザー名・ポート・鍵・踏み台は欄で入力し、そのほかは「その他の設定」で編集します。保存していない変更があると、ほかへ移る前に破棄してよいかを確認します。
- 一覧で、Shiftを押しながら選ぶと範囲を、Ctrl（macOSでは⌘）を押しながら選ぶと1件ずつ選択できます。**2件以上選ぶと一覧の上に帯が表示され、グループへの移動と削除をまとめて行えます。** Escで選択を解除します。選んだ接続先は、まとめてグループへドラッグすることもできます。
- 各行の「…」から、接続・名前を変更・複製・グループへ移動・削除を行えるようにしました。
- スマートフォンでは、［選択］または長押しで選び、画面の下の帯から操作します。
- まとめての移動と削除は、sshcエンジンが1回の保存で行います。途中で失敗して一部だけが移動した状態にはなりません。設定ファイルがほかで変更されていた場合は、どの接続先も変更せずに保存を断ります。削除した接続先に割り当てていた起動スニペットも、同じ保存で外します。
- aliasの重複の警告に、どのaliasが、どのファイルの何行目で宣言されているかを、両方の場所について表示するようにしました。警告は「警告 N件」にまとめて折りたたみ、開いている接続先に関わるものだけを右側に表示します。

## グループの共通設定

- これまでは、グループに共通設定を保存すると、そのグループの接続先がConnectionsに2つずつ並び、aliasの重複の警告が表示されていました。Diagnosticsでも同じ警告が出て、メンバーを踏み台にした接続経路のホップを特定できないと表示されていました。**グループの共通設定の行を、接続先やaliasの宣言として数えないように修正しました。**

## Home・Connections・SFTP

- 3つの画面の上に、画面の名前・件数・主な操作を1行に並べる帯を置き、高さと見た目をそろえました。
- Homeは中央寄せをやめ、ConnectionsとSFTPと同じく画面の幅いっぱいに表示するようにしました。
- Homeの見出しを、日本語でも英語でも「Home」にしました。これまでは日本語でConnections、英語でYour connectionsと表示され、Connectionsの画面と見分けにくくなっていました。
- Homeでも、既定のポート（:22）を表示しないようにしました。接続先の検索欄の文言と、件数の表示（N件 / 全N件）をConnectionsとそろえました。Connectionsのグループの列と見出しにも、Homeと同じグループの色を付けました。

## About sshcと更新

- ［更新を確認］と［sshcを更新］を押したときの経過を、**ボタンの下に時刻付きで表示する**ようにしました。GitHubへの問い合わせ、取得した最新リリース、確認の失敗、更新の段階を1行ずつ表示します。これまでは、確認の結果が前と同じだと、確認したかどうかが分かりませんでした。
- 「このsshc」の見出しを削除しました。コミット、コミットの日時、ビルドしたときの未コミットの変更が分からないときは、「不明」と表示せず、行ごと表示しないようにしました。
- Homebrew版でも、ビルドしたタグのコミットとコミットの日時を表示するようにしました。Homebrew版は.gitの無いソースからビルドするため、これまではどちらも「不明」でした。
- サイドバーの新しいバージョンのお知らせにあった［sshcを更新］を、About sshcを開くリンク［About sshcで更新］に変更しました。更新の確認と経過は、About sshcにまとめて表示します。About sshcを開いているあいだは、経過のダイアログを重ねて表示しません。更新の結果は、これまでどおりダイアログで1回だけ表示します。
