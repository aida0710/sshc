# sshc v0.60.0

v0.60.0では、スマホからClaude Codeを操作しやすくしました。Claude Codeの許可待ちをAndroidの通知で知らせ、操作に要るキーをキーバーにそろえ、回線が切れている間は再接続の回数を使わずに待ちます。

あわせて、保存せずに`user@host`で接続する操作、分割から新しいセッションを開く操作、コマンド検索からの操作と設定の実行、SFTPの画像のサムネイルとグリッド表示を追加しました。スマホの画面、接続の失敗の文、Windowsの表示、画面からの更新も改善しています。

## 更新後に必要な操作

- **実行先を使っている場合は、実行先のsshcもv0.60.0へ更新してください。** 接続先で`sshc update`を実行します。実行先とのやり取りの互換の番号を上げたので、どちらかがv0.59.9以前のままだと、その組み合わせは実行先として使えません。
- **「tmuxで開く」、右に分割・下に分割のキー、「画像のサムネイルを出す」のオフを使う前に、Syncで同期しているすべてのマシンをv0.60.0へ更新してください。** v0.59.9以前のsshcが設定を保存し直すと、これらの設定と、パスワードを「保存しない」と答えた記録が消えます。v0.59.5以前のsshcは、v0.60.0で保存したショートカットのプリセットごと捨てます。

## Claude Codeの操作

- これまではアプリを裏に回している間にClaude Codeが許可や入力を待っても、Androidの通知は出ませんでしたが、**通知で知らせるようにしました。** 通知を押すとそのセッションが開き、見るか待ちが終わると消えます。音は、Androidの通知の設定の「許可待ち・入力待ち」で変えられます。
- 別のセッションやページを見ている間に待ちが始まったときは、アプリを裏に回したときに1回知らせます。すでに見た待ちは知らせません。
- Claude Codeの状態を最初に受け取ったとき、通知の許可を求める知らせを1回出します。
- tmuxの中のClaude Codeは通知しません。tmuxがClaude Codeの問い合わせに答えず、状態が届かないためです。
- これまではスマホからShift+Tabを打てず、Claude Codeのモードを切り替えられませんでしたが、**Key barの「キーの並び」にプリセット「Claude Code」を追加しました。** いつも出す段はEsc・Shift+Tab・Enter・↑・↓・^C・/・@・Tabです。置けるキーにもShift+Tabと@を足しました。
- 入力欄が空のときの送信のボタンは、Enterを押すボタンになります。Claude Codeの許可の確認にそのまま答えられます。
- これまでは接続していない間に送信を押すと文が消えていましたが、文を残すようにしました。送信のボタンを薄くし、何をすればよいかを出します。接続したあとに自動では送りません。
- Claude Codeのモードの印（⏵⏵、⏸）が豆腐にならないようにしました。
- 文字を選んでいるときのAndroidの戻るは、ページを離れずに選択を外します。

## 回線が切れたとき

- これまでは回線が切れると約40秒で再接続の5回を使い切り、回線が戻っても接続しませんでしたが、**回線が無い間は回数に数えずに待ち、戻ったらすぐ再接続するようにしました。** AndroidはOSの知らせで回線の有無を判断します。PCは接続の失敗の理由で判断し、5秒ごとに確かめます。
- これまではWi-Fiとモバイル回線が切り替わると、「接続済み」のまま入力が届かなくなることがありました。OSが回線の変化を知らせたら接続が応答するかを確かめ、10秒応答が無ければ再接続します。
- **接続先ごとに「tmuxで開く」を選べるようにしました（Connectionsの［表示とターミナル］）。** 再接続やエンジンの再起動のあとも、同じtmuxのセッションに戻ります。接続先にtmuxが無いときはターミナルで知らせ、ふつうのシェルで開きます。Hostブロックに`RemoteCommand`があれば、そちらに従います。
- 新しいシェルに替わったとき、前のシェルでClaude Codeが動いていれば、`claude --continue`を案内します。枠の［続きから始める］は、動いていたフォルダへ移ってから実行します。フォルダが分からないときは枠を出さず、ターミナルの行で案内します。tmuxで前のセッションに戻ったときは案内しません。
- 再接続をあきらめたセッションは、Enterで再接続できるようにしました。スマホでは送信のボタンです。
- サイドバーのセッションの行に、切れた理由を短く出すようにしました（接続を拒否されました、認証できませんでした、など）。全文はツールチップと枠に出ます。
- 接続の失敗を日本語の行で伝えるようにしました。元の英語の文は接続ログの「詳しく」に残ります。
- keyboard-interactiveを問いを出さずに断るサーバーの失敗は、認証の失敗として伝え、自動再接続を止めます。
- ホスト鍵の答えを待つ間にサーバーが接続を切ったとき（`LoginGraceTime`、既定120秒）は、受け入れたあとに1回だけ接続し直します。鍵はもう一度聞きません。

## 接続先を作る、接続する

- **新しいセッションの検索欄とコマンド検索に`user@host[:port]`を打つと、保存せずに接続できるようにしました。** ［接続する］は設定ファイルに何も書きません。［接続先として保存して接続する］はHostブロックを書きます。スマホのキーボードがかなのときは、英字に切り替えて打ってください。
- 新しい接続先で接続名を空にすると、ホスト名から補います（`10.0.0.5`は`10-0-0-5`、`web.example.com`は`web`）。
- 認証方法に［接続のときに入力する］を足しました。ターミナルで打ったパスワードで接続できたら、Vaultに保存するかを1回だけ聞きます。「保存しない」と答えた認証先には、もう聞きません。
- 新しい接続先の画面で、踏み台を［経由する接続先］から選べるようにしました。
- OpenSSHが読めないキーワードの行（`HostNmae`など）があると、SSH Configの診断とHomeの「確認が必要」に出すようにしました。1行でもあると、OpenSSHは設定全体を読みません。

## 分割とコマンド検索

- これまでは横に並べるセッションが無いと分割できませんでしたが、［右に分割して表示］［下に分割して表示］から新しいセッションを選べるようにしました。今のセッションの複製、ローカルシェル、ほかの接続先、`user@host`を選べます。
- ショートカットに「右に分割」「下に分割」を足しました。既定は未設定です。
- **コマンド検索から、ショートカットの操作を名前で実行できるようにしました。** 割り当てたキーは右に出ます。テーマ、OSC 52、画面を常にオンも名前で切り替えられます。
- ショートカットのプリセットを「キーの割り当て」、キーバーのプリセットを「キーの並び」と呼び分けました。
- Vaultのマスターパスワードを自動ロックと別の節に分け、「このマシンだけ」の設定であることを出します。

## SFTP

- **画像の行にサムネイルを出し、リストとグリッドを切り替えられるようにしました。** PCとスマホ、リモートとローカルのペインで使えます。対象はJPEG・PNG・GIFで、動画、WebP、HEICなどはアイコンのままです。画像が1000枚を超えるフォルダでは出しません。
- サムネイルは見えている行の分だけ読みます。スマホの通信を増やしたくないときは、Settings > SFTPの「画像のサムネイルを出す」をオフにします。設定のプリセットごとに選べます。
- これまでは`known_hosts`に無い接続先を開くと英語のエラーで止まっていましたが、タブの中でホスト鍵を確かめてから開くようにしました。
- スマホのフォルダの「…」を19項目から7項目に絞りました。並べ替えと更新は一覧の上に、戻る・進むなどはパスを押したあとに移しました。
- スマホの行のチェックボックスは、長押しで選んでいる間だけ出します。
- プレビューの見出しをファイル名に、閉じるを×のアイコンにそろえました。
- PCの未接続のタブには、絞り込みと比較を出さないようにしました。

## スマホの画面

- **これまでは裏から戻るたびに全画面が数秒覆われていましたが、前の画面を出したままVaultの状態を確かめるようにしました。** 確かめている間は操作だけを止め、0.4秒以上かかるときに上に小さい印を出します。パスワードなしのVaultは操作も止めません。この動きはPCのブラウザでも同じです。自動ロックのあとは、確かめ終わるまで前の画面が読めます（操作はエンジンが断ります）。確かめに失敗したときは全画面で隠します。
- 接続名、ホスト名、ユーザーなどの英字の欄は、日本語のキーボードでも英字の配列で開くようにしました。
- 画面やダイアログを開いただけでは、キーボードを開かないようにしました。
- キーボードを閉じて裏へ回すと、戻っても閉じたままにしました。かなの変換中に裏へ回すと文を確定し、戻って続きを打っても消えません。
- サインアウト、ssh-agent、実行ファイル、内部のパスなど、Androidのアプリでは意味の無い案内を除きました。ファイルは`~/.ssh/`からの形で出します。
- 押す場所を広げました。ほとんどは44pxで、キーバーのキーは39×44です。
- 何も無い画面を、次にできる操作のタイルを並べた「はじめに」の板にしました（Home、Connections、Terminal、SSH Keys、Known Hosts）。PCでも同じです。
- Androidのアプリでも新しいリリースを確認し、Aboutの［リリースページを開く］で案内します。

## Windows

- ローカルのPowerShellとcmd.exeのセッション名が実行ファイルのパスになっていましたが、`Windows PowerShell`、`Command Prompt`と出すようにしました。SSHでWindowsへ接続したセッションは接続名です。
- ターミナル、差分、エディタの既定の字体を、Cascadia MonoかConsolasにしました。`\`が`¥`の形で出なくなります。
- `sshc service install`は、タスクが動いている間は20秒まで待ちます。タスクが止まったら、すぐにエンジンのログの末尾を添えて失敗を伝えます。

## 画面からの更新

- 過去の再起動の失敗の記録が残り、そのあと`sshc update`で更新しても［sshcを更新］が出なくなる不具合を修正しました。
- GitHubのAPIの回数制限に当たると「ネットワークを確認してください」と出て更新を始められませんでしたが、APIが断ったときはリリースページの転送先から最新のバージョンを読むようにしました。`sshc update`も同じです。
- Aboutを開いた直後に、前の確認の失敗が一瞬見える不具合を修正しました。

## Sync

- これまでは1台目が同期先を設定しても［今すぐ同期］を押すまで同期先は空のままで、その間に2台目を設定すると暗号化キーが食い違いました。空の同期先へ設定を保存するときに、ファイルを含まないスナップショットを置くようにしました。`~/.ssh`のファイルは送りません。
- ［今すぐ同期］のあと、最初の設定のあと、30秒ごとの確認で、コミットメッセージの下書きを読み直すようにしました。手で書いたメッセージは上書きしません。

## そのほかの修正

- Historyから「Vaultを復元」しても一覧が古いままで、次の保存が失敗する不具合を修正しました。
- Settings > Terminalで既定のシェルを選べない不具合を修正しました。
- Vaultの作成画面で言語を変えると、ロック解除の画面に移る不具合を修正しました。
- 日時の書き方を「今日 17:49」「昨日 9:02」「11/1 9:02」にそろえました。
- 「ディレクトリ」を「フォルダ」、「経路」を「ルート」、「リモートホスト」を「接続先」にそろえました。
- Open connectionsに開いているセッションを並べ、Historyの「その他の変更」の多くに名前を付けました。
- 変数の無いクイックコマンドは、確認を挟まずに［ペインに挿入］できるようにしました。実行は今までどおり確認します。
