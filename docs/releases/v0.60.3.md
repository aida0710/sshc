# sshc v0.60.3

v0.60.3では、Claude Codeの許可待ちの通知を改善しました。PCのブラウザでも通知が届くようになり、tmuxの中のClaude Codeの許可待ちもサイドバーと通知に出ます。

あわせて、スマホのパスワードの入力、Androidの再接続と複数のダウンロード、ドラッグの操作を改善しています。

## 許可待ちの通知

- これまでは、プログラムの許可待ち・入力待ちの通知はAndroidだけで、PCのブラウザではサイドバーにしか出ませんでした。**PCのブラウザでも通知する**ように変更しました。タブがバックグラウンドにあるときと、ウィンドウにフォーカスが無いときに待ち始めると、ブラウザ通知と通知音で知らせます。通知を押すとそのセッションを開き、待つのをやめると通知を取り下げます。
- 別のセッションを見ている間に待ち始めたものは、sshcから離れたときに1回だけ知らせます。
- ブラウザ通知をまだ許可していないときは、最初にプログラムの状態を受け取ったときに、許可するかを1回だけ聞きます。［Settings］→［Notifications］からも許可できます。
- これまでは、tmuxの中のClaude Codeの許可待ちと回答待ちは、サイドバーにも通知にも出ませんでした。tmuxがClaude Codeとsshcのやり取りを通さないためです。**engineが画面に出ている問いを読み取り、サイドバーと通知に出す**ように変更しました。問いに答えると通知を取り下げます。
- 画面から読み取るので、tmuxで表示していないウィンドウの問いとデタッチ中の問いは読めません。Claude Codeの問いの文が変わった場合も読めず、通知が出ないことがあります。tmuxの外でも、`less`などの全画面の表示に問いと同じ文字を出すと、許可待ちとして知らせることがあります。

## スマホの入力欄

- これまでは、パスワードを聞かれている間も、ターミナルの下の入力欄に打った文字がそのまま見えていました。**カーソルの行がパスワードの問いで終わっている間は、入力欄を伏せ字の欄に替える**ように変更しました。キーボードの候補と学習も使われません。問いの間も書きかけの文は消えず、問いが終わると戻ります。
- 問いかどうかは画面の文字で判定します。`password`、`passphrase`、`パスワード`、`パスフレーズ`のあとが`:`で終わる行を問いとして扱います。`パスワードが違います:`のような文は問いとして扱いません。

## Androidのアプリ

- これまでは、回線が変わって接続が切れたときも、再接続の回数に足して、次の再接続まで待っていました。回線が変わって切れた接続は、待たずに再接続するように変更しました。機内モードを切ってすぐモバイル回線からWi-Fiへ替わると再接続が2回起きますが、これは回線が変わったときの正しい動きなので残しています。エミュレータでは、機内モードを切ってから2回目の接続までが約8.6秒から約6.4秒になりました。
- これまでは、ライトのテーマで、ほかのアプリから戻るときに画面全体が黒くなっていました。この黒い画面が出ないように修正しました。画面を描き直す間は、0.2〜0.5秒ほど白い画面が出ます。同じ原因で、ライトのテーマでもシステムバーが黒いままだったので、白い地に暗いアイコンに変わります。
- これまでは、複数のファイルを選んでダウンロードすると、最初の1件以外が保存先を選ぶ前に「SFTPの操作に失敗しました」で失敗していました。保存先の画面を1件ずつ順に出すように修正しました。
- 保存先の画面でキャンセルした転送は、失敗ではなくキャンセルとして扱います。1件をキャンセルしても、次のファイルの保存先は聞きます。プレビューからのダウンロードとスクロールバックの保存でも、失敗の知らせを出しません。

## ドラッグ

- v0.60.2では、Connectionsの幅1280px未満のウィンドウで、接続先をグループへドラッグできませんでした。**ドラッグしている間だけグループの一覧を浮かせる**ように変更し、この幅でも落とせるようになりました。グループの見出しをドラッグして、グループごと動かすこともできます。
- これまでは、［SSH Keys］で選んでいない行をドラッグすると、ブラウザがドラッグをすぐに取り消していました。フォルダへ落とせるように修正しました。ドラッグしても行の選択は変わりません。選んである行をドラッグしたときは、今までどおり選んである鍵をすべて動かします。
- これまでは、SFTPのタブ、ワークスペース、セッションの一覧、Connections、［SSH Keys］のフォルダで、落とし先の中の要素の境目を越えた直後に離すと、何も起きないことがありました。すぐに離しても落ちるように修正しました。
- これまでは、接続先の無いグループを動かしても、新しい場所にフォルダが作られず、［フォルダの確認］に出ていました。動かすときにフォルダを作るように修正しました。

## ターミナル

- 出力が保存の大きさを超えたセッションで、engineの画面の処理がpanicすることがある不具合を修正しました。スクロールの範囲の下端が画面より下にあるときの改行と、画面を小さくしたあとで代替画面を抜けるときや保存したカーソルへ戻るときに起きます。
