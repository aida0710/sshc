# sshc v0.14.1

Live Workspaceの操作を整理し、ターミナル本文と操作ボタンの重なりを解消しました。スマホでは接続中のターミナルへ集中できるよう、デスクトップ専用の管理操作を表示しません。

## ターミナル画面

- pane移動、Focus Mode、Workspaceから外す操作を専用のタイトルバーへ移し、ターミナル本文へ重ならないようにしました。
- 明示的なSplitボタンを廃止しました。新しい分割は接続一覧からターミナルの左・右・上・下へDrag & Dropして作成します。
- 1つのLive Workspaceと保存レイアウトは最大4 paneです。既存paneの並べ替えは上限到達後も利用できます。

## スマホ

- 一括実行、保存レイアウト、paneタイトルバーなどのデスクトップ管理操作を非表示にしました。
- 複数接続のWorkspaceでは、上部の接続切替だけを残し、ターミナルは常に1画面表示します。

## 一括実行

- 常時入力を複製するBroadcast Inputを廃止し、「一括実行…」ボタンから開くモーダルへ統合しました。
- 直接入力したコマンドまたは保存済みSnippetを選び、対象host／paneと実際のコマンドをpreviewしてから実行します。
- 表示中shellの作業ディレクトリや環境変数を暗黙に共有せず、対象ごとに独立したSSH実行として扱います。

## 保存レイアウト

- Workspaceという用語だけでは目的が分かりにくかったため、管理入口を「保存レイアウト」へ変更しました。
- 保存対象は接続先alias、分割方向、分割比率、focus位置です。terminal sessionやscrollbackは保存せず、開くと新しいSSH接続を作成します。
- 管理入口に説明を表示し、「名前を付けて保存」「この配置を開く」「削除」の操作をまとめました。

## 検証

- 最大4 pane制限をlayout reducerと保存APIの両方で検証しました。
- Broadcastモーダル、Drag配置、paneタイトルバー、スマホの単一pane表示をunit testとChromium E2Eで確認しました。
- デスクトップ、Broadcastモーダル、360×800のスマホ表示をスクリーンショットで確認しました。
