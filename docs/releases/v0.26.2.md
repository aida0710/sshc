# sshc v0.26.2

v0.26.2では、SFTPで大きなファイルを送受信するときの上限と転送方法を見直しました。通常ファイルは512 GiBまで扱え、指定したチャンクサイズと接続数で分割してアップロード、ダウンロードできます。

あわせて、CLIとWebの転送設定、ターミナル上の秘密入力、Connections画面とサイドバーの表示を改善しました。

## SFTPの大容量転送

- 通常ファイルにもフォルダーZIP用の1 GiB制限が適用され、`sftp_text_too_large`で失敗していた問題を修正しました。通常ファイルの上限は512 GiBになり、転送サイズの上限を超えた場合は`sftp_transfer_too_large`を返します。
- 初期設定では、100 MiB以上のファイルを32 MiB単位に分け、最大4つの独立したSFTP接続で並列転送します。Webの転送マネージャーでは、分割開始サイズを16〜1024 MiB、接続数を1〜8、チャンクサイズを8〜4096 MiBの範囲で任意の整数に設定できます。転送がない状態でも設定でき、接続数を1にすると分割しません。
- 単一ファイルのアップロードにも同じ分割設定を使います。各接続はリモート側の一時ファイルにある重ならない範囲へ書き込み、すべての範囲が揃った後に内容全体を検証してから正式なファイル名へ置き換えます。接続が切れた場合は、エンジンの転送キューに保存された完了済み範囲を飛ばして再開します。
- `sshc sftp settings`でWebとCLIが共有する分割設定を表示・保存できます。`sshc sftp get`と`sshc sftp put`では、`--split-size`、`--split-jobs`、`--chunk-size`で、その実行だけ保存済み設定を上書きできます。`--jobs`には同時に転送するファイル数を1〜8で指定できます。
- 分割ダウンロードは、再開時にも同じリモート内容を取得できるよう、engineの一時領域へファイル全体を準備します。対象ファイルと同程度の空き容量が必要です。フォルダーをZIPにまとめるダウンロードには別の上限があります。

## ターミナルの秘密入力

- Vaultのマスターパスワード、Syncの秘密値、SSHのパスワードや鍵のパスフレーズを入力すると、Unicode文字1つにつき`*`を1つ表示します。入力中に何文字入れたかを確認でき、平文は画面やスクロールバックへ表示しません。
- Backspaceで1文字、`Ctrl+U`で入力中の内容を消去できます。SSHのkeyboard-interactive認証にも同じ入力方法を使います。

## Web画面とドキュメント

- Connections画面のヘッダーを他の画面と同じ高さに揃え、接続先一覧へ使える領域を広げました。
- サイドバーでは、engineの状態を示す点をバージョン表示と同じ行に配置しました。
- 入力欄、ボタン、確認ダイアログなどの共通部品を整理し、設定、鍵、Secrets、Snippetsを含む各画面の間隔と操作感を揃えました。
- 日本語の公開ドキュメントを実装と照合し、CLI、SFTP、接続設定、Sync、セキュリティなどの説明を修正しました。
