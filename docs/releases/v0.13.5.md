# sshc v0.13.5

Android 16のworkspace起動修正と共通エラー診断を正式公開し、非対話SSH操作の保存済みパスワード利用、同期・暗号化・ターミナルのCI安定性を改善しました。

## Android 16の起動修正

- Androidのprivate workspaceへ至る中間directoryを`O_PATH | O_NOFOLLOW | O_DIRECTORY`で辿り、`/`や`/data`の一覧取得が拒否されるAndroid 16でもengineを起動できるようにしました。
- 最終workspaceだけをread/write可能なdescriptorとして開きます。descriptor-relativeなpath traversal対策とsymlink拒否は維持しています。
- execute-only ancestorを再現するfilesystem／mobile engine testを追加し、Android固有の権限モデルをLinux CIで継続検証します。

## 共通エラー診断

- 予期しないserver／network失敗をApp shellで通知し、version、安定したerror code、HTTP status、method、pathname、安全確認済みdetailをコピー可能な診断レポートとして表示します。
- request body、query parameter、fetch例外本文は診断へ含めません。入力不備などの4xx、session lifecycle、background update確認は各画面の説明に任せ、二重表示を避けます。
- 起動途中のhealth request失敗にも同じ診断表示を使い、通常画面を離れず詳細確認とdismissができます。

## SSHと検証の安定性

- command実行、stream、接続診断などの非対話SSH経路でも、hostへ保存した専用passwordと共有passwordを認証候補として使用します。
- 自動同期backoffのtestを仮想時計へ切り替え、CPU速度に依存せず期限前後を検証します。
- Windowsで時間の掛かるvault鍵導出をdeadlockと誤判定しないようにし、高負荷race実行時のterminal終了待機も安定化しました。暗号化強度と製品側のtimeoutは変更していません。

## 検証

- 全Go packageの通常testとrace detector、Android arm64 cross build、dead-code検査を実施しました。
- Web単体test、TypeScript型検査、lint、Playwright 114 testと実engineの診断画面screenshotを確認しました。
- OpenSSH／object storage integration、Android AAR／APK、Java unit test、APK署名、全platform成果物とattestationはrelease workflowで確認します。

## 互換性

設定、Workspace、Snippet、同期snapshot、SFTP転送queueの保存形式は変更していません。v0.13.4は公開前検証で停止したため、同版の内容はすべてv0.13.5に含まれます。
