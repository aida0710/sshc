# sshc v0.33.8

v0.33.8では、SFTPとTerminalの日常操作を改善し、長時間処理の状態を分かりやすくしました。

## SFTP

- 空ファイルの作成、リモートファイルの複製、複数項目の絶対パスへの移動を追加しました。
- ディレクトリの容量計算と、シンボリックリンクをたどらない再帰的な権限変更を追加しました。
- ローカルとリモートで選んだ並び順をタブごとに保持します。
- バックグラウンド転送が完了または失敗したときに通知します。

## TerminalとConnections

- OSC 133のコマンド境界に対応し、30秒以上かかったコマンドの完了を通知します。
- 貼り付け確認ではコマンドを編集でき、制御文字を含む元コマンドの表示を初期状態で折りたたみます。
- Connectionsの省略記号だった操作を「接続の管理」トグルへ変更しました。
- ブラウザとPWAの戻る・進む操作で、メニューの遷移元や接続編集タブへ戻れます。

## 品質とリリース

- 主要画面のアクセシビリティ検査をCIへ追加しました。
- Android署名、GitHub Releaseの準備、Homebrew更新を1回の保護環境承認へまとめました。
- Android依存ツールの一時的な取得失敗に対して、上限付きの再試行を追加しました。

## 更新後

Webではバイナリ更新後に稼働中のengineを再起動してください。Androidでは正式版APKを更新してください。
