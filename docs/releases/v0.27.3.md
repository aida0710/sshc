# sshc v0.27.3

v0.27.3では、v0.27.2で発生したTerminal背景画像の表示不具合を修正しました。

あわせて、常駐起動したengineのローカルシェルで文字の表示が崩れる問題を修正し、SFTPで1ファイルを分割転送する際の並列数を最大128へ拡張しています。

## Terminalの描画

- v0.27.2で文字の残像を抑えるために導入した不透明な描画レイヤーを取りやめ、背景画像を再びTerminalの背面から表示できるようにしました。
- 「WebGL描画を使用する」の設定は維持しています。背景画像を使用するTerminalでは、引き続きDOM描画へ自動的に切り替えます。
- 背景画像の設定、表示、解除と、画像を表示した状態での文字入力を実際のブラウザーで確認するテストを追加しました。

## ローカルシェル

- SSH接続ではTerminal種別を`xterm-256color`としていましたが、ローカルシェルはengineを起動した環境の`TERM`をそのまま引き継いでいました。launchd、systemd、GUIから起動した場合に、`TERM`が未設定または不適切な値となり、入力した文字が二重に見えたり、削除した文字が残ったりすることがありました。
- ローカルシェルも常に`TERM=xterm-256color`で起動するよう統一しました。engineをどこから起動しても、組み込みTerminalの機能とシェル側の端末認識が一致します。
- あえて`TERM=dumb`でengineを起動したブラウザーテストでも、ローカルシェル内では`TERM=xterm-256color`となることを確認しています。

## SFTPの分割並列数

- 大きなファイルを分割してアップロード、ダウンロードする際の1ファイルあたりの並列数を、最大8から最大128へ拡張しました。Webの転送マネージャーとCLIの`--split-jobs`から1〜128を指定できます。
- 既定値はこれまでどおり4です。1を指定すると分割転送を無効にできます。実際に開く接続数は未転送チャンク数までに制限されます。
- キュー全体で同時に処理するファイル数は、引き続き最大8です。複数ファイルを同時に分割すると接続数が掛け合わされるため、接続先サーバーと端末の上限に合わせて設定してください。
- OpenAPI、CLIヘルプ、入力検証、進捗表示を128並列に対応させ、境界値を確認するテストを追加しました。
