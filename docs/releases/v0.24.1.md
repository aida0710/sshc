# sshc v0.24.1

v0.24.1では、画面ごとに異なっていた確認・入力ダイアログを共通化し、キーボード、Androidの戻る操作、画面遷移を含む操作方法を揃えました。

あわせて、PWAアイコンの表示とWorkspace名の変更方法を修正しています。

## 確認・入力ダイアログ

- Workspaceの保存、SFTPのフォルダ作成・名前変更・権限変更、接続編集の未保存確認で使用していたブラウザー標準ダイアログを、sshcの画面内ダイアログへ置き換えました。
- 接続作成、保存パスワード、秘密鍵の表示、同期のForce Push・Pull、ポート転送、Command Palette、Workspaceへの一括コマンドを同じダイアログ基盤へ統一しました。
- ダイアログ内からTabキーでフォーカスが外れないようにし、Escapeキー、Androidの戻る操作、外側のクリックによる閉じ方と、閉じた後のフォーカス復帰を揃えました。
- 入力値に問題がある場合は、ダイアログを閉じずに、その場で理由を表示します。SFTPでは空の名前、`/`を含む名前、変更前と同じ名前、不正な権限表記を明示的に拒否します。
- 未保存の接続設定を破棄した場合は、確認前に選んだ接続先や移動先へ、そのまま操作を続けるよう修正しました。

## Workspace

- Workspaceの名前変更をブラウザー標準の入力画面から、セッション名と同じ一覧内の入力欄へ変更しました。Enterで確定、Escapeで破棄し、空の名前と変更前と同じ名前は保存しません。
- 保存レイアウトへ名前を付ける操作もsshcの画面内で行い、入力内容と保存・キャンセル操作を確認できるようにしました。

## PWA

- AndroidなどでインストールしたPWAのアイコンが真っ暗に表示される問題を修正しました。
- maskableアイコンを正本SVGから決定的に生成し、背景と中央のマークを自動テストで確認するようにしました。ManifestとService Workerも更新し、以前の壊れたアイコンがキャッシュへ残らないようにしています。

## 検証

- Goの全パッケージテスト、Webの1,102テスト、TypeScript、ESLint、production buildを実行しました。
- 接続編集、秘密鍵、Workspace、画面遷移、360px幅を含む影響範囲のE2E 69件を実Chromiumで確認しました。
