# sshc v0.16.2

ローカルシェルとSSH terminalの操作体系を揃え、画面全体を静かな灰色基調へ整理した更新です。

## 変更

- Workspace Command Centerから、接続中のSSH terminalとローカルシェルへ同じcommandを一括送信できるようにしました。
- 一括送信はpreview時のsession generationを固定し、再起動・再接続後の別processへ誤送信しないようにしました。
- 1 terminal時はWorkspace名、台数、一括送信、保存layoutを隠し、terminal名と検索だけを表示する簡潔な構成にしました。
- 接続設定の「基本」「設定解析」「詳細設定」と、その内容を同じ外枠へまとめ、親子関係を明確にしました。
- Config Explorerの左右headerを同じ高さへ揃え、接続summaryやeditorで欠けていた外周線を実borderで表示しました。
- 大きなsurface、control、小さな補助要素の角丸を12px、8px、6pxへ整理し、用途の異なる角が混在しないようにしました。
- 青みと強い境界線を抑えた黒・灰色中心のpaletteへ変更し、選択状態は輪郭ではなく面の差で示すようにしました。
- card外周、table区切り、input、buttonの境界色を用途別に分離し、必要な輪郭を残しながら主張を弱めました。
- ライト・ダーク、desktop・mobileについて、外枠、角丸、header高、詳細設定の表示を自動検査するようにしました。

接続・再接続・SFTP・認証などtransport固有の処理を除き、Workspace、検索、履歴、一括送信はローカルとSSHを同じterminalとして扱います。
