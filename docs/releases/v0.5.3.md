# sshc v0.5.3

スマートフォンでの操作性を改善したリリースです。

## 改善

- Keys の一覧を狭い画面では縦型にし、鍵の表示、ssh-agent への追加、その他の操作へ横スクロールなしで到達できるようにしました。
- Keys の作成フォームを狭い画面では一列にし、入力欄の幅を確保しました。
- Groups の未保存バーが編集内容を覆わないよう、スマートフォンでは通常の文書フローに配置しました。
- Sync の設定行を狭い画面では縦積みにし、Ad hoc checks の横スクロール表には操作案内を追加しました。
- Home、Connections、Config、Groups、Keys、Known Hosts、Install Key、Ad hoc checks、Secrets、Settings、Sync、History の主要操作を、スマートフォンでは40px以上の高さにしました。
- ページを移動したとき、前のページのスクロール位置を引き継がず、新しいページを先頭から表示するようにしました。

## インストール

```sh
brew install aida0710/tap/sshc
```

または:

```sh
curl -fsSL https://raw.githubusercontent.com/aida0710/sshc/main/install.sh | sh
```
