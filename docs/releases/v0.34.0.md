# sshc v0.34.0

v0.34.0では、SFTPでsshcエンジンが動いている端末のファイルを「ローカル」として開き、SSHホストとの間で直接転送できるようにしました。

あわせて、ローカルとリモートのパスバーで絶対パスのコピーと直接入力ができるようにし、ローカル側の操作ボタンをリモートと同じ構成に揃えています。

## SFTPのローカル

- 接続先メニューの先頭に**「ローカル」を固定表示**しました。左右どちらのペインでも、SSHホストと同じ操作で選べます。
- ローカルは、ブラウザを開いているPCではなく、sshcエンジンが動いている端末のファイル一覧です。初期位置はエンジンを実行しているユーザーのホームディレクトリで、OSの権限が許す範囲でルートまで移動できます。ブラウザにフォルダの権限を与える必要はありません。
- 選んだローカルのタブと表示中のパスは、ブラウザを閉じても他のタブと同じように復元します。
- ローカルとSSHホストを左右に並べると、選択したファイルやディレクトリのアップロード・ダウンロード、リモートからローカルへのドロップを転送マネージャーのキューに登録します。転送はエンジンが直接行い、ディレクトリは階層のまま扱います。宛先に同じ名前のファイルやディレクトリがすでにある場合は上書きせず、その転送は失敗として記録します。
- ローカルを選んでいないペインでのダウンロードは、これまでどおりブラウザのダウンロードです。

## SFTPのパスバーと操作

- ローカル・リモートの両方で、パスバーの空白をクリックすると絶対パスを直接入力できるようにしました。ローカルでは`~/`から始まるパスも使えます。
- 現在のフォルダの絶対パスをコピーするボタンを追加しました。モバイルのリモート側では操作メニューからもコピーできます。
- ローカルの戻る・進む・ホーム・ルート・更新のボタンをリモートと同じ配置にしました。一覧の先頭には`..`行を表示し、行ごとのチェックボックスで複数選択できます。モバイルでは操作シートから、進む・ホーム・ルート・パスのコピーと編集を行います。
- ローカルのタブは、別のタブを表示している間も一覧と戻る・進むの履歴を保持します。

## 更新後
