# sshc v0.60.1

v0.60.1では、すべてのページの見た目の崩れを修正しました。長い名前や狭い幅で、文字やボタンが切れる、重なる、画面の外へ出る箇所を直しています。

あわせて、Androidの戻るボタンの動き、スマホの警告アイコンとコマンド検索、回線が戻ったときの再接続を改善しています。

## スマホの操作

- これまでは、ターミナルの検索欄、SFTPの絞り込み、複数選択、パスの編集を開いたままAndroidの戻るボタンを押すと、Homeへ移っていました。**戻るボタンは、開いているこれらを先に閉じる**ように変更しました。
- これまでは、警告アイコンを開くと、同じ知らせとボタンが上の帯と枠に2つずつ出ていました。スマホでは、枠が伝えている内容を帯に出さないようにしました。
- コマンド検索は、スマホで押せないキーを案内しないようにしました。下の案内は「user@hostと入力すると接続できます」だけになり、Escの印は閉じるボタンに替わりました。
- ターミナルの「…」のメニューは、低い画面や横向きで下の項目に届きませんでした。画面に収めて、スクロールできるようにしました。
- クイックコマンドの枠が上のバーに重ならないようにしました。キーボードが開いているときも、画面に収まります。
- ターミナルの検索欄の正規表現の誤りは、ボタン1つ分の幅に詰めず、ボタンの下の行に出します。
- セッション名の変更中は「…」と×を隠し、入力欄を広くしました。
- セッションが無い画面の最後のタイルが、低い画面で下のバーに隠れないようにしました。

## SFTP

- これまでは、縦長の画像と動画のプレビューが枠からはみ出し、下が切れていました。**縦長でも画面に収まる**ように修正しました。スマホで拡大のバーが［ダウンロード］に重なっていたのも直しました。
- スマホのフォルダの比較は、差分の列が画面の外に出ていました。サイズを名前の下に置き、横にスクロールせずに読めるようにしました。
- 比較するタブの選択は、同じ親フォルダの下の2つのタブを見分けられませんでした。フォルダ名を先に出します。
- エディタの［閉じる］と、PCの選択中の帯の［名前変更］が途中で折れないようにしました。エディタの見出しには、ファイル名が見えるようにパスの末尾を出します。
- スマホのプレビューの見出しが、明るい画像の上でも読めるようにしました。
- 転送マネージャーの要約が右で切れないようにしました。複数の項目をまとめて転送したときの見出しが英語の「3 items」になっていたのも、「3件の項目」に直しました。

## 接続先と設定のページ

- Connectionsは、幅1280px未満のウィンドウでグループの列を出さず、一覧の上の［グループ］のボタンから選ぶように変更しました。幅1024pxのウィンドウで接続先の編集に170pxほどしか残らず、接続名が読めなかったためです。この幅では接続先をグループへドラッグできないので、［グループへ移動…］を使ってください。
- 接続先の［最終的な値］と［Diagnostics］の参照元の表は、狭いときは読み込み元と状態を値の下に出します。横にスクロールする必要はなくなりました。
- ［Diagnostics］は、検査の結果を設定ファイルの一覧より上に出すように変更しました。
- ［History］は、長いファイル名のボタンが列を占めて変更の名前が1文字ずつ縦に並んでいました。ボタンの列を幅の40%までにして、ファイル名を折り返します。「Vaultを復元」した記録は「Vaultの変更」と表示します。
- ［Machines］は、幅1024pxのウィンドウでプリセット名が1文字になっていました。一覧の幅が足りないときは、1台ごとに縦に並べます。
- ［Known Hosts］の鍵の種類が途中で折れないようにしました。スマホのスキャン候補は、はみ出さないように行の形で出します。
- グループの枠は、下の［色］や［その他の設定］に届くようにしました。
- スマホで、チェックボックスの下の余白をそろえ、色の入力を44pxの高さにしました。
- 「tmuxで開く」のチェックボックスを、名前と同じ行に置きました。
- Androidのアプリの［VPN］は、説明だけを出します。Dockerの案内と追加のフォームは出しません。同期で届いたプロファイルがあれば、一覧を出します。

## エラーと言葉

- これまでは、一部のエラーに内部の記号がそのまま出ていました（「要求が拒否されました（…）」など）。分かる言葉の文だけを出すように変更しました。履歴を読み込めなかったときは、「履歴を読み込めませんでした」と出します。
- 「つながっている」「つなぎ直す」を、画面、接続のログ、ドキュメントで「接続」「再接続」にそろえました。
- 入力欄の案内が欄の幅で切れないように、いくつかの文を短くしました。［SSH Keys］の検索の案内は「ファイル名や接続先で検索」、「接続先を選択」の案内は「名前、グループ、ホスト名で検索」になりましたが、検索できる対象は変わりません。
- Androidのアプリの「接続先を選択」で、ローカルの説明を「sshcエンジン側」から「このデバイス」に変更しました。

## 再接続

- Androidのアプリで、再接続を待ち始める瞬間に回線が戻ると、その知らせを取りこぼし、待ち時間（既定で最大40秒）の最後まで再接続しないことがありました。**回線が戻ったらすぐ再接続する**ように修正しました。
