# sshc v0.47.2

v0.47.2では、起動してマスターパスワードを解除し、すぐ接続したときに、ターミナルの下の行が隠れる問題を修正しました。

あわせて、Web画面から更新したときのお知らせの出し方と、説明書を改善しています。

## ターミナル

- これまでは、JetBrains Monoなどのフォントを使っていると、起動直後に開いたターミナルの行数が、フォントを読み込む前の文字の大きさで決まることがありました。そのため下の数行が枠の外に隠れ、ウィンドウの大きさを変えるまで直りませんでした。**フォントを読み込んで文字の大きさが変わったら、ターミナルの行数と列数を合わせ直す**ように修正しました。

## Web画面からの更新

- これまでは、Web画面から更新した結果（「〜へ更新しました」など）が、サイドバーのバージョンの下に残り続けていました。Homebrewなど別の方法で更新したあとも、古いバージョンへの更新のお知らせが表示されていました。**更新中の進み具合と結果は、ダイアログで表示する**ように変更しました。結果は1回の更新につき1回だけ表示し、閉じたあとは表示しません。
- バージョンの下に表示するのは、新しいバージョンのお知らせと［sshcを更新］、Web画面から更新できない場合の理由だけにしました。バージョンの横の印で折りたためます。折りたたんだお知らせは、さらに新しいバージョンが公開されるまで閉じたままです。

## 説明書

- 同期がエンドツーエンド暗号化（E2EE）であることを、ホームページ、同期のページ、セキュリティのページ、READMEに明記しました。復号できるのは同じ同期キーを設定したマシンだけで、暗号化にはAES-256-GCM、鍵の導出にはArgon2idを使います。
- 説明書を現在の動作に合わせました。セッション一覧の進み具合、Homebrew版のWeb画面からの更新、Androidのフォルダのアップロードの上限などを追記・修正し、英語版のボタン名を画面の表示に揃えました。
