# sshc v0.39.5

v0.39.5では、接続に失敗したときの接続ログを読みやすくしました。これまでは、失敗の理由や元のエラーが接続ログに何度も並び、VPNのコンテナイメージの作成に失敗した場合は、`docker build`の出力が階段状に崩れて表示されていました。

## 接続ログ

- **失敗の理由は、最後の`sshc:`の行にだけ表示するようにしました。** `[sshc][debug1]`の行には、どの段階で失敗したか（「接続に失敗しました。」など）だけを表示します。
- VPN経路の起動に失敗したとき、元のエラーを「失敗の詳細」の1か所にだけ表示するようにしました。VPN画面の「ログ」と`sshc vpn logs <名前>`にも1回だけ残ります。
- VPNのコンテナイメージの作成に失敗したとき、`docker build`の出力を1回だけ表示するようにしました。エラーの文には、失敗の要点の1行（`ERROR: failed to build …`）だけを表示します。
- 複数行にわたる出力が、ターミナルで階段状に崩れていた問題を直しました。
- 日本語と値のあいだの空白をそろえました。VPNプロファイル、コンテナ、コンテナイメージの名前は「」で括ります（例: `VPN経路「tohoku-univ」を起動します`）。括弧の中の項目と値は「：」で区切ります（例: `インターフェース：ppp0`）。`sshc vpn logs <名前>`のようなコマンドの前後の空白はそのまま残しています。

## 更新後に必要な操作

更新後はengineを再起動してください。VPN機能を使用している場合、次にVPNへ接続するときに、新しいコンテナイメージをマシン上で作成します。作成にはネットワークが必要です。
