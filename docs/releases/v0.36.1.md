# sshc v0.36.1

v0.36.1は、SFTPの2つの不具合を直す修正リリースです。

## SFTP

- **engine側ディスク（Local）のペインから行をドラッグできなかった問題を直しました。** v0.35.0でLocalとリモートのペインを統合したときにLocalの行から`draggable`が外れ、ホストのペインへドラッグしようとすると文字の範囲選択になっていました。ドロップ先はこの経路（engineによるput）を受け付けていたので、行にも`draggable`を付けています。
- **狭いペインでも一覧の列を減らさなくなりました。** 2ペインでそれぞれが680pxを下回ると、v0.36.0では名前・サイズ・日付だけの1行の一覧に、それ以前はスマートフォン向けの高い2行の一覧に切り替えて、更新日時・種類・権限の列を落としていました。ポインター操作のデスクトップでは幅に関わらずテーブルのままにし、一覧の枠を横にスクロールして見ます。2行の一覧はスマートフォンだけに残しています。

## 更新後に必要な操作

v0.36.0から更新する場合、追加の操作はありません。v0.35.0以前から更新する場合は、[v0.36.0のリリースノート](v0.36.0.md)にあるブラウザーの再登録とengineの再起動が必要です。
