# クイック接続へのグループブラウザー移設

## 背景と目的

接続画面へ追加した「サーバー／グループ」切り替えと、一段ずつグループを辿るブラウザーは、接続先を探して起動する用途には向いている。一方、接続画面の主目的は設定の確認と編集であり、階層を一段ずつ移動すると一覧性と移動操作の発見性が下がる。

そこで、接続画面は変更前の常時展開ツリーへ戻し、サーバー／グループを選んで接続先を探す機能をホームの「クイック接続」へ移す。クイック接続の既定表示はサーバー一覧とする。

## 接続画面

- 左ペインは、変更前と同じ「グループ別／ファイル別」の常時展開ツリーに戻す。
- グループ別では宣言済みの階層、直下の接続、未分類を同時に表示する。子グループは折りたためるが、初期状態は展開する。
- ファイル別では読み込み元ファイルごとに接続とパターンルールを表示する。
- 検索、お気に入り絞り込み、色、タグ、選択中表示を維持する。
- 接続とグループのドラッグ移動を維持し、編集中または保存後の再確認中は無効にする。
- alias を持たないパターンルールは接続詳細ではなく設定ファイルの該当行を開く。
- 接続詳細、保存、認証、診断、管理操作は変更しない。

接続の canonical URL は現在の `/connections/servers` と接続 identity query を維持する。今回変えるのは左ペインの表示責務であり、URL・履歴・接続詳細の契約まで戻す必要はない。既存の `/connections/groups/...` を新たな導線から生成しないが、ルーターから積極的に削除する作業も本変更には含めない。

## ホームのクイック接続

- クイック接続の先頭に「サーバー／グループ」の segmented control を置く。
- 初期表示はサーバーで、具体的な alias を持つ全接続を従来どおりカード表示する。
- グループ表示のルートではトップレベルの宣言済みグループと、必要な場合だけ未分類を表示する。
- グループを選ぶと、その直下の子グループと直下のサーバーへ内容を置き換える。
- パンくずでグループルートまたは親へ戻れる。
- 空の宣言済みグループ、存在しないグループ、検索結果ゼロを区別して表示する。
- 検索中は現在のグループ以下を再帰検索し、該当サーバーをカード表示する。サーバー表示では全接続を検索する。
- お気に入り絞り込みを利用できる。
- 各サーバーカードは既存の `…` メニューを維持し、「接続設定を開く」と「接続」を分ける。
- 表示切り替え、検索、グループ移動だけでは Terminal、SSH、診断、`ssh -G` を開始しない。
- グループ位置、検索、お気に入り絞り込みはホーム内の一時状態とし、URL・localStorage・metadata へ保存しない。

## コンポーネント境界

- `connectionBrowser.ts` は overview から装飾済みサーバーとグループ階層を作る純粋な index／projection として、クイック接続から再利用する。
- `OverviewPanel` はクイック接続の一時的なブラウザー位置、検索、カード操作を所有する。
- `ConnectionTree` は接続管理専用の展開ツリーとドラッグ操作を所有する。クイック接続からは使わない。
- `ConnectionsPage` は固定の管理ツリーと、現在の接続 URL／detail state を調停する。

閲覧用コンポーネントをそのまま共有しない。接続画面のドラッグ移動をホームへ持ち込むと、起動導線の中で設定ファイルを書き換えられてしまい、画面責務が再び混ざるためである。共有するのは副作用のない射影ロジックだけとする。

## エラーと安全境界

- overview 読み込み失敗は、従来どおりホーム上のエラーとして表示する。
- Terminal 起動失敗は対象 alias を含む既存のエラーを表示する。
- クイック接続は具体的 alias だけを対象にし、パターンルールを起動対象へ混ぜない。
- 重複 alias は保存元 path を表示して識別できるようにする。ただし Terminal 起動 API の既存 alias 契約は変えない。
- 秘密、下書き、検索文字列を URL、DOM の隠し値、永続ストレージへ追加しない。
- API、SSH config、vault、認証情報モデルは変更しない。

## テスト

- `ConnectionTree` のグループ／ファイル表示、パターンルール、検索、お気に入り、ドラッグ無効化を component test で固定する。
- `OverviewPanel` の既定サーバー表示、グループのドリルダウン、パンくず、検索、お気に入り、空状態、`…` メニューを component test で固定する。
- `ConnectionsPage` がサーバー／グループ切り替えを表示せず、展開ツリーから接続を開くことを component test で固定する。
- E2E ではホームのクイック接続でグループを辿っても通信せず、明示的な「接続」だけが Terminal を起動することを確認する。
- 接続画面の旧グループドリルダウン E2E は、管理ツリーの展開・選択・移動契約へ置き換える。
- 最後に Web unit、TypeScript、production build、Playwright、生成 API、Go normal／race、Docker 統合を実行する。

## 非目標

- スマートフォン専用画面
- クイック接続からのドラッグ移動
- クイック接続状態の URL 化または永続化
- 接続ルート全体の再設計
- サーバー API、SSH 設定形式、秘密情報モデルの変更
- 新しい依存パッケージの追加
