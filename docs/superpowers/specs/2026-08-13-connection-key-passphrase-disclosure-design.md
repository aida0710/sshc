# 接続画面の鍵パスフレーズ折りたたみ設計

## 目的

接続の「認証」に常時表示されている鍵パスフレーズ入力欄を、必要なときだけ開く「鍵パスフレーズを保存、修正」セクションへまとめる。

## 挙動

- 選択中の暗号化秘密鍵に専用または共有の保存済みパスフレーズがある場合、初期状態は閉じる。
- 保存済みパスフレーズがない場合、初期状態は開く。
- 見出しを操作すると開閉でき、開いた中には現在の保存状態、2つの入力欄、補足、検証エラーを表示する。
- 接続または選択鍵が変わった場合は、新しい鍵の保存状態から初期状態を決め直す。
- 保存API、秘密値の保持・消去、共有値から鍵専用値へ付け替える意味は変更しない。
- 未暗号化鍵、独自パス、複数鍵の場合は従来どおり編集セクションを表示しない。

## 実装

`ConnectionBasicForm` の既存エディタを native `<details>` で囲み、React state で開閉を管理する。資格情報を読み終えた後、選択鍵または保存状態が変わったときだけ「専用・共有のどちらもない」なら開くよう初期化する。ユーザーが同じ対象を手動で開閉した状態は、通常の再描画では維持する。

## 検証

- コンポーネントテストで未保存は開、共有・専用は閉を確認する。
- 閉じた保存済みセクションを手動で開き、既存の保存更新フローが操作可能であることを確認する。
- 接続画面の該当E2Eを、新しい開閉操作を含む利用手順へ更新する。
