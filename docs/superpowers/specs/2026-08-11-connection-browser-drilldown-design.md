# 接続ブラウザーのサーバー／グループ導線

## 目的

接続先が増えても、利用者が「すべてのサーバーから直接探す」か「グループを段階的に辿って探す」かを最初に選べる接続ブラウザーにする。

現在の左ペインは、同じ接続ツリーをグループまたは保存ファイルで並べ替える。グループは最初からサーバーと一緒に展開されるため、グループを選んで対象を絞る導線にはなっていない。本変更では既定を全サーバーのフラット一覧とし、必要なときだけグループ階層へ入る。

一人で利用しているアプリケーションであり、既存の接続 URL や旧六タブ URL の後方互換は維持しない。新しい情報設計に合わせて URL も置き換える。

この URL 方針は、`2026-08-11-connection-summary-editor-design.md` の「URL 互換」を置き換える。保存済み概要、認証、下書き境界など、それ以外の設計は引き続き有効である。

## 採用する構成

左ペイン上部に `サーバー｜グループ` の segmented control を置く。既定はサーバーである。

- サーバーは、具体的な alias を持つ全接続先をグループ階層なしで表示する。
- グループは、最初にトップレベルグループだけを表示し、選択後に子グループと直下のサーバーへ表示を置き換える。
- 右ペインの接続詳細は現在のまま保つ。ブラウザーの表示方式やグループ位置を変えても、選択中の接続自体は変えない。
- 現在のファイル別表示は接続ブラウザーから削除する。保存ファイルや具体的なパターンルールの確認は既存のファイル画面で行う。

二列のグループ／サーバー master-detail は採用しない。現在の 19rem の左ペインでは両列が狭くなり、右の接続詳細まで圧迫するためである。現在の展開式ツリーも採用しない。階層全体は一度に見えるが、「グループを選んで対象を絞る」という目的を満たさない。

## サーバー表示

`/connections/servers` は接続画面の既定表示である。

- 具体的な alias を持つ全接続先を一つのフラット一覧にする。
- 各行は alias を主表示にし、所属グループがあれば補助表示する。
- 同じ alias が複数ファイルに存在する場合は、保存元の相対パスも表示して identity を区別する。
- 並び順は既存の host metadata の `order` を維持し、同順位は overview の順序を保つ。
- お気に入り絞り込み、色、タグの表示を維持する。
- 検索対象は alias、パターン、タグ、所属グループである。
- 接続を選んでもサーバー表示のままにする。
- グループの移動先が画面に無いため、この表示ではドラッグ移動を開始しない。任意グループへの移動は接続詳細の管理操作を使う。

具体的な接続先ではない `Host *`、否定パターン、複合パターンなどはサーバー一覧へ混ぜない。それらは既存のファイル画面から編集する。

## グループ表示

### ルート

`/connections/groups` はトップレベルの宣言済みグループを表示する。

- グループ行は名前と配下にある具体的な接続先の総数を表示する。
- 空の宣言済みグループも表示する。空であること自体が有効な設定状態だからである。
- どのグループにも属さない接続がある場合は「未分類」を表示する。
- 「未分類」は実グループではないため、名前付きグループと衝突しない専用 URL を使う。

### 名前付きグループ

`/connections/groups/home/eu` のように、グループ名の各要素を URL path segment として表す。

選択したグループでは、次の順で表示する。

1. 現在位置を示すパンくずと一段戻る操作
2. 直下の子グループ
3. 現在のグループに直接属するサーバー

子グループを選ぶと同じ左ペインの内容を置き換える。親グループ配下の全サーバーを通常時に平坦化しない。所属階層を辿る操作を残すためである。

### 未分類

`/connections/groups?scope=ungrouped` は、どのグループにも属さないサーバーだけを表示する。`scope=ungrouped` と名前付きグループ path が同時に指定された URL は不正として扱う。

### 非表示コンテナ

既存の hidden group の安全境界を維持する。

- 直下サーバーを持たない hidden group は一覧へ出さず、その可視の子孫を最も近い可視の親へ昇格して表示する。
- 直下サーバーを持つ hidden group は隠さない。手編集された metadata のために接続先が到達不能になる方が危険だからである。

## 検索とお気に入り

検索文字列とお気に入り絞り込みは一時的な表示状態であり、URL や永続ストレージへ保存しない。

- サーバー表示では全接続先を検索する。
- グループ表示で検索文字列が空なら、子グループと直下サーバーだけを表示する。
- グループ表示で検索中は、現在位置以下を再帰検索し、該当するサーバーを平坦な検索結果として表示する。
- 検索結果には所属グループの完全な path を添え、通常の階層表示と区別する。
- グループ path 自体も検索対象に含める。その path に属するサーバーが結果になる。
- お気に入り絞り込み中は、お気に入りの直下サーバーと、お気に入りを子孫に持つグループだけを残す。
- 絞り込み結果が空なら、グループが存在しないとは言わず、現在の条件に一致しないことを表示する。

## URL

新しい canonical URL は次である。

```text
/connections/servers
/connections/groups
/connections/groups/home/eu
/connections/groups?scope=ungrouped
```

接続を選んだ場合は、ブラウザー位置を保ったまま query に接続 identity と右ペインを追加する。

```text
/connections/servers?path=config&host=bastion&panel=basic
/connections/groups/home/eu?path=connections%2Fhome%2Feu%2Fapp.conf&host=app&panel=advanced&advanced=raw
```

- `path` と `host` は常に組で指定する。alias は重複しうるため `host` だけでは identity にしない。
- `panel` は `basic`、`analysis`、`advanced` の三つだけである。
- `advanced` は `panel=advanced` の場合だけ `jump`、`directives`、`raw` を受け入れる。
- `/connections` は `/connections/servers` へ replace する。
- 旧 `/connections?...` の接続選択、旧 `tab=basic|diagnostics|effective|jump|advanced|raw` は引き継がない。
- 不明な path、欠けた identity、未知の panel、矛盾した query を推測で別状態へ直さない。URL が不正であることと、サーバー一覧へ戻る操作を表示する。
- 下書き、秘密値、検索文字列、確認結果、診断結果は URL と history state へ入れない。

トグル、グループ選択、パンくず、接続選択、右ペイン切り替えは通常の history entry を作る。Back、Forward、reload は同じブラウザー位置と接続詳細を復元する。

## 下書きとナビゲーション

ブラウザー位置と接続 identity は別の状態として扱う。

- サーバー／グループの切り替え、グループ移動、パンくず移動は、選択中の接続を変更しない。
- 同じ接続を開いたままブラウザー位置だけを変える場合、基本または詳細設定の下書きを保持し、破棄確認を出さない。
- 新しいサーバーを選ぶ場合だけ、既存の未保存変更ガードを使う。
- 破棄確認を拒否した場合は identity、右ペイン、URL を現在の接続へ戻し、下書きを保持する。
- 接続詳細が開いたまま、その接続を含まないグループへ移動することは許可する。右ペインは保存済みの選択を示し続け、左ペインには選択行が無いだけである。
- dirty または保存後の snapshot 再確認中は、接続・グループのドラッグ移動を無効化する。

## ドラッグ移動

グループ表示では、現在画面に存在する移動先に限ってドラッグを維持する。

- 直下サーバーは、表示中の子グループへ移動できる。
- 直下サーバーは、親パンくずへドロップして一段上のグループへ移動できる。
- 子グループは、表示中の兄弟グループへドロップして入れ子にできる。
- 子グループは、親パンくずへドロップして一段上へ出せる。
- 自分自身または自分の子孫への group drop は拒否する。
- 画面外の任意グループへ移動する操作はドラッグへ追加しない。接続詳細の「所属グループを変更」を使う。

保存が成功した時点で移動後の identity を URL の正本にする。後続の overview 読み込みに失敗しても、存在しなくなった旧 path を URL に残さない。

## コンポーネント境界とデータフロー

### 接続ルート

接続ルートの parser／formatter は、ブラウザー方式、グループ path、未分類 scope、接続 identity、panel を一つの型へ変換する。React component は query string を個別に解釈しない。

旧六タブの互換 mapper は削除し、三つの visible panel と advanced subview を直接表現する。

### 接続ブラウザー

現在の `ConnectionTree` は、次の責務を持つ接続ブラウザーへ置き換える。

- サーバー／グループの切り替え
- 検索とお気に入り絞り込み
- 一段分のグループ表示
- パンくず
- 接続選択
- 表示中の対象だけを使うドラッグ移動

右ペインの detail 取得、保存、接続、診断、管理操作は所有しない。

### グループインデックス

overview から一度だけ、次を持つ index を作る。

- identity ごとの装飾済みサーバー
- group ごとの直下サーバー
- group ごとの直下の可視子グループ
- group ごとの子孫サーバー総数
- group ごとのお気に入り子孫数

各描画で全グループと全サーバーの積を走査しない。overview 更新時に index を再構築し、通常の一段表示は現在位置の entry を読むだけにする。

### `ConnectionsPage`

`ConnectionsPage` は URL 由来のブラウザー位置と接続 identity、overview、選択済み detail、dirty state を調停する。

- ブラウザー位置の変更は detail を再取得しない。
- identity の変更だけが detail と安全な認証 metadata を再取得する。
- overview 更新後に現在のグループが消えても別グループを推測せず、missing group state にする。
- 接続 rename、move、delete の commit 後は、後続 GET を待たず新しい canonical identity または一覧 URL を確定する。

## エラーと空状態

- overview 読み込み失敗はブラウザー全体の再試行可能なエラーとして表示する。
- サーバーが一件も無い場合は、サーバー表示に接続作成の導線を出す。
- 宣言済みグループが無い場合は、グループ表示にグループ画面への導線を出す。
- 空グループは「サーバーなし」と表示し、存在しないグループと区別する。
- URL の名前付きグループが overview に存在しない場合は「グループが見つかりません」とグループルートへ戻る操作を表示する。
- 不正 URL は missing group と混ぜず、「この接続 URL は認識できません」とサーバー一覧へ戻る操作を表示する。
- 選択した接続だけを取得できない場合は、ブラウザーを残し、右ペインに既存の missing connection state を表示する。
- 検索結果ゼロ、データゼロ、読み込み失敗を同じ文言へ畳み込まない。

## テスト

### Pure unit

- 新 canonical URL の parse／format 往復
- `/connections` から既定サーバー URL への replace
- 名前付きグループ、未分類、接続 identity、三 panel、advanced subview
- 欠けた identity、未知の panel、矛盾した scope、不正な group segment の拒否
- 旧 `tab` URL を互換変換しないこと
- グループ index の直下／子孫、空、入れ子、hidden container、未分類、重複 alias
- metadata order、お気に入り子孫数、検索対象と安定した結果順

### Component

- 既定が全サーバーのフラット一覧であること
- サーバー行に所属グループと、必要な場合だけ保存元 path が見えること
- グループルートから親、子へドリルダウンできること
- パンくずで一段ずつ戻れること
- 通常時は直下だけ、検索時は子孫の一致を平坦表示すること
- 空グループ、未分類、missing group、不正 URL の空状態
- 同じ identity のままブラウザー位置を変えても detail 取得と dirty draft を維持すること
- 別 identity の選択だけを未保存ガードが止めること
- dirty／refreshing 中のドラッグ拒否
- サーバー、グループ、親パンくずへの許可された drop と、自己／子孫 drop の拒否

### End-to-end

- `/connections` が `/connections/servers` へ正規化され、全サーバーを表示する。
- サーバー／グループの切り替え、親、子、サーバー選択が URL に反映される。
- reload、Back、Forward がブラウザー位置と接続詳細を復元する。
- グループ位置を保ったまま接続詳細を開閉・切り替えできる。
- dirty draft のまま同じ identity で表示方式を変えられ、別接続への移動は確認される。
- 不明なグループ URL と不正 URL がそれぞれ正しい回復操作を出す。
- 接続ブラウザーを開く、検索する、グループを辿るだけでは、接続、診断、`ssh -G`、Terminal を開始しない。
- 旧 URL に依存する E2E を削除し、新 canonical URL のみを契約にする。

最終検証は Web unit、TypeScript、production build、全 Playwright、生成 API 整合性、Go normal／race、Docker-backed SeaweedFS／OpenSSH integration を含む。ビルド済み UI を更新し、全検証後に `main` へ push する。依存パッケージは追加しない。

## 非目標

- 旧接続 URL または旧六タブ URL の後方互換
- ファイル別表示を接続ブラウザーへ残すこと
- パターンルールをサーバーとして表示すること
- 左ペインを二列に分割すること
- スマートフォン専用 UI
- 検索文字列、お気に入り絞り込み、折りたたみ状態の永続化
- 画面外の任意グループへドラッグする新しい UI
- サーバー API、SSH config、vault、秘密情報モデルの変更
- 表示しただけで接続、診断、認証、`ssh -G` を開始すること
