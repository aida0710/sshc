# 文章と用語のガイド

このリポジトリのREADME、ドキュメント、コードコメント、CLI、Web UI、リリースノートには、同じ文体と用語を使用します。

## 基本方針

- 比喩よりも、実際に行う処理を記述します。
- 主語がなくても明確な文では、アプリケーションを擬人化しません。
- 強調は警告や重要な前提に限定し、段落全体を太字にしません。
- 実装の経緯は、現在の挙動を理解するために必要な場合だけ記載します。
- エラー文は、発生した事象、影響、利用者が行える対処の順に記述します。
- CLI（`sshc`のhelp、質問、状態、失敗の文）は英語で書きます。画面とpagesの日本語版、sshcエンジンのターミナルの接続ログは日本語で書きます。

## 推奨する用語

| 使用する表現 | 避ける表現 |
| --- | --- |
| URLを表示する | 入口を刷る |
| sshcエンジンを起動する | sshcエンジンを起こす |
| sshcエンジンを常駐させる | sshcエンジンを生かしておく |
| 実行ファイル、バイナリ、プロセス | 実体 |
| パス、名前、文字列 | 綴り |
| 値、結果、応答、認証情報 | 答え |
| 暗号化する | 封じる、封をする |
| SSH接続を確立する、SSHプロトコルを実装する | SSHを話す |
| 指定する、参照する、表示する | 名指しする |
| 検査、回帰テスト | 見張り |

コード内の識別子やOpenSSHの正式な用語は、既存の英語表記を維持します。日本語と英数字、インラインコードの間には、原則として空白を入れません。製品名の正式表記に空白が含まれる場合や、空白がないと読み違える場合だけ、その表記を維持します。

### sshcエンジンの呼び方

画面、pages、READMEの本文では「sshcエンジン」と書きます（2026-09-30に決定）。本文に`engine`、`Engine`、「エンジン」だけの形を混ぜません。画面とpages、READMEで呼び方を分けません。見出しと、`sshc engine`のようなコマンド名はそのまま書きます。

画面、Androidの文言、日本語のpages、READMEの本文に「sshcエンジン」でない「エンジン」があると、`web/src/i18n/retiredJapaneseTerms.test.ts`が失敗します。Markdownの見出しとページの`title`は検査しません。

リリースノートは、製品画面やコマンドに合わせて`engine`と書く従来の決まりのままです。この決定では変えていません。

### 画面の文言の書き方

- 失敗の文は、何が失敗したかを先に書きます。例:「VPNの接続に失敗しました。ハンドシェイクに失敗しました。鍵とサーバーの指定を確認してください。」前置きの文には何の操作が失敗したかを書きます。理由の文には、どの段階で失敗したかと、確認してほしいことを書きます。理由の文で前置きの内容を繰り返しません。
- 「〜に失敗しました」「〜できません」「〜してください」「〜を指定してください」を使います。「〜である必要があります」（must be）の直訳は使いません。
- 擬人化しません。「サーバーが尋ねてくる」は「サーバーが要求する」、「ホスト鍵アルゴリズムを名乗る」は「提示する」と書きます。
- 「その〜」で何を指すか分からない文にしません。「指定した〜」にするか、主語を書きます。
- 1文に項目を詰め込みません。3つ以上の仕様が並ぶ説明は箇条書きにします。
- 画面の文言を変えたら、pagesの［…］と「…」の引用も同じ変更で直します。`web/src/i18n/pagesQuotedLabels.test.ts`が、引用が今の画面の文言と一致するかを検査します。

## CLIに出る文の言語

CLIが自分で組み立てる文は英語で書きます。help、質問、状態の表示、失敗の文が当たります。sshcエンジンやVPNに断られたときにCLIが出す文も、CLIが組み立てるので英語です。

接続ログは、画面のターミナル、`sshc vpn logs`、`sshc ssh`の出力が同じ文を出します。`sshc ssh`に出るときも、画面と同じ日本語で書きます。

- SSH接続の段階を示す行（`internal/sshclient`が書く、接続先、認証の結果など）
- `sshc ssh`の出力に写すsshcエンジンの記録（「== sshcエンジンの記録 ==」から始まる部分）
- VPNの段階の知らせ
- agent転送の行

接続ログを英語と日本語の両方で出すには、すべての行を言語ごとに持つ作りが要ります。3つの出力先が同じ文を共有しているので、接続ログは日本語の1つにそろえます。
