# OS icons

Vendored from [Devicon](https://github.com/devicons/devicon/tree/7330accdbc47e2dc0c19789a48533c4a3c50fe58/icons) at `7330accdbc47e2dc0c19789a48533c4a3c50fe58`. Plain SVGs where available (Ubuntu, Debian, Red Hat, Fedora, CentOS, AlmaLinux, Arch Linux, Linux), otherwise original SVGs; line endings normalized. Rendered as monochrome CSS masks; MIT license in [LICENSE](LICENSE). Logos identify their respective operating systems; brand rights remain with their owners.

Alpine uses the Linux family icon; FreeBSD currently uses the generic server icon.
