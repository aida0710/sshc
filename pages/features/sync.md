# 暗号化同期

![同期の状態と変更確認画面](/images/sync-desktop.png)

sshcは同期用のクラウドストレージを提供せず、同期データを預かりません。利用者が用意したS3互換オブジェクトストレージを同期先として使います。同期対象のデータは端末上で暗号化し、スナップショットとして保存するため、ストレージ事業者へ平文が送られることはありません。

## 最初の端末を設定する

1. バケット、エンドポイント、アクセスキーを入力する
2. 接続テストを完了する
3. 保存先が空なら同期キーを生成する
4. 一度だけ表示される同期キーを安全な場所へ保管する

## 別の端末を追加する

同じバケット内のパスと同期キーを入力します。リモートに既存のスナップショットがある場合は、正しいキーで復号できたことを確認してから設定を保存します。データを分けたい場合は、バケット内のパスを変更してください。

同期方向は、送受信、送信専用、受信専用から選べます。追加した端末を閲覧用にするなら、受信専用が適しています。

## Gitに似た同期操作

- **変更を確認**: ローカルとリモートの差分を事前に確認
- **Push**: 確認したリモートのリビジョンに対して条件付きで送信
- **Pull**: 競合や削除がなければ適用
- **Force**: 事前に確認したETagとリビジョンにだけ適用
- **履歴**: バケット内の過去のスナップショットを表示

自動同期は1分ごとにリモートの更新だけを確認します。sshcで設定を変更すると、最後の変更から5秒後に1回だけPushし、同じスナップショットを繰り返しアップロードしません。

::: warning 同期キー
マスターパスワードは端末ごとに異なって構いません。一方、同じ保存先を使う端末には、共通の同期キーが必要です。同期キーを紛失すると、リモートのスナップショットを復号できません。
:::

競合の扱いや履歴については、[Push・Pull・履歴](/sync/workflow)で詳しく説明しています。
