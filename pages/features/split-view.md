# 分割表示

SSHとローカルシェルのセッションを、最大4ペインに並べて操作できます。同じ実行先で開いているセッションなら、別のワークスペースからも選べます。

## セッションを並べる

1. セッションを2つ以上開きます。
2. サイドバーのセッションを、表示中のターミナルの上下左右へドラッグします。
3. 色が付いた領域にドロップすると、その位置にペインが増えます。

ターミナルの見出しやサイドバーのセッションの［…］から［右に分割して表示］または［下に分割して表示］を選ぶこともできます。見出しのメニューでは、続けて並べるセッションを選びます。選んでいるペインを基準に分割します。サイドバーのワークスペースへドロップした場合は、これまでどおりセッションの所属を移します。

## 分割を切り替える

セッションを1つだけ表示している状態から分割すると、サイドバーの **Split views** に「分割 1」「分割 2」…が増えます。最大8グループ、各4ペインまで作れます。番号は作成順で、解除しても詰めません。分割を表示中にペインを追加すると、そのグループに入ります。

グループの行を選ぶと、その分割を表示します。行の下には並べているセッション名が出て、左の矢印で開閉できます。ワークスペースの木にも、セッション名の横に分割のアイコンと番号が付きます。

グループ内のセッションをサイドバーで選ぶと、その分割を表示してペインにフォーカスします。どのグループにも入っていないセッションを選ぶと、そのセッションだけを表示します。グループは残るため、Split views の行から戻れます。

セッションが入れるグループは1つだけです。別のグループへ追加すると元のグループから外れ、残りが1ペインになると元のグループは解除されます。ワークスペースの所属は変わりません。

## ペインを操作する

| 操作 | 方法 |
| --- | --- |
| 大きさを変える | 仕切りをドラッグ。仕切りを選択して矢印キーでも調整できます。比率は10〜90%です |
| 入れ替える | 見出しの入れ替えボタンを相手のペインへドラッグ。または、両方のペインの入れ替えボタンを順に選択します |
| 1つを大きく表示する | 見出しのフォーカス表示ボタンを選択。［分割表示に戻る］かEscで元に戻ります |
| ペインを閉じる | 見出しの［<セッション名>のペインを閉じる］を選択。セッションは終了せず、サイドバーに残ります |
| 別のペインを選ぶ | ペインをクリック、またはサイドバーでそのセッションを選択。ターミナル内ではCtrl+Alt+←／→でも移れます |

選んでいるペインには色付きの枠が付きます。グループの［解除］、またはペインを閉じて残りが1つになったときに、グループは無くなります。どちらもセッション自体は終了しません。セッションが終了・削除されたときもペインから外れ、残りが1つ以下になったグループは解除されます。

## モバイルと保存

モバイル幅ではペインを1つずつ表示します。分割表示中に画面を狭くした場合は、上部のセッション名で切り替えられます。サイドバーの Split views からグループも切り替えられます。画面を広げると分割表示に戻ります。

グループと配置は、サーバーにもブラウザにも保存しません。ブラウザのタブを再読み込みするか、実行先を切り替えると、分割は解除されます。

セッションのまとめ方については[ワークスペース](./workspace)を参照してください。
