# 分割表示

SSHとローカルシェルのセッションを、最大4ペインに並べて操作できます。同じsshcエンジンで動いているセッションなら、別のワークスペースからも選べます。

## セッションを並べる

1. セッションを開きます。
2. サイドバーのセッションを、表示中のターミナルの上下左右へドラッグします。
3. 色が付いた領域にドロップすると、その位置にペインが増えます。

ターミナルのヘッダーやサイドバーのセッションの［…］から［右に分割して表示］または［下に分割して表示］を選ぶこともできます。ヘッダーのメニューでは、続けて並べるセッションを選びます。［新しいセッション］を選ぶと、今のセッションの複製、ローカルシェル、ほかの接続先から選んで新しいペインに開きます。並べるセッションが無いときは、最初からこの選択を開きます。選んでいるペインを基準に分割します。

ペインを足すと、同じ向きに並んだペインを同じ幅（下に足したときは同じ高さ）に割り直します。足すとどれかのペインが最小の大きさ（ヘッダーのボタンが収まる幅、ヘッダーとターミナルの1行が収まる高さ）を下回る側には足せず、その項目は選択できません。

［Settings］→［Keyboard shortcuts］の［右に分割］［下に分割］にキーを割り当てると、同じ選択をキーで開けます（既定は未設定です）。

サイドバーのワークスペースへドロップした場合は、これまでどおりセッションの所属を移します。

## 分割を切り替える

セッションを1つだけ表示している状態から分割すると、サイドバーの**Split views**に「分割 1」「分割 2」…が増えます。最大8つ、各4ペインまで作れます。番号は作成順で、解除しても詰めません。分割を表示中にペインを追加すると、その分割に入ります。

分割の行を選ぶと、その分割を表示します。行の左の小さな図はペインの並び方を、右の数字は入っているセッションの数を表します。行の下には、入っているセッションを1つずつ、状態の点と名前、その下に接続先で出します。セッションの行を選ぶと、その分割を表示してそのペインにフォーカスします。サイドバーのワークスペースでも、分割に入っているセッションの名前の横に、そのセッションが分割のどの位置にいるかを小さな図で示します。

分割に入っているセッションをサイドバーで選ぶと、その分割を表示してペインにフォーカスします。どの分割にも入っていないセッションを選ぶと、そのセッションだけを表示します。分割は残るため、Split viewsの行から戻れます。

セッションが入れる分割は1つだけです。別の分割へ追加すると元の分割から外れ、残りが1ペインになると元の分割は解除されます。ワークスペースの所属は変わりません。

## ペインを操作する

| 操作 | 方法 |
| --- | --- |
| 大きさを変える | 仕切りをドラッグ。仕切りを選択して矢印キーでも調整できます。比率は10〜90%で、ペインはヘッダーとターミナルの1行、ヘッダーのボタンが収まる幅より小さくなりません。画面を狭くしたときも、すべてのペインが収まる間はこの大きさを保ちます |
| 入れ替える・移す | ヘッダーの名前の部分を相手のペインの中央へドラッグすると入れ替え、端の近くへドラッグするとその側へ移します。タッチで操作する画面では、名前の文字を選べるように、ヘッダーはドラッグできません。サイドバーのSplit viewsのセッションの行も、ペインの端へドラッグして移せます。ヘッダーの［…］→［ペインを移動］を選んでから、相手のペインの［…］→［ここと入れ替える］を選んでも入れ替えられます |
| 1つを集中表示する | ヘッダーの［…］→［集中表示］を選択。集中表示の間はヘッダーに出る［集中表示をやめる］か、Escで元に戻ります |
| 分割表示から外す | ヘッダーの［<セッション名>を分割表示から外す］（×）、またはターミナルの［…］かサイドバーのセッションの行の［…］→［分割表示から外す］を選択。セッションは終了せず、サイドバーに残ります。モバイル幅ではターミナルの［…］から外せます |
| 別のペインを選ぶ | ペインをクリック、またはサイドバーでそのセッションを選択。ターミナル内ではCtrl+Alt+←／→でも移れます |

選んでいるペインには色付きの枠が付きます。分割の行の［…］→［解除］、または分割表示から外して残りが1つになったときに、分割は無くなります。どちらもセッション自体は終了しません。セッションが終了・削除されたときもペインから外れ、残りが1つ以下になった分割は解除されます。

## モバイルと保存

モバイル幅ではペインを1つずつ表示します。分割表示中に画面を狭くした場合は、上部のセッション名で切り替えられます。サイドバーのSplit viewsから分割も切り替えられます。画面を広げると分割表示に戻ります。

分割と配置は、サーバーにもブラウザにも保存しません。ブラウザのタブを再読み込みすると、分割は解除されます。リモートセッションのsshcエンジンを切り替えても、分割は解除されません。sshcエンジンごとに覚えていて、戻ると元の分割を表示します。

セッションのまとめ方については[ワークスペース](./workspace)を参照してください。
