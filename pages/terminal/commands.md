# クイックコマンドとスニペット

クイックコマンドは、Terminalのオーバーフローメニューから開きます。保存済みのスニペットを現在のペインへ挿入し、そのまま実行またはコピーできます。

![Terminalのクイックコマンドメニュー](/images/terminal-actions.png)

## Snippetを作る

MenuのSnippetsで、名前、コマンド、変数を保存します。シークレット変数は通常の変数と分けて扱い、スニペットライブラリそのものもVaultのマスターキーで暗号化します。

## 実行前に確認する

実行前には、対象のエイリアス、展開後のコマンド、必要な入力が表示されます。確認後にセッションのプロセスが入れ替わった場合は送信を拒否し、別のプロセスへ誤送信しないようにします。

## ワークスペースへ一括送信

2ペイン以上のワークスペースでは、コマンドの一括送信画面を開き、その場で入力したコマンドまたはスニペットを選べます。送信先と内容を確認してから、各PTYへコマンドとEnterを送ります。SSHとローカルシェルのどちらも対象にできます。

::: warning シークレット
Terminalへ送信した値は、リモートシェルの履歴、TTYのエコー、スクロールバックに残る可能性があります。シークレット変数を実行中のTerminalへ送る操作は拒否されます。
:::
