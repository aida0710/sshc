# トラブルシューティング

## エンジンを起動できない

```sh
sshc status
sshc engine --replace
```

CLIとsshcエンジンのバージョンが違う場合は、古い方を更新してから、sshcエンジンを起動し直してください。`sshc service install`で登録したサービスは`sshc service install`で、それ以外のsshcエンジンは`sshc engine --replace`で再起動します。Androidでは、エラー画面にバージョン、エラーコード、詳細、Android SDK、機種名、ABIが表示され、［診断情報をコピー］でまとめて共有できます。シークレットは診断レポートに含まれません。

起動時に`was recorded by an sshc release before v0.24.0`と表示されて止まる場合は、v0.24.0より前のsshcで中断した変更の記録が`~/.ssh/sshc/journal/`に残っています。今のバージョンでは、その変更を完了させることも取り消すこともできません。前に使っていたバージョンのsshcを起動し、［History］画面の「中断した変更」で［完了させる］か［取り消す］を選んでから、もう一度更新してください。前のバージョンに戻せない場合は、表示されたファイルを`~/.ssh/sshc/journal/`の外へ移すと起動できます。ただし、その変更は途中のまま残るので、記録の`path`に書かれたファイルの内容を確かめてください。`was recorded by a newer sshc release`と表示された場合は、記録を書いた新しいバージョンのsshcへ更新してから片付けてください。

## Vaultのロックを解除できない

マスターパスワードは復旧できません。Vaultの作成に失敗した場合は、作成画面に表示されたエラーコードと原因を確認してください。Vaultのロックを解除できない場合は、入力したマスターパスワードが正しいか確認します。

`vault_too_new`は、現在のバイナリでは扱えない新しい形式でVaultが保存されている状態です。sshcを更新してから、もう一度試してください。

## 同期後に秘密鍵が見つからない

`IdentityFile`がこのマシンに復元された鍵を指しているか確認してください。SSH Keysでグループを選んで生成した鍵や、グループへ移動した鍵は、`~/.ssh/keys/...`へ保存されます。SSH Configに記載された`IdentityFile`のパスと、Connectionsの［Analysis］に表示される最終的な絶対パスを比較し、古いマシンの絶対パスが残っていないか確認してください。

## IdentityFileの鍵が使われない

`IdentityFile`に次の形の値を書いた鍵は、接続で使いません。

- `id_work`のような相対パス
- `~other/...`のような、ほかのユーザーのホームディレクトリ
- `%T`のような、sshcが展開しないトークン
- 値の無い環境変数を指す`${NAME}`

以前のバージョンのsshcは相対パスをホームディレクトリから開いていたため、`IdentityFile id_work`のような設定では、更新後に公開鍵認証が失敗することがあります。`~/.ssh/id_work`のように、`~`から始まるパスか絶対パスに書き直してください。どの鍵を使わなかったかは、［Settings］→［Terminal］の［接続のログ］を［鍵・経由ホスト・所要時間（-vv）］以上にすると確認できます。展開する形と使わない形は[SSH鍵とKnown Hosts](/connections/keys)に記載しています。

## ProxyJumpでパスワードを求められる

非対話SSHやSFTPで接続する場合は、最終接続先だけでなく、各踏み台に必要なパスワードまたは鍵のパスフレーズも保存してください。Connectionsの認証テストで、どの接続先が失敗したかを確認できます。2FAなど保存済みの認証情報だけでは完了できない接続は、対話Terminalから開いて追加入力します。

## Syncが進まない

```sh
sshc sync
sshc sync now
```

Vaultのロックが解除されているか、同期方向が合っているか、バケットの状態が最新か、最後の確認がいつ行われたかを確認してください。`outcome_unknown`は、変更を送信したものの、結果を確定できなかった状態です。同じ操作をすぐに繰り返さず、リモートの状態を更新してから判断してください。

同期エラーには、画面上の原因説明と`Code`が表示されます。

| エラーコード | 意味と主な原因 | 確認箇所と対処 |
| --- | --- | --- |
| `bucket_authentication_failed` | Access Key IDまたはSecret Access Keyが無効か、認証に失敗した | S3の認証情報を入力し直す |
| `bucket_access_denied` | 保存先がHTTP 403を返した。権限不足または署名不一致 | バケット名、リージョン、S3アクセスキーのオブジェクト読み書き権限を確認する |
| `bucket_rate_limited` | 保存先が要求数を制限している | 時間を置いて再実行する |
| `bucket_unavailable` | 保存先で一時的な障害が発生している | 保存先の状態を確認し、復旧後に再実行する |
| `bucket_refused` | 保存先が要求を拒否したが、原因を分類できない | S3の認証情報、リージョン、アクセス権限を確認する |
| `bucket_dns_failed` | エンドポイントの名前解決に失敗した | エンドポイントとDNS設定を確認する |
| `bucket_tls_failed` | HTTPS証明書を検証できない | 証明書とこのマシンの時刻を確認する |
| `bucket_timeout` / `bucket_unreachable` | 保存先へ到達できない | ネットワーク、VPN、ファイアウォールを確認する |
| `endpoint_must_be_https` / `endpoint_must_have_no_path` | エンドポイントがhttps://で始まっていない、またはバケット名やパスを含んでいる | エンドポイントにはhttps://で始まるアカウントのURLだけを指定し、バケット名は［バケット名］に入力する |
| `unsafe_bucket_name` / `unsafe_object_path` | バケット名、またはバケット内のパスに使用できない文字がある | 英数字、ハイフン、ピリオド、アンダースコアだけで入力する |
| `sync_push_refused` / `sync_apply_refused` | 同期の方向が「受信のみ」のマシンで送信した、または「送信のみ」のマシンで適用した | ［同期の方向］を変更する |
| `wrong_passphrase` | 同じ保存先を使うマシンの暗号化キーが一致していない | 最初のマシンで保管した暗号化キーを設定し直す |
| `passphrase_too_short` | 入力した暗号化キーが12文字未満 | sshcが生成した暗号化キーを使う |
| `snapshot_schema_unsupported` | リモートのスナップショットが、このバージョンのsshcでは読み込めない形式（v6より古い、または新しい） | 新しい形式なら、同じ保存先を使うすべてのマシンを同じバージョンへ更新する。古い形式なら、送信できるマシンからForce Pushで上書きする |
| `snapshot_rejected` | スナップショットを復号できたが、内容の検証に失敗した（破損、または改ざん）。前のバージョンのsshcがLinuxやmacOSから送ったスナップショットに、`:`や`?`などWindowsのファイル名に使えない文字を含む名前のファイルがある場合も、この表示になる | 履歴から別のスナップショットを復元するか、送信できるマシンからpushし直す。名前が原因なら、送ったマシンのsshcを更新してpushし、`sync_local_path_unportable`に表示されたファイルの名前を変更してから、もう一度pushする |
| `snapshot_download_incomplete` / `snapshot_too_large` | ダウンロードが途中で切れた、または上限（128 MiB）を超えた | ネットワークを確認し、同期対象から大きなファイルを除外する |
| `sync_remote_moved` | 別のマシンが先にpushしていて、確認したスナップショットと一致しない | 最新の状態を取り込んでから再実行する |
| `sync_remote_deleted` | 同期済みのリモートが削除されている | 保存先を確認し、送信できるマシンからpushし直す |
| `sync_local_path_unportable` | 送る対象のファイルに、ほかのマシンで同じ名前として扱えない名前がある（Windowsの予約名、`:`や`?`などWindowsのファイル名に使えない文字を含む名前、末尾がピリオドか空白の名前、大文字と小文字だけが違う名前など）。画面にはそのファイルのパスが表示される | ファイルの名前を変更するか、［同期するファイル］で除外する |
| `preview_stale` / `sync_local_changed` | プレビュー後にリモートまたはローカルが変わった | もう一度［変更を確認］してから適用する |
| `sync_conflicts` | ローカルとリモートの両方が変わっていて、自動でマージできない | 「このマシンの内容を残す」か「他のマシンの内容を使用」を選ぶ |
| `sync_internal_failed` | 原因を分類できない内部エラー | 表示された診断コードを添えて報告する |
