# SSH Config

接続設定の基準となるデータは`~/.ssh/config`です。sshcは`Include`の階層をたどり、ワイルドカードを含まない個別の`Host`エイリアスを接続先として表示しています。

## 設定ファイルを編集する

SSH Configでは、読み込まれたファイルと`Include`の関係を確認しながら、UTF-8テキストを編集できます。保存中に処理が中断しても、元の設定ファイルが途中まで書き換わった状態にならないよう保存します。

sshcが管理するグループ領域を除き、コメント、空行、ディレクティブの順序はできるだけ維持されます。生成範囲は、`# >>> sshc groups`で始まる行と`# <<< sshc groups`の間です。この範囲は次回の保存時に置き換えられるため、直接編集しないでください。

### ファイルとディレクトリの操作

見出しの［ファイルを作成］で、`~/.ssh`の中に新しい設定ファイルを作れます。OpenSSHに読み込ませるには、`~/.ssh/config`の`Include`から参照してください。開いているファイルの見出しの「…」には、次の操作があります。

- ［ファイル名を変更］: このファイルを直接参照する`Include`の行も同時に書き換えます。ワイルドカードのパターンは書き換えず、新しいパスが一致しないときは警告します。
- ［ディレクトリを作成］: `~/.ssh`の中にディレクトリを作ります。グループのフォルダは、Connectionsのグループの一覧で管理してください。
- ［ファイルを削除］: このファイルを直接参照する`Include`の行も削除します。バックアップを保存するので、履歴から復元できます。
- ［ディレクトリを削除］: 空のディレクトリだけを削除できます。

未保存の編集があるあいだは、名前の変更と削除はできません。`~/.ssh`の外のパスは使えません。

## 接続詳細の4つのタブ

- **基本**: ホスト、ユーザー、ポート、認証
- **踏み台・転送・その他**: 経由する接続先（ProxyJump）、ポート転送、その他のディレクティブ
- **表示とターミナル**: 色、OSアイコン、タグ、表示順、ターミナルの配色・文字コード、VPNなど、sshcだけが使う設定
- **最終的な値**: 最終的に適用される値、参照元、警告

値を空にして保存すると、OpenSSHから継承した値に戻ります。名前の変更、グループへの移動、複製、コメント、保存ファイルの変更、削除と、Hostブロックをテキストのまま編集する［テキストで編集］は、接続詳細の見出しの「…」にあります。

## 接続せずに設定を確認する

```sh
sshc info <alias>
sshc info <alias> --json
```

実際の接続時と同じ規則で`Include`、`Match`、`ProxyJump`を読み、最終的に使われる設定を表示します。パスワード、パスフレーズ、`SetEnv`の値、`ProxyCommand`の本文は表示されません。
