# Get started

sshc reads your existing `~/.ssh/config` and serves its Web UI and API locally.

```sh
sshc engine
```

Open the UI from another terminal.

```sh
sshc
```

On first launch, follow the prompt to create a vault. Existing `Host` entries appear under **Connections**.
